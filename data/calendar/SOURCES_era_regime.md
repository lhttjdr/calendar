# 年号与历史政权数据可信来源

`vendor/calendar/chinese_calendar/年号表.csv` 中的年号及政权/帝号/年号名/年数等字段，可对照以下权威来源进行补全与校勘。

## 一、主要文献与数据源

### 1. 李崇智《中国历代年号考》

- **出版**：中华书局，1981 年初版，2004 年修订本（ISBN 9787101025125）。
- **内容**：汉武帝建元（前 140 年）至中华人民共和国成立前，约 **800 余个年号**、**1200 余条**使用记录；含各朝代、农民起义、地方割据与少数民族政权。
- **编排**：按朝代分章（西汉、东汉、三国、晋及十六国、南北朝、隋唐、五代十国、辽宋夏金元、明清等），修订本增补北凉、高昌、于阗等政权年号。
- **说明**：维基百科「中国年号列表」凡例写明：*該年號列表內容主要根據李崇智《中國歷代年號考》整理而成*，可作为补全与校勘的**首要依据**。

### 2. 万国鼎《中国历史纪年表》

- **出版**：中华书局，1978 年。
- **用途**：ytliu0/ChineseCalendar 项目年号数据来源之一，与维基百科等配合使用。
- **说明**：纪年表形式，便于按年检索朝代与年号对应关系。

### 3. 张培瑜《三千五百年历日天象》

- **用途**：历日与朔闰考证，本仓库朔日表（`vendor/calendar/chinese_calendar/实历朔日表.csv`）的来源依据。
- **说明**：该书采用「据历还原」编制历表，本仓库主表即由此得来；具体含义（书中并无一种名为「中原正朔」的历法）见 [README_shuori.md](README_shuori.md)「主表来源」一节，不在此重复。
- **勘误**：ytliu0 维护勘误页 [《三千五百年历日天象》勘誤](https://ytliu0.github.io/ChineseCalendar/3500Calendars_errors.html)。

### 4. 维基百科「中国年号列表」

- **链接**：[维基百科·中国年号列表](https://zh.wikipedia.org/wiki/中国年号列表)
- **内容**：按朝代分节，每条约含年号名称、使用该年号的君主、起讫时间、使用年数、备注；凡例标明以李崇智《中国历代年号考》为主并辅以他书。
- **用途**：机器可读性较好，便于按「政权 → 君主 → 年号 → 起讫年」做批量对照与补全。

### 5. 朱文鑫《历法通志》

- **作者**：朱文鑫（近代天文学史、历法学者）。
- **内容**：历名、治历者（政权与人物）、岁实（回归年长度）、朔策（朔望月或相关参数）、成历或行历之年与相当公元年份、出处备注（如汉书律历志、魏书律历志、宋史律历志）。
- **用途**：历法名称与政权/人物对应、岁实/朔策与推步参数校核（见 `doc/calendar/push-algorithms.md`）、成历之年与公历对照及年号校勘。本仓库在 `vendor/calendar/lifa_tongzhi/` 下按原书两页合一整理为单表：`历法通志_README.md`、`lifa_tongzhi.csv`（历名·治历者·岁实 + 朔策·成历之年·公元·备·注 合一）。

### 6. 方诗铭《中国历史纪年表》

- **出版**：上海书店出版社，新修订本。
- **内容**：从十二诸侯（西周共和）到民国，按朝代分章的纪年矩阵表（公元/干支 + 并列政权列，格为君主/年号+
  在位年数），另含多个政权兴亡表、三代纪年表、黄帝纪年对照表、年号索引等。
- **用途**：与李崇智《中国历代年号考》、万国鼎《中国历史纪年表》性质相近，可用于政权/君主/年号/起讫年的
  交叉校勘，尤其是十二诸侯、战国、晋及十六国、南北朝、五代十国、宋辽金等"多政权并存"时期的对照表形式，
  便于按年份横向比较不同政权的纪年。
- **本仓库中的存放**：原书 PDF 与逐页扫描图片见 `vendor/calendar/fang_shiming/`（原样保留）；结构化转录（按
  章节拆分的宽表 CSV/JSON，2026-09 逐页视觉识别产出并复核）见 `data/calendar/fang_shiming/README.md`。**尚未**
  与本仓库 `年号表.csv`/`汇总/regime_era_calendar_matrix.*` 做过交叉校验或合并，目前仅是独立的忠实转录层。

### 7. ytliu0/ChineseCalendar

- **链接**：[ GitHub ](https://github.com/ytliu0/ChineseCalendar) / [ 中国历史纪年表 ](https://ytliu0.github.io/ChineseCalendar/era_names_simp.html)
- **说明**：本仓库 `vendor/calendar/chinese_calendar/年号表.csv` 的**直接数据来源**（从该库 `src/eras.js` 的 default 区域提取）；其年号与纪年表综合了万国鼎《中国历史纪年表》、维基百科中国年号列表等。
- **范围**：722 BCE–2200 CE；主表为各朝据历还原推步的连续表，魏蜀吴等政权另有 region 数据可参考。

## 二、补全与校勘建议

1. **政权（regime_simp）为空**：可查《中国历代年号考》或维基百科该年所属朝代/政权，补上政权简称（如 武周、南明、西夏 等）；本仓库解析脚本中的 `PREFIXES` 列表可根据上述来源扩展。
2. **帝号/庙号（emperor_simp）为空或异常**：按同一来源核对该年号对应的君主称谓（庙号、谥号或习惯称呼），与 `era_simp` 全称一致即可。
3. **年号名/年数（era_name_simp / era_year_simp）**：若出现「X 载」（如 天宝三载），解析脚本需支持「载」与「年」的等价处理；缺段时可用 `era_only_simp` 兜底。
4. **交叉核对**：同一农历年可在 李崇智、维基百科、ytliu0 纪年表 之间对照，取多数一致或文献优先（李崇智 > 纪年表 > 维基）作为最终值。

## 三、本仓库中的使用方式

- **朔日**：`vendor/calendar/chinese_calendar/实历朔日表.csv`，即主表（《三千五百年历日天象》按各朝颁历据历还原推步得出的连续表）；勘误见上。
- **年号与政权**：`vendor/calendar/chinese_calendar/年号表.csv` 含 8 列（含改元前列）；由 `scripts/calendar_data/refactor_era_names_csv.mjs` 或 `scripts/calendar_data/era_names_to_base_csv.mjs` 生成。**补全与修正**可依据上述文献或《历法通志》成历之年表（`lifa_tongzhi_establishment.csv`）校订。
- **重新生成**：若从 ytliu0/ChineseCalendar 重新提取带 era_simp 的表，运行 `refactor_era_names_csv.mjs` 可得到 6 列基础表；补全时可在脚本中增加政权前缀或按年映射，或手工校订 CSV。

以上来源均为历史学与年代学常用参考，可作为「可信来源」用于补全与校勘本仓库中的历史政权与年号数据。
