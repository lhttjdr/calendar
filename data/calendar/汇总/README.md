# 跨来源汇总数据

本目录存放跨多个来源汇总/生成的数据，区别于 `data/calendar/fang_shiming/` 这类按单一来源整理的子目录。

## era_names_merged.csv / .json —— 政权·年号汇总表（供程序加载）

**这是"多来源交叉校对出汇总表"这条路线的第一版产物**，由
`scripts/calendar_data/build_era_names_merged.py` 从 `vendor/calendar/chinese_calendar/年号表.csv`
（ytliu0/ChineseCalendar，"正统主线"，每年一条）与 `data/calendar/fang_shiming/`（方诗铭《中国历史纪年表》
转录，并存政权）合并生成，取代 `EraNames` 原先直接读 `vendor/.../年号表.csv` 的做法。

### 表结构（长表，一年一个政权一行）

| 列 | 含义 |
|---|---|
| `lunar_year` | 农历年，**天文纪年**（含公元0年=公元前1年）——与 `vendor/calendar/chinese_calendar/` 下其余数据及 `rust/core` 的公历↔儒略日转换一致；`data/calendar/fang_shiming/` 下的数据用的是历史纪年（无公元0年，原书体例），合并时已换算 |
| `regime` | 政权名。同一年可能有多行并存政权（如三国期间魏/蜀/吴三行），不强行二选一 |
| `emperor` | 帝号/庙号，主线行来自年号表.csv；fang_shiming 补充行是从原书单元格拆出的君主（帝号或人名，带本名时写作「太祖(朱温)」，原书「~」已按同姓展开，原书存疑的「?」保留），取该年**年末**在位者 |
| `era_name` | 年号。奉中原正朔、无自有年号的政权（吴、荆南、吴越、南唐等）填所奉年号（原书括号内文字）；只有在位纪年、无年号的（如渤海诸王、蒙古、前燕慕容皝时期）为空，此时 `era_year` 是在位年数 |
| `era_year` | 年数（整数） |
| `is_primary` | 1 = "正统主线"，每年恰一条：前106年（天文 -105）起来自年号表.csv（原 `EraNames` 单一年号表的等价延续），此前来自方诗铭表 01–04 章（见下「前106年以前」）；0 = 并存政权/诸侯 |
| `has_gaiyuan` | 是否改元年（仅 `is_primary=1` 的行有值：年号表.csv 原字段；方诗铭来源的先秦/汉初主线恒为 0——无年号，嗣位踰年改元） |
| `gaiyuan_prev_era_name` / `gaiyuan_prev_era_year` | 改元前的年号名/年数：`is_primary=1` 行来自年号表.csv 原字段；方诗铭补充政权（`is_primary=0`）在同一格内由旧年号转入新年号时（如北齐 560「乾明→皇建」、北周 579「大成→大象」、隋 581 起诸年）亦填，`has_gaiyuan=1`，`gaiyuan_month` 取圈码月份 |
| `gaiyuan_month` | 改元/继位所在的**农历月份**（1-12），仅在该年是某年号第一年时有值。来自 fang_shiming 转录里的圈码标注，来源为年号表.csv 的主线行（年号表.csv 本身不含月份）此列恒为空。**只精确到月，不到日**——精确到日的改元时间是另一套独立机制，见下「已知局限」 |
| `source` | 数据来源：`era_names_csv` 或 `fang_shiming:<章节文件名>` |
| `note` | 校勘/异说说明，见下 |
| `gaiyuan_earlier_eras` | 一年三号以上者，除 `era_name` 与 `gaiyuan_prev_era_name` 外本年行用过的年号，「名年数」以 `/` 相隔、按先后（528 北魏 `武泰1`，304 晋 `永安1/建武1`）。来自方诗铭表三段以上的单元格与 `data/calendar/era_gaiyuan_day.csv`；次年元年的年号不计（武周建子，改元表记在上年十一月者）。末列追加：Rust `era_names` 按位置读到 `gaiyuan_month` 为止，不受影响 |

### fang_shiming 单元格的结构化解析（`is_primary=0` 行）

原书单元格把君主、年号、年数、月份圈码挤在一段文字里（「高保融③(乾祐) 1」「~从诲(大和)1 / (天成⑦)4」
「孝静帝元象」）。脚本 `parse_segment()`/`forward_fill_column()` 逐列拆成四个字段，规则：

- **哪段是年号**：以方诗铭自己的 `16_年号索引.csv` 为字典（外加索引未收的个例 `ERA_INDEX_EXTRA`），取能查到的
  最长后缀；括号里查得到的是奉正朔的所奉年号，查不到的是人名（紧跟帝号 = 本名注，跟在年数后 = 年内嗣位新君）；
  单字括号是异写注（「太(大)安」「寿昌(隆)」），丢弃。
- **年末状态**：一格多段（`/` `／` 换行）依次生效，取最后状态；君主、年号各自前向填充。新君无年号且年数从 1
  重起 = 在位纪年，不沿用旧号；年数延续 = 沿用旧号（踰年改元）。括号年号若年数恰好续当前年号，则是原书附注的
  异说（渤海 774 年「(宝历) 38」），记入 note、不切换。
- **「~」**（原书同姓省写）按本栏最近已知姓氏展开，含复姓表 `COMPOUND_SURNAMES`；南诏栏的国号前缀（大长和、大封民等）
  拆到 note。
- **跨章续接**：同一政权跨两章（如吴越 10→11 章）时，后一章从前一章末年状态接续——旧版因此整段丢失了
  吴越/南唐 961–978 年（11 章只印「(建隆) 1」这类无名单元格）。
- 月份：圈码 ①–⑫/㊀–㊉ 与 10 章转录的 `[11]` `[12]`；⑬、㉚、`[13]` 含义不明，不当月份。

### 前106年以前：方诗铭表 01–04 章（共和元年前841年起）

年号表.csv 起于前106年（汉武帝元封五年），此前取 `01_十二诸侯纪年表`、`02_战国纪年表`、`03_秦纪年表`、
`04_汉纪年表`「汉」栏（只取前106年之前，之后仍以年号表.csv 为主线）：

- **主线（正统）按《资治通鉴》体例**：周（前841 共和元年—前256 周赧王卒）→ 秦（前255 秦昭襄王五十二年—前207）
  → 汉（前206 汉高祖元年起），见脚本 `early_primary_regime()`；三个交接年的 `note` 写明依据。前206年秦王子婴、
  其余诸侯（鲁齐晋楚宋卫陈蔡曹郑燕吴、魏韩赵田齐等）为 `is_primary=0`。
- 这一段没有年号：`era_name` 为空、`era_year` 是君主在位年数（共和、汉文帝/景帝的中元后元、秦惠文王更元、魏惠王后元
  例外，按通行写法放 `era_name`，见 `ERA_INDEX_EXTRA`）。`emperor` 是谥号，周王带本名（「宣王(姬静)」）。
- **精度**：前106年以前没有实历朔日表，农历年按现代定气定朔推算；先秦各国岁首不一（周正/殷正/夏正），本表按年

- 这次合并顺带发现并修正 `hist_to_astro()` 公元前换算方向写反（应为 +1），此前合并的 fang 数据全在公元后，未受影响。

### 对年号表.csv 上游数据的订正（非史料分歧，是确认的遗漏/字段污染）

脚本里 `MANUAL_PRIMARY_FIXES`/`MANUAL_ERA_NAME_FIXES` 按(年份,政权)覆盖主线行，原值与依据写在 `note`，vendor 原文件不动：

- **697 年**：年号表.csv 记"万岁通天二年"且未标改元，漏记当年九月改元**神功**；据方诗铭表（`09_唐纪年表`
  "神功⑨ 1"、`16_年号索引`）与《旧唐书·则天皇后纪》订正为神功元年（改元前：万岁通天二年）。
- **756 年**：原字段"肃宗至德元载"把年数拼进了年号名、年数列为空，拆为"至德"/1。
- **1278/1279 年**："帝昺祥兴""昺祥兴"剥离帝昺本名为"祥兴"。
- 另外 `clean_era_name()` 改为先剥帝号头衔再剥朝代名，修正了"元帝景元""明宗天成""陈后主至德"等被剥成
  "帝景元""宗天成""后主至德"的问题；改元前年号（`gaiyuan_prev_era_name`）也走同一清洗（"宋元徽"→"元徽"等）。
  以方诗铭 `16_年号索引` 为字表校验，主线行剩余不在索引里的只有异体字（佑/祐、升/昇）与索引本身未收的
  "后元""乾兴""民国"。

### 与"精确到日"的改元数据是两套机制

本表 `gaiyuan_month` 只精确到**月**（来自 fang_shiming 的圈码月份标注，逐年批量提取）。精确到**日**的改元
时间是完全独立的另一套机制：`rust/core/src/calendar/era_gaiyuan.rs`（`GaiyuanDays`）+
`data/calendar/era_gaiyuan_day.csv`（由 `scripts/calendar_data/sync_era_gaiyuan_day.py` 从**本表**主线
改元行生成骨架——必须与本表同源，因为 `GaiyuanDays::resolve` 只在 `EraNames` 主线条目 `has_gaiyuan=1` 时才查日表，
`era_names::tests::gaiyuan_day_skeleton_covers_merged_gaiyuan_years` 会检查两者一致）。

日期由 `scripts/calendar_data/fill_era_gaiyuan_day.py` 从 `data/calendar/era_gaiyuan_sources.csv` 填入——后者是
**逐条查证的史料记录**（2026-10-25，203 条），每行写明出处
（多为正史本纪，异说取舍依《资治通鉴》或两《唐书》互校）、原文摘录、月份与日干支；脚本用 `gaiyuan_date.py`
查实历朔日表把「某月某干支」换算成农历日序与公历日期，干支不在该月内即报错（已据此发现并注明 105 年元兴、
363 年兴宁两处史书干支讹误，《晋书》校勘记亦有同说；307 永嘉、345 永和两处本纪误书「朔」，换算结果与校勘记一致）。
190 条精确到日、13 条只能精确到月（史书未载日，公历留空）。
填表时还校验每年第一个改元事件的改元前年号等于本表的年初年号，据此订正了本表 304、690、701、705、712、874、
948 年的年初年号与 954、959、1329、1332 年的改元标记（见 `MANUAL_PRIMARY_FIXES`）。

**年号表.csv 未标的年内改元**：年号表.csv 的 `has_gaiyuan` 只标"一年两号"，正月中旬（非朔日）才改元的年份被当成
年首换号。已把主线上全部 189 个「元年且未标改元」的年号逐个查了元年改元日：
- 36 个确属年内改元（如唐显庆正月初七、宋端拱正月十七、梁承圣十一月即位改元、明天顺夺门后正月丙戌、新莽天凤/地皇
  始于夏正上年十二月朔），另补出年号表.csv 完全未载的前 5 年「太初元将」改元及废除；这些写入 era_gaiyuan_sources.csv，
  `build_era_names_merged.py` 的 `mark_inyear_gaiyuan()` 据此自动补标 `has_gaiyuan` 与年初年号（共 39 年），
  不再逐条手写订正；
- 153 个确认为年首换号（正月朔改元，或前一年下诏「改明年为……」；另含原标改元、经查为正月朔改元的 954 年显德），出处记于 `data/calendar/era_gaiyuan_yearstart.csv`
  备查；明清各年号均已摘录本纪「以明年为某元年」原文；前106年以前因无实历朔日表无法换算，在 note 注明。

重新生成顺序：`build_era_names_merged.py` → `sync_era_gaiyuan_day.py` → `fill_era_gaiyuan_day.py`（三者都是
确定性的，可重复执行）。

注意本表 `has_gaiyuan` 沿用年号表.csv：正月中旬（非初一）才改元的年份（如唐代多在南郊大赦日改元）被记为
`has_gaiyuan=0`，这些年正月初一到改元日之间的日子目前仍按新年号处理，见「已知局限」。

### 已知局限（供后续迭代参考）

- **年内年号变动的覆盖依据**：除年号表.csv 标注与上述 189 个元年逐个核查外，还用方诗铭表做了独立交叉检查——扫描各章
  主线政权栏中一格多段（原书以「／」分写同年两号）及新号首年带非正月圈码的单元格，凡未被 era_gaiyuan_sources.csv
  覆盖的逐条核实：补出 189 年（光熹→昭宁→永汉→复中平六年）、761 年（九月壬寅诏去上元号，十一月起只称「元年」）；
  其余命中均为新君即位月份（非改元）或并存政权（553 年武陵王天正）。两源都未体现的变动仍可能遗漏。
- **依据较弱的条目**：`era_gaiyuan_yearstart.csv` 中前106年以前各年号（无实历朔日表）；366 年太和《晋书》《通鉴》
  均未载改元，已据《建康实录》卷八「（兴宁三年）十二月，大赦，改明年为太和元年」补证；`era_gaiyuan_sources.csv` 中 189 年复中平「十二月戊戌」按朔日表闰十二月处理（note 有说明）。
- **周正时期（689–700）的年级标签**：本表沿用年号表.csv 的夏正年对应，而周正的正月、腊月落在夏正上一年年末，
  故 694、695、697 年末实际已是下一个年号（证圣、万岁登封、圣历）；按日解析（GaiyuanDays）已正确处理，年级标签未改。

- `regime`/`era_name` 主要依据 `年号表.csv`（只有一条正统主线）与 `fang_shiming` 各章节转录直接合并而成，
  **尚未**引入李崇智《中国历代年号考》等第三方文献做进一步裁决。
- 相邻章节交界年份（如 960 年同时是"五代十国纪年表"末年与"宋辽金纪年表"首年）同一政权两章各有一条记录时：
  完全一致的自动去重；内容有出入的 7 处（420 北燕、907 吴/渤海、960 南汉/大理/荆南/辽）已于 2026-10-25 逐条
  对照原书核实，结论写在脚本 `BOUNDARY_RESOLUTIONS` 与对应行 `note` 里——6 处是同一事实的不同写法，960 荆南是
  同年嗣位前后两个状态（取年末），核实中顺带订正了 fang_shiming 转录的 4 处误读（见该目录 README 订正记录）。
  今后新出现的未裁决冲突仍会两条都保留并标"需人工核对"，`era_names::tests::parses_real_merged_file` 会因此失败，
  提醒补进 `BOUNDARY_RESOLUTIONS`。

## 一致性检查（2026-10-28）
