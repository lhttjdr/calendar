## 表头及含义

CSV / JSON 字段(均为原书信息经结构化拆分,未合并压缩):

| 字段 | 含义 |
|---|---|
| `id` | 转录顺序号(从 1 递增,仅用于定位,不代表原书排序号) |
| `stroke_section` | 该条目所属的笔画分节标题,如「二画」「三画」……「十六画以上」。原书仅在笔画数变化时印出居中分节标题,同一分节内延续多页不重复印标题;转录时按「上一次出现的分节标题延续」处理,与原书排版逻辑一致(已逐页核对分节标题出现位置)。 |
| `era_name` | 年号,原样照抄。 |
| `seq` | 同一年号被多个政权/帝王使用时,原书用「(1)(2)(3)…」编号;此列记录该序号(整数),单一政权使用的年号留空。 |
| `ruler` | 政权/帝王(或起事者、僭号者姓名),原样照抄原书写法(如「北汉刘钧、刘继元」「后汉高祖、隐帝、北汉刘旻、刘钧」等合并写法不拆分)。 |
| `year_text` | 原书印刷的公元纪年原文,完整保留「前」字、前后「—」符号位置、「?」问号、「( )」括注即位之年,是转录的第一手依据。 |
| `year_start` | 当 `year_text` 形如「N—」(数字后接「—」)时,解析出的起年(整数,公元前为负)。 |
| `year_end` | 当 `year_text` 形如「—N」(数字前接「—」)时,解析出的讫年(最后一年,整数,公元前为负)。 |
| `single_year` | 当 `year_text` 无「—」符号(仅一年)时,解析出的年份(整数,公元前为负)。 |
| `accession_year` | 当 `year_text` 形如「(N— )」时(用于起讫年不详、以即位之年供查核的条目),解析出的即位之年。 |
| `uncertain` | 原书是否带「?」号(起讫年不详),「是」/空。 |
| `note` | 转录备注,如字迹不清占位说明、疑难字形复核提示。 |

`year_start`/`year_end`/`single_year`/`accession_year` 四列互斥,按 `year_text` 的书写形式解析得出,严格遵循书中页脚凡例:「公元前加'前'字,公元后一律不加。公元纪年前有'—'号的表示年号的最后一年,后有'—'号的表示年号的起年,无'—'号的表示仅有一年。凡有'?'号的则表示起讫年不详,于( )号内注明即位之年,以便检查。」

## 排序规则推测

索引正文首页（page_161.png）印有编者按语(已原样保留,未作为数据行):

> 索引中所列年号,按第一字的笔画排列,数字为公元纪年……

即：条目按年号首字的笔画数从少到多排列(二画→三画→……→十六画以上),同笔画数内的排列顺序未见另加说明,观察实际顺序大致接近《康熙字典》部首/字形顺序,但未逐一验证是否严格遵循部首规则,仅原样保留原书出现顺序。

分节标题仅在笔画数发生变化且原书确实印出居中标题时才出现;有些相邻页面之间笔画数不变则不重复印标题(已核对页面图像确认,如「八画」自 page_168.png 出现后延续至 page_169.png、page_170.png 前段,直至「九画」标题出现在 page_170.png 右列「政和」之前)。

## 不确定 / 疑难之处(人工复核结论,见下)

1. **id=19「大同(2) 南诏隆舜(887— )」——复核确认原转录无误**:用原图(`page_161.png`)及 PDF 内嵌高分辨率原始扫描(1570×2432px)反复裁图放大核对「(887—　)」括号内及前后区域，确未发现「?」问号痕迹，原书此条确实未加问号，与页脚凡例「凡有'?'号的……于( )号内注明即位之年」的通常写法(全索引中其余括注即位年条目均带「?」,如 id=170「天瑞景星」、id=321「正德(1)」等)不完全一致，判断为原书体例本身的个别不一致（或编者对南诏隆舜即位之年把握程度与其他条目不同所致），非扫描/转录遗漏，维持原状不改动。
2. **id=73、577「义和(2)/和平(4) 高昌麴□」——复核确认原转录无误，并补充重要背景**:用原图(`page_162.png`/`page_169.png`)及 PDF 内嵌高分辨率原始扫描核对，确认原书该处**本身即排印为方框「□」**（笔画规整、边缘清晰的印刷符号，非扫描/字迹模糊导致我方无法辨认而自行添加的占位符）。进一步查证现代史学研究：高昌「义和」年号(614—619)的建立者是延和十二年(613年)政变夺权者，据黄文弼、吴震等考订，其本名史料确实未见记载，仅知麴姓；高昌「和平」年号(551—554)的建立者为麴玄喜之子，其本名史料亦未完整保留。两条目的「麴□」均与现代史学界对这两位高昌国王本名"缺载"的共识完全吻合，说明原书排版者面对的底本本就缺此二字，转录「麴□」准确无误，非本次转录/扫描造成的信息缺失。
3. **id=106「天成(1) 南朝梁贞阳侯 555—」——复核确认「天成」无误**:用原图及 PDF 内嵌高分辨率原始扫描放大核对，发现区分「天」「大」的关键顶部短横因原书印刷较淡，在扫描图上呈现为字形右上方一个略微游离、不易第一眼察觉的小短横，但确实存在，故该字应读作「天」。并查证史实：南朝梁贞阳侯(萧渊明)于555年即位改元「天成」、安庆绪于758年、后唐明宗李嗣源于926年，三者均确切使用年号「天成」（而非「大成」），与索引中该条目所在「天」字四画分节完全吻合，可以确认原转录「天成」准确无误。
4. 索引中出现的「?」条目均严格保留原书标记,未做起讫年推断或补全;`year_start`/`year_end`/`single_year` 三列对这些条目均留空,仅填 `accession_year`,以避免臆测。
5. 全部 914 条均为逐页视觉识别结果,未参照已弃用的 `方诗铭纪年表.xlsx` / `ocr_pages.jsonl`。
6. 本次复核（针对以上 1—3 项）额外使用了原书 PDF（`vendor/calendar/fang_shiming/中国历史纪年表 (方诗铭) (z-library.sk, 1lib.sk, z-lib.sk).pdf`）内嵌的原始扫描图像（经 PyMuPDF 提取，分辨率 1570×2432px，约为 `pages/` 目录下导出 PNG 分辨率的 1.5 倍），比单纯放大已导出的 PNG 更清晰，特此记录供后续类似复核参考。
