# 《中国历史纪年表》（方诗铭）结构化数据

**来源**：方诗铭编著《中国历史纪年表》（新修订本，上海书店出版社）。原书 PDF 及逐页扫描图片（`page_001.png` –
`page_175.png`）位于 `vendor/calendar/fang_shiming/`（原样保留，不改动，详见该目录的
[README.md](../../../vendor/calendar/fang_shiming/README.md)）。本目录下的数据是本项目**自己生成/整理**的
结构化转录结果——2026-09-21 逐页视觉识别（非 OCR，Claude 直接读图转录）产出，2026-09-22 又对全部疑难点做了
第二轮复核——按「vendor 原样保留 / data 本项目整理」的仓库惯例，从 `vendor/calendar/fang_shiming/parsed/`
迁移到本目录。

早期用 rapidocr 自动 OCR 生成的 `方诗铭纪年表.xlsx`、`ocr_pages.jsonl` 精度很差、不可用，已废弃删除，
**不要**再参考或依赖它们；本目录数据是本书唯一可用的结构化数据。

## 一、页码映射（原书 ↔ 扫描图片）

图片页码与书内印刷页码为固定偏移：**图片页码 = 书内印刷页码 + 5**（已用书内第 2/34/63/169 页等多组页面交叉
验证）。每页顶部印有形如「（N）中国历史纪年表·XX纪年表」的页眉，可据此核对；对应扫描图片见
`vendor/calendar/fang_shiming/pages/`。

## 三、转录约定

- **宽表镜像原书版式**：每行 = 一个纪年（`year` 整数，公元前为负数；`ganzhi` 干支），每列 = 原书中并列的一个
  政权/朝代（列名即原书印刷的政权名，按书中首次出现顺序排列）。单元格内容原样照抄。
- **留空 = 延续上一行**：原书对同一君主/年号的延续年份不重复印君主名，只印递增的在位年数；转录时同样留空，
  不做前向填充（下游若需要"每行都带上当前君主名"，需自行按列做 forward-fill）。
- **带圈数字（①～⑫等）多数表示继位/改元所在的农历月份**，而非脚注编号——这是多个章节（三国、汉、隋、唐、
  明、清等）逐一与史实交叉核对后确认的体例，已统一按此理解转录为 Unicode 圈码数字。**例外**：
  `06_晋及十六国纪年表` 因表格规模过大（140 行 × 32 列），未转录带圈月份数字，只保留政权/年号/年数等主体信息，
  与其余章节的处理深度不一致，如需月份精度需专门补做。
- `〜`：原书「同上」符号，表示与上一行同一人物/同一政权延续，原样保留。
- `?`：原书自身标注的不确定（如南诏纪年、人名存疑），原样保留，不是转录者加的。
- `□`：**本次转录**中确实无法辨认的字符占位（与原书本身印刷的空心方框——如 `10_五代十国纪年表` 944 年大理
  「神武□」——含义不同，各 `notes/notes_XX.md` 中会说明是哪一种）。
- `〔〕`：原书用于标注编者认为不确定/后世追拟的政权名或年号，原样保留。
- 部分章节新增了原书没有的「备注」列（如 `01`、`05`、`11`、`13`、`14`、`15`、`16_年号索引` 等），用于承载字迹
  不清说明、原书未印栏名条目的注记等，不是原书列。
- 政权兴亡表类文件（`02f`、`06f`、`10f`）列结构与纪年矩阵表不同，是「政权名/建立者/起讫年代/灭于何国」一类，
  具体列名见文件表头。

## 五、与仓库其他数据的关系

本目录是「忠实转录层」——尽量原样保留原书版式和文字，**不是**可直接消费的分析表，也未与本仓库
`lifa.csv`、`regime_era_calendar_matrix.*` 等跨来源汇总数据或 `vendor/calendar/chinese_calendar/`
（`年号表.csv` 等）做过交叉校验或合并。后续如果要把方诗铭此表用作政权/年号数据的补充校勘来源，需要单独
设计从这里的宽表到目标 schema 的转换/校勘规则（类比 `vendor/calendar/lifa_tongzhi/历法通志_README.md` 「三、
与仓库其他数据的关系」一节的做法），并更新 `SOURCES_era_regime.md`（见该文件新增的方诗铭条目）。
