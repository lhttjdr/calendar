# 星空文化数据

由 `scripts/sky_culture/lunar_mansions.py` 生成。

## chinese_lunar_mansion_determinatives.csv

二十八宿距星，按体系并存（`chenzhuo`、`song_huangyou`、`yuan`、`ming_xianglin`、`qing`）。来源为 `vendor/stellarium_skycultures/`
的 `lunar_system.defining_stars`。脚本逐宿核对：距星须属本宿星官的连线；若该体系在星名中标了「距星」，二者须一致。
许可证 **CC BY-SA 4.0**（承自 Stellarium 星空文化）。

| 列 | 含义 |
|---|---|
| `system` | 体系 id |
| `index`、`mansion` | 宿序（1 = 角 … 28 = 轸）、宿名 |
| `hip` | Hipparcos 编号（星表见 `data/stars/hipparcos_bright.csv`） |
| `stellarium_name` | 该体系中的星名（宋代等未命名者为空） |

汉至明四套相同。清代改了三宿：奎 ζ And → η And，觜 φ¹ Ori → λ Ori，参 δ Ori → ζ Ori。另有 `qing_lingtai`（康熙《灵台仪象志》1674）：
据潘鼐《中国恒星观测史》（2009）第 640 页，在传统距星上改奎 η And、觜 λ Ori、昴 η Tau（Stellarium 无此体系）。
传统距星与潘鼐第 14 页表 1.2.1、清代与第 641 页表 9.1.4 逐宿核对一致。

## chinese_asterisms.csv

各体系全部星官（`chenzhuo`、`song_huangyou`、`yuan`、`ming_xianglin`、`qing`），取自各 `index.json` 的 `constellations`。
许可证 **CC BY-SA 4.0**。

| 列 | 含义 |
|---|---|
| `system`、`id` | 体系 id、星官编号（Stellarium 的 `CON … NNN` 末段） |
| `name`、`english` | 中文名、英文名（英文名中的逗号换成空格） |
| `members` | 连线中出现的天体，按首次出现顺序，空格分隔：HIP 编号；`DSO:M44` 等深空天体；`GAIA:…` 盖亚编号 |
| `determinative` | 距星：星名中标「距星」者；二十八宿取 `lunar_system.defining_stars`；其余为空 |
| `lines` | 原连线（画星图用）：各折线以 `;` 分隔，折线内天体以空格分隔，记法同 `members`；单星星官为只含一星的折线 |

`members` 恰为 `lines` 中天体按首次出现去重（测试 `asterism_lines_and_star_names`）。

## chinese_star_names.csv

各体系的星名，取自各 `index.json` 的 `common_names`，只取 HIP 星。许可证 **CC BY-SA 4.0**。列：`system`、`hip`、`name`
（一星多名以 `/` 连接；名中可带「距星」注记、方括号内所属宿）。陈卓、元、象林三套只给少数星（多为单星星官）起名，各数十至百余条；
宋皇祐 419 条，《仪象考成》3053 条。星图对无专名的星显示其所属星官。

## kaiyuan_sanjia.csv

《开元占经》三家星官的原文条目，由 `scripts/sky_culture/sanjia.py` 从维基文库「唐開元占經 (四庫全書本)」卷六十五至七十提取
（原文缓存于 `scripts/sky_culture/_cache/`，不入库）。列：`school`（石氏、甘氏、巫咸）、`section`（中官、外官、中外官）、`ordinal`
（节内序号）、`title`（条目题名）、`definition`（定义句「某氏曰某某N星在……」）、`stars`（星数）、`note`（注文；石氏条目取含
「去極」者，即入宿度、去极度、黄道内外度）。原文字形照录，四库缺字（SKchar）作 □。

- 条数：石氏中官 62（实存 56）、石氏外官 30、甘氏中官 76、甘氏外官 42、巫咸 44，合 254，与传统「三家二百五十四官」相合
  （加二十八宿为 282，《晋书·天文志》作 283 官）。
- 订正四处（文件头注释逐条列出原文与理由）：匏瓜条题脱「占」、定义句脱「曰」；内五諸侯条题脱「占」；蓋屋条与泣条重号（十二→十三）。
- 四库本原阙石氏中官四十七至五十二（卷六十六止于太微四十六，卷六十七起于三台五十三）。
- 石氏 86 条实存条目全部带度数注文，供石氏星表检验用。

## shishi_xingjing.csv

石氏星表度数，由 `sanjia.py` 解析：二十八宿 27 条（亢宿条无去极度）、中外官 86 条。列：`ref`、`title`、`qualifier`（所测之星或距星描述）、
`lodge`、`ru_du`、`qu_ji`（古度）、`huangdao`（黄道内 +、外 −）、`width`（宿度）、`flags`、`note`（所据原文）。检验见 `sky_culture::tests_shishi`。

## sanjia_schools.csv

陈卓体系（Stellarium `chinese_chenzhuo`）317 个星官各属哪一家，由同一脚本据 `kaiyuan_sanjia.csv` 对出。列：`id`、`name`
（同 `chinese_asterisms.csv`）、`school`、`basis`（判定依据）、`source`（所据条目，家+节+序号）。

| 依据 | 含义 | 数 |
|---|---|---|
| 同名 | 繁简与异体字归一后同名 | 202 |
| 拆分 | 一条对应数官（攝提→左右摄提，河鼓「三星旗九星」→河鼓、鼓旗，库楼「十星五柱十五星衡四星」等） | 29 |
| 二十八宿 | 卷六十至六十三，石氏 | 28 |
| 别名 | 匏瓜即瓠瓜、北落即北落师门、帝席即帝坐(大角)、甘氏「天紀一星在外厨南」即天记等 | 18 |
| 方位 | 同名者按定义句方位区分（天田在右角北/牵牛南，从官在太子西北/房南等） | 13 |
| 附座 | 随所附之官 | 11 |
| 推定 | 五帝坐、内屏、郎位、郎将、常陈：四库本阙文处（石氏中官四十七至五十二）据序号推定，非原文明记 | 5 |
| 家括注 | Stellarium 自以「三公(甘氏)」等括注区分 | 2 |

天库（03L，一星）三家名录无此官，不归属。核对：可比的 235 官中，原文星数与陈卓成员数一致者 227；不一致 8 官中 6 官为原文
无星数的条目（如「老人星在弧南」），另 2 官为巫咸三公（原文「在北斗魁第一星西」未言星数）、天大将军（原文 11 星，陈卓复原 10 星）。

## system_periods.csv

各星官体系的适用年代（手工整理），星图「按时期」据此选体系。规则：各体系自其观测或成书历元起适用，至下一体系历元前一年止；
历元以前不用后出的认星结果，最早的陈卓体系兼作此前各代的兜底。列：`system`、`from_year`、`to_year`（天文纪年，空为不限）、
`epoch`（历元）、`basis`（依据）。

| 体系 | 适用年代 | 历元依据 |
|---|---|---|
| 陈卓 | —1051 | 陈卓（3 世纪）汇集三家星官，宋以前沿用 |
| 宋皇祐 | 1052—1362 | 皇祐四年（1052）实测 |
| 元《天文汇钞》 | 1363—1633 | 观测历元约 1363 年（Stellarium 说明据傅里叶分析与 Bootstrap 统计；旧说为郭守敬时代） |
| 明《象林》 | 1634—1673 | 1634 年 |
| 清《灵台仪象志》 | 1674—1743 | 1674 年；仅距星不同，星官与星名用《仪象考成》 |
| 清《仪象考成》 | 1744— | 1744 年测 |

明代钦天监的官方星官体系另有沿革（如《崇祯历书》1634 年已引入西法星表），本表只按现有数据的历元划分。

## pannai_table_9_1_4.csv

潘鼐《中国恒星观测史》第 641 页表 9.1.4：《仪象考成》二十八宿距星 1744 年赤经、赤纬与潘鼐「今测计算值」（1744.0）。十二宫赤经已化为度。
原表误差栏自检：危宿一、奎宿一两行与前栏之差不符；本项目推算与「今测值」栏相差 < 1″，可知误差栏误印（应为 +18″、+1′45″）。

## yuanshi_lodge_widths.csv

《元史·历志一·授时历议》「周天列宿度」，历代六次实测的赤道宿度：汉洛下闳、唐一行、宋皇祐、元丰、崇宁、至元。
取自维基文库 `元史/卷052`。

- **空栏**：原文例为空栏同左栏，脚本照此补齐。
- **分数**：少、半、太为 ¼、½、¾，强按 +1/12。至元栏以百分为度。
- **汉栏核对**：与《汉书·律历志》（`漢書/卷021`）逐宿一致。
- **至元栏核对**：取卷054「赤道宿度」。卷052 表中虚宿作 8.95、室宿作 17.11，卷054 作 8.9575、17.10。卷052 自身的北方小计与
  卷054 相合，故从卷054。
- **唐、皇祐两栏合计 365.33**：「虚十度少强」实为当时虚分（周天余数，约 10.256）。按 +1/12 读多出约 0.08 度，
  已在检验容差内。
