# 地磁：世界磁场模型 WMM2025 与磁偏角

网页罗盘（择日页二十四山图随手机朝向旋转）要的是**真北**，而手机指南针给的是**磁北**。两者之差为磁偏角 D（东偏为正），真方位 = 磁方位 + D。D 随地点、年份而变：中国东部现今约西偏 5°—10°，西部更小，且每年变动约 0.1°。本项目按世界磁场模型 WMM2025 计算。

## 一、模型与数据

| 项 | 内容 |
|---|---|
| 模型 | WMM2025（美国 NOAA/NCEI 与英国地质调查局联合发布，美国国防部、英国国防部与北约等的标准地磁模型；公有领域） |
| 系数 | `vendor/geomag/wmm2025/WMM.COF`（原样；高斯系数 g、h 至 12 阶及年变率 ġ、ḣ，历元 2025.0） |
| 有效期 | 2025.0—2030.0；期外 `Wmm::field` 返回 `None`、wasm 返回 NaN（`field_unchecked` 可外推，不受保证） |
| 精度 | 技术报告列有各要素的误差估计（数值本项目未逐页核）；误差主要来自模型不含的地壳磁场与外源场，高纬与磁异常区更大。作罗盘真北改正，远小于手机指南针本身的校准误差 |
| 代码 | `rust/core/src/astronomy/geomag.rs`：`Wmm::embedded()`（编译期嵌入）、`Wmm::from_repo()`、`field(lat, lon, alt_km, decimal_year) -> Option<GeomagField>`（X Y Z H F、I、D）、`decimal_year(y, m, d, h)` |
| wasm | `magnetic_declination_wasm(lat_deg, lon_deg, alt_km, decimal_year) -> f64` |

## 二、算法（技术报告第 1.2 节）

1. **时间外推**：g(t) = g(t₀) + (t − t₀) ġ，h 同。
2. **大地 → 地心球坐标**（WGS84：a = 6378.137 km，1/f = 298.257223563）：R_c = a / √(1 − e² sin²φ)，p = (R_c + h) cos φ，z = (R_c(1 − e²) + h) sin φ，r = √(p² + z²)，φ′ = arcsin(z / r)。
3. **球谐展开**（参考半径 a = 6371.2 km）：施密特半归一化缔合勒让德函数 P̆ₙᵐ(sin φ′) 由递推得（P̆ₙⁿ = √((2n−1)/2n) cos φ′ P̆ₙ₋₁ⁿ⁻¹；P̆ₙᵐ = [(2n−1) sin φ′ P̆ₙ₋₁ᵐ − √((n−1)² − m²) P̆ₙ₋₂ᵐ] / √(n² − m²)），导数同递推；
   X′ = −Σ (a/r)ⁿ⁺² Σ (g cos mλ + h sin mλ) dP̆/dφ′，Y′ = (1/cos φ′) Σ (a/r)ⁿ⁺² Σ m (g sin mλ − h cos mλ) P̆，Z′ = −Σ (n+1)(a/r)ⁿ⁺² Σ (g cos mλ + h sin mλ) P̆。
4. **转回大地坐标**：X = X′ cos(φ′−φ) − Z′ sin(φ′−φ)，Y = Y′，Z = X′ sin(φ′−φ) + Z′ cos(φ′−φ)。
5. H = √(X² + Y²)，F = √(H² + Z²)，I = atan2(Z, H)，D = atan2(Y, X)。

十进制年：年 + (年内日序 − 1 + 日内小数) / 年长日数。

## 四、罗盘与磁偏角（源流）

中国很早就记下磁针不指正南。沈括《夢溪筆談》卷二十四「雜誌一」：「方家以磁石磨針鋒，則能指南，然常微偏東，不全南也。」（据通行本，影印本未核）这是世界上关于磁偏角的早期明确记载之一。

风水罗盘有正针、缝针、中针三盘：正针以子午正对磁针，缝针（相传出杨筠松）较正针偏半格（7.5°），中针（相传出赖文俊）较正针反向偏半格。有一说以为缝针、中针是古人对磁偏角的校正，但三针的出处与本意诸家说法不一，此说未核，本项目不据以取舍。网页罗盘只做现代意义的真北改正：真方位 = 指南针磁方位 + WMM2025 磁偏角。

## 五、限制与待做

- 只含主磁场；地壳磁异常（局部可达数度）与磁暴等外源变化不计。
- 有效期外（2030 年后）须换用下一版 WMM。
- 手机指南针本身的校准误差常达数度，远大于模型误差；网页应提示用户校准。
