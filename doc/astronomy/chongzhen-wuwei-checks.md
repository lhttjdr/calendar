# 《崇禎曆書·五緯曆指》崇禎七—九年五星記錄检验

> 生成：`uv run --no-project --with skyfield python -I scripts/phenomena/chongzhen_wuwei_check.py`（仓库根）。录文：`data/phenomena/chongzhen_wuwei_observations.csv`。勿手改本文件。

## 来源

《崇禎曆書·五緯曆指》卷九（第八章「五星盈縮立成考」之后至第十章末），曆局所录崇禎七年（1634）至九年（1636）新法（西法）与大統曆推算之五星会合、凌犯、入宿与见伏，及「會同部監公同測驗」之结果（卷九，《故宫珍本丛刊》第 382 册书页 309—313）。卷末自云「此上所錄，皆係會同部監公同測驗過者，其未經測者，每年相差甚多，茲不備錄」，故所录本是择优之例，用以论证新法之密，不是随机样本。

原书所记以推算值为主：新法、大統各给时日、宫度、宿度与纬差，实测多为「果合」「委無水星出見」之类的定性结论，数值实测只有「相距不過一度」等少数。故本检验以 DE406 分别检核新法、大統推算之误差，实测则逐条判其与 DE406 天象是否相符。

## 方法

- 时刻：北京（116.4°E、39.9°N）地方真太阳时；曆局用九十六刻制，一时辰八刻（初、正各四刻），卯正二刻 = 06:30。历表 DE406（skyfield，ΔT 用其内置长期表）；恒星用 Hipparcos（I/311，含自行视差），積尸氣（M44）取星团中心。
- 坐标皆地心视位置、当日真春分点。新法黄道：黄经 360°，十二宫每宫 30°（鶉火 120°—150°、析木 240°—270°）；黄道宿度 = 行星黄经 − 距星黄经。新法赤道宿度 = 赤经差（360°），「出極一直線」即同赤经，「距夏至」= 赤经 − 90°。
- 大統宿度按授时—大统「黄道宿度」之定义：距星赤经圈投影到黄道之点起算（古黄道），化古度（×365.25/360）；兼给赤道古度备参。距星鬼 θ Cnc、張 υ¹ Hya、角 α Vir、軫 γ Crv（明清相同）。大統以至元十七年宿度为常数，不随岁差重算，本检验按当日距星位置投影，所差在十分之一度量级。
- 见伏：太阳在地平下 h 度（视界弧）时行星几何高度 ≥ 2° 为可见。h 取宽、严两档（宽：金 4°、木 7°、水 8°；严：金 6°、木 10°、水 11°，严档近托勒密所用值），DE406 见伏日给两档之间的区间，推算日落在区间内误差记 0，否则记到较近一端之日数。实测「见」须严档亦可见、「不见」须宽档亦不可见方判「合」，介于两档之间判「两可」。北京平地平、不计大气消光与星等变化，只作粗判。
- 会合、同度：在 ±12 日内求黄经差（或赤经差）变号之时刻。入鬼宿座：木星过「两星中线」即过两距星所定大圆之时刻（西侧鬼宿一 θ、鬼宿二 η；东侧鬼宿三 γ、鬼宿四 δ）。
- 误差 = 推算 − DE406；时日误差以日计（大統只给日，按当日正午计）。
