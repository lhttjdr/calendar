# 各家通书对照（一）：《類編曆法通書大全》与协纪神煞起例

协纪删改所据的底本是明清通书。本篇拿现存较早的一部通书——元末本《類編曆法通書大全》——和《欽定協紀辨方書》的神煞起例逐神对照，用来回答三个问题：协纪按语里说「通書誤以……」，指的旧说在通书里是不是真的这样写；协纪删掉或改定的神，通书原来怎么排；哪些通书旧法值得在本项目里做成「类编」选项。

逐神对照表：[data/folk/tongshu_leibian_vs_xieji.csv](../../data/folk/tongshu_leibian_vs_xieji.csv)，共 131 行，列为 `神,协纪起例,类编起例,异同,类编页,说明`。

## 一、版本与方法

**类编**：题「(元)宋魯珍通書」，北京大学图书馆藏，archive.org 影像十五册 `02094403.cn`—`02094417.cn`，存在 `doc/references/folk/通書/類編曆法通書大全/`（不入库）。卷一《前朝公規》有「至正二十四年新降春牛經式」，所以是元末本；书中又有「宣德元年丙午」「宣德十年乙卯」的推例（卷十五暗金殺），说明现存本含明初增补，不全是元本原貌。各卷所在册、PDF 页的换算如下（PDF 页 = 卷内页序 + 偏移，偏移是同册前几卷的页数之和加封面 1 页）：

| 册 | 卷 | PDF 页 |
|---|---|---|
| 02094404 | 卷二、卷三 | 卷二第 k 页 = k+1 |
| 02094405 | 卷四、卷五 | 卷四第 k 页 = k+1 |
| 02094406 | 卷六、卷七 | 卷六第 k 页 = k+1 |
| 02094407 | 卷八至卷十 | 卷十第 k 页 = k+77 |
| 02094410 | 卷十三（年吉凶神）、卷十四（月吉凶神）、卷十五（日吉凶神） | k+1、k+21、k+51 |
| 02094411 | 卷十六（时家）、卷十七（诸神释义） | k+1、k+43 |
| 02094417 | 卷二十八（丧葬）、卷二十九、卷三十 | k+1、k+51、k+107 |

**协纪**：月家神煞取本项目 [data/folk/shensha_month.csv](../../data/folk/shensha_month.csv)（卷五、卷六按语定论，63 神）；年神取 `rust/core/src/folk/nianshen.rs`（卷三）；原文据维基文库四库本录文 `vendor/folk/wikisource/欽定協紀辨方書/`。

**方法**：先用识典古籍的类编 OCR 文本（`CADAL02094403` 各卷）逐神检索同名、异名，定位到页，再逐页看影像、以影像为准。识典 OCR 多形近误字（戌/戍、巳/已/己、申/甲、午/牛、寅/演），表格常错行（如卷十五天地争雄与天狗下食两列被拼成一行），所以凡表中「異」与「協紀無」的起例都对过影像。

**类编的神煞分布**：月家日神主要在卷十五「日吉凶神」（PDF 52—64 页为逐月表）；卷十四「月吉凶神」是方位（如天德作四维）；卷十三是年神；卷十七是诸神释义（多为方位义）；鸣吠、复日的旧说在丧葬诸卷（卷二十八、二十九）。

### 协纪按语与类编的对应

- **鸣吠、鸣吠对**：协纪卷五按语说「通書誤以庚寅壬寅為鳴吠，甲午為鳴吠對」。类编十四日表正是多出庚寅、壬寅，十日表正好有甲午，与按语完全吻合。类编卷二十八「論斬草」还自己改过一处：「舊本用庚子日斬草，乃是甲子日……今依道藏經改正，庚午對甲子謂之鳴吠對」，可见元明之间鸣吠对已有几种传本。
- **复日**：协纪卷首奏议斥「通書因誤以正月之庚日七月之甲日皆為復日」，就是类编所引百忌歌的两干说（卷十七作劒鋒、卷二十九作重喪重賻）。类编自己的结论取一干说，但季月三说并列、没有定论，协纪的季月取法（月建所藏之干）与三说都不同。
- **天火**：协纪说《歷例》原文是「正月在子順行四仲」，类编正是如此，协纪改为逆行。
- **天德四仲**：协纪说四维没有十干，所以不得有其日；类编日表直接把四维换成邻近的孟支，四仲照样有天德日、天德合日。这是协纪没有明说的通书写法。
- **蚕命**：协纪卷三引「今之蠶命子年未丑年午寅年亥……亥年酉」，谓「此恐有悞」。类编卷十三的蚕命与这串字逐字相同。
- **守日、牢日**：协纪说《歷例》原以春辰夏未秋戌冬丑为牢日，类编正作牢日，可以作为《歷例》旧名的旁证。
- **天愿、地囊、四击**：协纪说天愿「二十四字中誤十三字」、地囊「四十八字中誤二十三字」，又引「通書」四击；类编三神都没有起例（地囊只在卷四动土条里出现名字），无从核对。协纪所说的通书，应是比此本晚的明清本。
- **灾煞、天狱**：协纪说月家灾煞「舊歷缺」，类编月家也没有（年家、日家方位才有）。类编没有四仲天狱，只把「天獄」当作朱雀黑道的别名；乾隆时宪书朱字里的天狱旧法（正月起子顺行四仲）不出自此本。

### 类编无的协纪月神（24）

天愿、四相（只有「相日」，相日的干部分就是四相）、时德、官日、民日、四击、五墓、四忌、四穷（类编只有「四忌五窮」的名字）、八风、解神、三合、临日、天后、月害、天吏、兵吉、阳德、阴德、天马、兵禁、地囊、灾煞、天狱。其中兵吉是类编有意不收：卷六「論兵吉……二月用寅日為兵吉，其日與兵禁日同，恐難信用，今不收入」（02094406:13）。

年神中类编无岁干合、岁枝德、群丑三神。另有一点：类编「歲合」是岁支六合（子年丑），不是岁枝德。

### 荒芜：前文的更正

[shensha.md](shensha.md)「时宪书朱字」一节说类编卷十种植门凶日表的荒芜是「按季三支」，这是误读。影像（02094407:93）是一月一支：巳酉丑辰申子卯未亥寅戌午，卷十各门、卷十五表都是如此。按季三支是协纪所引宗镜与时宪书的写法，类编所写的正是协纪所驳的「一月止忌一字」。类编卷十五新增起例另给「孟平仲破季收」一法，也是一月一支，但次序不同，而且该书各表并未据此改动。

## 四、与时宪书朱字的关系

乾隆三十年时宪书的朱字中，有四神协纪不载或已删，钦天监沿用通书（见 [shensha.md](shensha.md)）。它们在类编中的情况：

| 朱字 | 时宪书起例 | 类编 |
|---|---|---|
| 荒芜 | 按季三支（即五虚） | 有，但一月一支（两种次序），与时宪书不同 |
| 枯焦 | 同九焦（九坎） | 无此名，作「焦坎」，起例相同 |
| 四不祥 | 初四、初七、十六、十九、二十八 | 有，相同（卷二） |
| 天狱 | 正月起子顺行四仲 | 无；但天火正是这个顺行四仲，或许时宪书天狱旧法与通书天火同出一源，未核 |

所以时宪书朱字所据的通书不是这个元末本：荒芜取法不同，「枯焦」之名不见，天狱旧法也没有。

## 五、类编选项（已实现）

各家宜忌照录并列、协纪为默认（见 shensha.md「待做」）。类编与协纪起例不同、且类编自身前后一致的六组，已做成神煞起例选项：月家日神在 `rust/core/src/folk/shensha.rs`（`ShenshaOptions`，逐神可选；`shen_for_day_with`），年神蚕命在 `rust/core/src/folk/nianshen.rs`（`NianShenOptions`；`nian_shen_with`、`by_position_with`）。缺省全依协纪，原有的 `shen_for_day`、`nian_shen`、`by_position` 不变；`ShenshaOptions::leibian()` 全依类编（复日取所列三曆之首《集正》，鸣吠取十四日，鸣吠对取「鳴吠對日」正表十一日，荒芜取表序）。

选项只改「当日所值之神」的列出，不改协纪月表的宜忌（`yiji.rs` 的月表是按协纪卷十、卷十一推出并与影印本逐页核过的，属协纪一系）；类编自己的宜忌体系（卷十一逐月日表）尚未录入。
