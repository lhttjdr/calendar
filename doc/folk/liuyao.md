# 六爻纳甲筮法与起卦

只排卦（装卦），不断吉凶。代码：`rust/core/src/folk/liuyao.rs`（经文卦名取 `zhouyi::text`）；《周易》本身的揲蓍与取辞见 [zhouyi.md](zhouyi.md)。

## 源流

- **纳甲筮法**出于西汉京房：以八宫统六十四卦（每宫本卦、一世至五世、游魂、归魂），配世应，以纳甲、纳支给六爻配干支五行，以宫五行定六亲。原书《京氏易傳》（题汉京房撰，吴陆绩注）。
- 宋代《火珠林》（托名麻衣道者）以钱代蓍，用世应、六亲、飞伏、卦身断卦，为后世「火珠林法」之祖。
- 明清以下：《卜筮正宗》（清王洪绪）、《增刪卜易》（清野鹤老人著，李文辉增删）、《黄金策》（托名刘基）等，装卦法大同，于卦身、用神、六神之取舍有异。
- 《梅花易數》题宋邵雍，以数起卦（年月日时、物数、声音、字），用体用生克断卦；书序（维基文库本题「清黃宗羲撰」）及成书年代皆存疑，本项目只照录其起卦之法。

## 装卦规则

| 项 | 规则 | 出处 |
|---|---|---|
| 八宫与世应 | 本宫首卦依次变初、二、三、四、五爻得一世至五世；五世复变四爻为游魂；游魂内卦复本宫为归魂。世：本宫六、一世至五世依次、游魂四、归魂三；应隔世两位 | 《京氏易傳》；《增刪卜易》八宮圖第三、世應章第六「乾爲天世在六，天風姤世在初……火地晉世在四，火天大有世退在三」 |
| 纳甲（天干） | 乾内甲外壬、坤内乙外癸、震庚、巽辛、坎戊、離己、艮丙、兌丁 | 《京氏易傳》卷下「分天地乾坤之象，益之以甲乙壬癸……震巽之象配庚辛……坎離之象配戊己……艮兌之象配丙丁」 |
| 纳支 | 乾在内子寅辰、在外午申戌；坎内寅辰午、外申戌子；艮内辰午申、外戌子寅；震同乾；巽内丑亥酉、外未巳卯；離内卯丑亥、外酉未巳；坤内未巳卯、外丑亥酉；兌内巳卯丑、外亥酉未 | 《增刪卜易》渾天甲子章第四（录文「辰在內」为「艮在內」之讹） |
| 六亲 | 以本宫五行为我：同我兄弟、我生子孙、我克妻财、克我官鬼、生我父母；乾兌金、坎水、艮坤土、震巽木、離火 | 《增刪卜易》六親歌章第五；变爻六亲仍以本卦之宫论（同书动变章「變出之爻安六親者仍照正卦而推」） |
| 六神 | 甲乙日初爻青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武，自初而上依青龙、朱雀、勾陈、螣蛇、白虎、玄武 | 《增刪卜易》六神章第十八表 |
| 伏神 | 本卦所缺之六亲，取本宫首卦同位之爻为伏神 | 《火珠林》「本宫之六亲在飞象之下，为之亲王，为之伏神」 |
| 旬空 | 日干支所在之旬所空二支（甲子旬戌亥……甲寅旬子丑） | 通法 |
| 卦身 | 阳世从子起、阴世从午起，自初爻数至世爻 | 《火珠林》「阳世则从子月起，阴世还当午月生，此即卦身也。而《元龟》以月卦言之，所以吉凶不应」 |
| 月建、日辰 | 由调用方给出：月建以交节换月（与本项目干支历同），日辰为当日干支 | — |

## 各说差异

| 项 | 各说 | 本项目 |
|---|---|---|
| 卦身 | 《火珠林》阳世子起、阴世午起；《元龟》以月卦言之（火珠林斥「吉凶不应」）；《增刪卜易》「古以身爲卦身……予試之不驗，後遇身者卽以之爲世」，不用 | `GuaShenRule::HuoZhuLin`（缺省）、`None` |
| 六神 | 《增刪卜易》六神章表戊日初爻勾陈、己日初爻螣蛇；同章「戊子日占生產，得山地剝變風地觀」例初、二爻作「滕蛇」「勾陳」，与表互倒 | 从表（例中上四爻与表全合，初二两爻疑录文互倒，未以刻本核） |
| 伏神 | 《火珠林》取本宫首卦；京房《易傳》另有各卦「與某為飛伏」之说（卦与卦相配） | 取《火珠林》法；京房飞伏未实现 |
| 掷钱 | 三钱一掷：背为阳、字为阴（或反之），各家约定不一 | 调用方径给 6—9，`qian_to_value` 以阳面个数映射（三阳老阳九、二阳少阴八、一阳少阳七、零阳老阴六，即「單拆重交」） |

## 起卦

- **掷钱**：输入初至上六爻之数（6 老阴、7 少阳、8 少阴、9 老阳）。
- **梅花易数年月日时**（卷一「年月日時起例」）：年支数（子一……亥十二）＋农历月数＋农历日数，以八除得上卦；加时支数以八除得下卦；总数以六除得动爻；卦以先天数（乾一兌二離三震四巽五坎六艮七坤八），余零作八（坤）、作六（上爻）（卷一「卦以八除」「爻以六除」）。年支、农历月日由调用方按本项目农历给出（年以正月初一换，梅花原文未明言，未核）。
- **数字起卦**（卷一「物數占例」「聲音占例」）：所见之数作上卦，加时数作下卦，两数并以六除取动爻。
- **互卦**（卷一「互卦起例」）：去初、上爻，二三四爻为下卦、三四五爻为上卦；「乾坤無互」（互仍乾坤）。
