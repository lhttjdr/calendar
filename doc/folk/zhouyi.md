# 《周易》筮法：大衍揲蓍与取辞

只成卦、给出应读之辞，不断吉凶。代码：`rust/core/src/folk/zhouyi.rs`；经文表 `rust/core/src/folk/zhouyi_text.rs`（由 `scripts/folk/gen_zhouyi_text.py` 自维基文库录文生成，勿手改）。京房纳甲装卦见 [liuyao.md](liuyao.md)。

## 揲蓍成爻

《周易·繫辭上》：「大衍之數五十，其用四十有九，分而為二以象兩，掛一以象三，揲之以四以象四時，歸奇於扐以象閏，五歲再閏，故再扐而後掛。」

一变：所用之策分为左右两堆；自右取一掛之；左右各四四数之，余（奇）一至四（余零作四），归奇于扐。所去之策＝掛一＋左奇＋右奇。第一变用四十九策，所去必五或九；第二、三变用余策（四十四或四十），所去必四或八。三变之后余策三十六、三十二、二十八、二十四，以四除之得九（老阳）、八（少阴）、七（少阳）、六（老阴）。十八变成卦。

| 函数 | 说明 |
|---|---|
| `dayan_change(total, left)` | 一变：给所用策数与左手所分之数，返回所去之策 |
| `dayan_yao([l1, l2, l3])` | 三变成一爻，返回 6—9 |
| `dayan_yao_from_random([r1, r2, r3])` | 以调用方所给随机整数定每变之分（left = 1 + r mod (total − 2)）；模块不取系统随机，结果可复现 |
| `dayan_steps([r; 18])` | 十八变逐变详情：所用之策、分左右、掛一后右余、左右之奇、所去、余策，三变之末给爻数；与 `dayan_yao_from_random` 同法（每三个 r 成一爻，结果相同，测试 `dayan_steps_same_as_yao` 随机 200 卦验之） |
| `dayan_probabilities()` | 设每变左手之余一至四等可能，得六、七、八、九各 1/16、5/16、7/16、3/16 |
| `coin_probabilities()` | 掷三钱：1/8、3/8、3/8、1/8 |

揲蓍与掷钱之别：揲蓍老阴最少（1/16）、老阳 3/16，阴阳之变不对称；掷钱老阴老阳各 1/8。

## 取辞之法（朱熹《易學啟蒙·考變占》）

据元胡方平《易學啟蒙通釋》（四库本）卷下所录启蒙原文（`vendor/folk/wikisource/易學啟蒙通釋/卷下.wikitext`「考變占第四」）：

| 变爻数 | 原文 | 实现 |
|---|---|---|
| 0 | 凡卦六爻皆不變則占本卦彖辭而以内卦為貞外卦為悔 | 本卦卦辞 |
| 1 | 一爻變則以本卦變爻辭占 | 本卦该爻辞 |
| 2 | 二爻變則以本卦二變爻辭占仍以上爻為主（經傳無文今以例推之當如此） | 本卦二变爻辞，上爻主 |
| 3 | 三爻變則占本卦及之卦之彖辭即以本卦為貞之卦為悔前十卦主貞後十卦主悔 | 本卦（贞）、之卦（悔）卦辞；主次见下 |
| 4 | 四爻變則以之卦二不變爻占仍以下爻為主（經傳亦無文今以例推之當如此） | 之卦二不变爻辞，下爻主 |
| 5 | 五爻變則以之卦不變爻占 | 之卦不变爻辞 |
| 6 | 六爻變則乾坤占二用餘卦占之卦彖辭 | 乾用九、坤用六；余卦之卦卦辞 |

**三爻变之主**：《啟蒙》「前十卦主貞，後十卦主悔」，次序依其六十四卦变图（三十二图）。其注举乾三爻变「自否至恒為前十卦，自益至泰為後十卦」：否（变初二三）、恒（变初五上）皆含初爻，益（变二三四）、泰（变四五上）皆不含；三爻之二十种变法每两两互补，恰各一含初爻。据此推定前十卦即初爻在变爻之中者（`SanBianZhu::ChuYaoZaiBian`，缺省）；另设不分主次、两卦并列之选项（`SanBianZhu::Both`）。

**以明人图说核**：明韩邦奇《啓蒙意見》述三十二图三爻变之次：「初二三三變、初二四三變、初二五三變、初二六三變，凡四。初三四……初三六，凡三。初四五、初四六，凡二。初五六，凡一。二三四……二五六……三四五……四五六三變，凡一」，即变位之字典序，前十皆含初爻，与推定合；辛賢据之重构三十二图，乾例「否（123）、漸（124）、旅（125）、咸（126）、渙（134）、未濟（135）……泰（456）」，第十为恒、第十一为益，正合《啟蒙》注「自否至恒」「自益至泰」（辛賢〈『易学啓蒙』「考変占」の卦変三十二図――韓邦奇『啓蒙意見』にもとづいて〉，《大阪大学大学院人文学研究科紀要》第 1 号，2024，§二(3)「三爻変」，第 4—5 页，doi:10.18910/94809）。测试 `san_bian_order_han_bangqi` 依此次序验乾例与主贞、主悔之分。此为明人图说与今人重构，宋元刻本《易學啟蒙》或《通釋》影印本之图仍未见（维基共享资源未检得书影；京都大学、东北大学所藏本有在线书影待核），故仍注「据韩邦奇说」而非原图。

## 他说

- 《啟蒙》本身指出穆姜例中「史妄引隨之彖辭以對則非也」——史官以之卦卦辞对，朱子不取；左传国语筮例中「之八」「皆八」之读法，今人（如高亨《周易古經今注》）另有解，降权，未实现。
- 三爻变之主次另有取「以本卦为主」等说，未见原典，未实现。
