# 玄空飞星

风水理气之一派：以三元九运之运星入中宫，按洛书数序飞布九宫为运盘；取坐山、向首所在宫的运星入中，按二十四山阴阳顺逆飞布，得山盘、向盘；三盘合观，论旺衰与格局。

## 一、源流与原典

- **经**：题唐杨筠松《青囊奧語》《天玉經》、题曾文辿《青囊序》，及《都天寶照經》。皆隐语，不明言排法。
- **蒋大鸿《地理辨正》**（清初）：注上述诸经，力辟三合、五行诸家，倡「玄空大卦」，然自序明言「有訣無書……天律有禁，不得妄傳」，排法仍不著于书（维基文库录文《地理辨正》序）。
- **章仲山**（清中叶）《心眼指要》《宅運新案》：以宅例示运盘、山向盘，世称无常派之祖。原书未见。
- **沈竹礽《沈氏玄空學》**（沈氏卒于 1906 年，书于民国由其子沈祖绵整理刊行）：首次系统写出飞星排法——运星入中、山向星入中按阴阳顺逆、替卦起星、城门诀等，为今日通行排法之所本。原书未见（archive.org 有 2009 年华龄出版社《增廣沈氏玄空學》，借阅受限，未核）。
- **四库本《天玉經》注**：读「江東一卦」「江西一卦」「南北八神」为「寅甲卯乙辰巽巳丙共為江東卦……申庚酉辛戌乾亥壬共為江西卦……午丁未坤子癸丑艮共為一卦」（影印本第 6 页），是三合式的读法，与玄空家以之为卦运者不同；两读并存，本模块不取三合读法。

按资料可靠性：经文只有隐语，沈氏排法是今日唯一系统的成文规则，但原书未核；以下凡出沈氏者皆注「出处未核」，待取得沈氏原刊（或章仲山原书）影印再核。

## 二、排法

| 项 | 规则 | 出处 |
|---|---|---|
| 运 | 三元九运，康熙二十三年（1684）为上元甲子，每运二十年（另说五运前十年寄四、后十年寄六） | 协纪卷八（三元）；九运分法未核（见 taiyi.md） |
| 运盘 | 当运之星入中，按洛书数序（中→乾六→兑七→艮八→离九→坎一→坤二→震三→巽四）顺飞 | 沈氏，未核 |
| 二十四山归宫 | 壬子癸坎、丑艮寅艮、甲卯乙震、辰巽巳巽、丙午丁离、未坤申坤、庚酉辛兑、戌乾亥乾；每宫三山依次为地元、天元、人元 | 通行 |
| 二十四山阴阳 | 四正宫（坎震兑离）地元阳、天元人元阴；四隅宫（坤巽乾艮）地元阴、天元人元阳。即甲庚丙壬、乾坤艮巽、寅申巳亥阳，子午卯酉、乙辛丁癸、辰戌丑未阴 | 沈氏，未核（《青囊奧語》「左為陽，子癸至亥壬；右為陰，午丁至巳丙」为另一义，非此） |
| 山盘、向盘 | 取运盘坐山（向首）所在宫之星 m 入中；以 m 之原宫与坐山（向首）同元之山的阴阳定顺逆，阳顺阴逆 | 沈氏，未核 |
| 五黄入中 | m 为五（无原宫）：缺省依坐山（向首）本山阴阳（`WuRule::BenShan`）；另说依运星之宫同元之山（`WuRule::YunGong`） | 未核 |
| 替卦（起星） | 兼向逾限，以 m 原宫同元之山的「替星」入中：《青囊奧語》「坤壬乙，巨門從頭出；艮丙辛，位位是破星；巽辰亥，儘是武曲位；甲癸申，貪狼一路行」定十二山；余十二山扩为子→一、卯未→二、乾戌巳→六、酉丑→七、寅午庚丁→九 | 奥语四句据维基文库录文；扩表出沈氏，未核 |
| 替卦顺逆 | 缺省仍依原星原宫同元之山阴阳（`TiShunRule::YuanXing`）；另说依替星之宫（`TiXing`） | 未核 |
| 兼向限度 | 偏离本山中线逾 3° 用替卦（`ti_threshold_deg`，可调） | 通行，未核 |
| 空亡 | 距山界 1.5° 以内：同宫两山之间为小空亡，两宫之间为大空亡（`kong_wang_deg`，可调） | 未核 |
| 流年、流月 | 年星、月星入中顺飞（年月九星见 jiuxing.rs，协纪卷八）；日、时紫白协纪未收，不提供 | 协纪卷八 |

坐山以方位角给出时（网页罗盘测得之真北方位角），子山中线为 0°，每山 15°。古罗盘有正针、缝针、中针之别（相差半山），本模块用正针（以真北为子午），缝针、中针待考。

## 三、格局

| 格局 | 判法 | 出处 |
|---|---|---|
| 旺山旺向 | 当运山星到坐宫、向星到向宫 | 沈氏，未核 |
| 上山下水 | 当运向星到坐宫、山星到向宫 | 同上 |
| 双星到向（会向） | 当运山星、向星同到向宫 | 同上 |
| 双星到坐（会坐） | 当运山星、向星同到坐宫 | 同上 |
| 伏吟、反吟 | 山盘（向盘）与元旦盘（五入中顺飞）同为伏吟，合十（五入中逆飞）为反吟 | 未核；他说以运盘为准，未做 |
| 合十 | 各宫山星（向星）与运星合十 | 未核 |
| 连珠三般卦 | 各宫运、山、向三星为相连三数（含九一相接） | 未核 |
| 父母三般卦 | 各宫三星为一四七、二五八、三六九之一 | 未核 |
| 城门诀 | 向宫左右两宫，与向宫成河图之配（一六、二七、三八、四九）者为正城门，另一为副城门；城门宫之运星入中，依其原宫与向首同元之山阴阳，阳（顺飞）则可用 | 未核 |

**顺逆定理**（由排法推得，测试遍历验证）：坐、向两宫洛书数和十，故（下卦）山盘逆飞必旺山、向盘逆飞必旺向；山顺向逆必双星到向，山逆向顺必双星到坐，山向俱顺必上山下水。九运×二十四山 216 局逐一与 `ge_ju` 相合。
