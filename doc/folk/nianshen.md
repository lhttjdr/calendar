# 年神方位

《協紀辨方書》卷三「義例一」诸年神：按年干支定其所在方位（二十四山：十二支、八干、四维）。时宪书卷首印「年神方位之圖」。

| 内容 | 位置 |
|---|---|
| 起例与求值 | `rust/core/src/folk/nianshen.rs`：`nian_shen(年干支序)` 返回各神及方位；`by_position` 按二十四山（自子顺行）列各位所临之神，不含岁德、岁德合（时宪书另行印「歲德在某合在某」）与岁干合、岁枝德（见下） |
| wasm | `folk_day_wasm` 结果的 `nian_shen`：「歲德在某合在某；子：……」，年以立春分（与年九星同） |
| 网页 | 民俗栏「年神方位（《协纪辨方书》卷三）」一行 |
| 测试 | `nianshen::tests`：乙酉年对时宪书图；六十年遍历卷三按语所述诸神同位关系 |

## 按日之神（卷三末）

| 神 | 起例 | 实现 |
|---|---|---|
| 太岁出游日 | 甲子东游、丙子南游、戊子游中宫、庚子西游、壬子北游，各五日，至己巳、辛巳、癸巳、乙巳、丁巳还位，共二十五日（《厯例》） | `tai_sui_chu_you` |
| 日游神 | 癸巳至丁酉房内北，戊戌己亥房内中，庚子辛丑壬寅房内南，癸卯房内西，甲辰至丁未房内东，戊申又中，己酉出游四十四日（《厯例》）；「載於時憲書」 | `ri_you_shen` |
| 鹤神 | 卷三按语引婁元禮《田家五行》：己酉下地东北，乙卯正东，庚申东南，丙寅正南，辛未西南，丁丑正西，壬午西北，戊子正北，癸巳上天（十六日）；四维六日、四正五日 | `he_shen` |

协纪按语谓鹤神「暗與日遊神相應」：日游神在室十六日即鹤神上天十六日。六十日逐日检验，两者全合（`nianshen::tests::daily_spirits`）。网页民俗栏于年神方位下列当日日游神、鹤神与太岁出游。

## 检验

**内在关系**（六十年遍历，全部成立）：博士与奏书对冲，蚕室与力士对冲，豹尾与黄幡对冲，灾煞居劫煞前一辰；以及卷三按语自述的同位：黄幡豹尾总论「子午夘酉年黄幡即是官符、豹尾即是弔客；寅申己亥年黄幡即是白虎、豹尾即是喪門；辰戌丑未年黄幡即是太歲、豹尾即是歲破」，飞廉按语「子丑寅午未申年飛廉即是白虎，夘辰巳酉戌亥年飛廉即是喪門」，五鬼按语「子午年與官符同位，丑未年與喪門同位，寅申年與太歲同位，夘酉年與大隂同位，辰戌年與白虎同位，己亥年與歲破同位」，群丑只在四孟年。
