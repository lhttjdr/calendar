# 子平命理

读者站对应章：民俗篇《子平八字》（`site/folk/ziping.md`）。本文记子平诸项起例的原典、各家异同、本项目的实现与逐条检验。只做原典规则能机械推出的部分（四柱、十神、藏干、长生、大运小运、胎元命宫、空亡、神煞、月令取格），不作吉凶判断；格局、用神只述各家体系。四柱的年月日时界见 [ganzhi-calendar.md](ganzhi-calendar.md)，纳音见 [nayin-zhiri.md](nayin-zhiri.md)。

源流要点（读者站第一节据此写）：
1. 唐李虚中以生年月日三柱（年为主，见下）推命；四柱（加时）「其説實起於宋」（四库提要）。
2. 主柱之争：《三命通會》卷二《論年月日時》并存「古法以年看，子平以日看」与「唐李虚中獨以日干為主」两说；《淵海》卷二《喜忌篇》「專以日上天元」、卷四《實法第一》「子平一法，專以日干為主，而取提綱所用之物為命」（引文已见 [ganzhi-calendar.md](ganzhi-calendar.md)）。
3. 明代集成：《淵海》以起例、格局、赋诀为体；《三命通會》采撮群言而好取神煞纳音，四库提要评其「多取正官正印正財，而不知偏官偏印偏財亦能得力」。
4. 清代转向：《子平真詮》专以月令定用神、论成败救应，斥神煞（《論星辰無關格局》）；《滴天髓》论旺衰、清浊、顺逆；《窮通寶鑑》论十干逐月调候；《命理約言》驳分日司令、驳过分依赖神煞。

## 三、四柱

四柱排法、各家年月日界、平气与夜子时见 [ganzhi-calendar.md](ganzhi-calendar.md)。子平取立春换年、十二节换月、子正换日（`folk::ganzhi_presets::zi_ping_ba_zi`），`ZipingOptions` 取其日界与定气平气；夜子时时干缺省依次日（`YeZiShi::CiRi`，袁树珊），可改依当日。`pan.rs` 自行比交节时刻（TT），日柱时柱按 `clock_utc_offset_hours` 所指时区的钟点（历法域 `ganzhi_from_jd_solar` 的输入时间尺度不明，不用）。

## 四、十神

《淵海》卷一《論五行相生相尅訣》（书影 n5）：「生我者為正印偏印，我生者為傷官食神，尅我者為正官七殺，我尅者為偏財正財，比者為劫財敗財。其法陽見陰為正，陰見陽為正，陽見陽為偏，陰見陰為偏。如甲丙戊庚壬屬陽，乙丁己辛癸屬陰是也。」比和者同阴阳为比肩、异阴阳为劫财。别名：七杀 = 偏官，偏印 = 枭神、倒食，正印 = 印绶；劫财 = 败财（阳干之劫财即阳刃所藏）。

实现：五行序木火土金水，差 0 比、1 我生、2 我克、3 克我、4 生我，再分同异阴阳。测试 `shishen::tests::table`（甲日、癸日十干，每日干十神各一）。

- 《淵海》歌诀（书影 n5 左页末）：「子宮單癸水，丑癸己辛逢，寅還見甲丙，卯宮獨乙木，辰藏癸戊乙，巳丙戊庚中，午宮丁己土，未內乙己丁，申宮庚壬戊，酉內獨辛金，戌宮辛丁戊，亥宮壬甲從」。寅句首字残损，以五字句读作「寅還見甲丙」，寅无戊（申有戊、巳有戊，与寅不对称），**待他本核**。
- 《三命通會》首段是逐月「用事」之干：四库之墓取阳干（辰壬、戌丙、丑庚、未甲），与他表之阴干（癸、丁、辛、乙）不同；子午卯酉兼前月余气。
- 通行表：《子平真詮·論用神變化》「以寅論，甲為本主……丙其長生……戊亦長生」，《論雜氣如何取用》「辰本藏戊，而又為水庫，為乙餘氣」；《神峰通考》「辰有乙戊癸……戌中有辛戊丁……丑中有癸巳（己）辛……未中有丁己乙」；《三命通會》卷二《論地支》亦言「未中有乙木有丁火」「巳……庚金寄生……戊土歸祿」「午……巳（己）至此為歸垣」。全表未见原书列成一表，真詮取格依之，故作缺省。
- 《子平真詮》「十二支中，除子午卯酉外，餘皆有藏」——午只丁、不藏己？与通行表午丁己不合，书中无他处明文，**未改**。
- 实现：`cang_gan` 返回本气在前、余按原书次序；`ben_qi` 寅甲、申庚、巳丙、亥壬、子癸、午丁、卯乙、酉辛、辰戌戊、丑未己。

- 实现：`si_ling_with(月支, 交节后日数, SiLingTable)`，缺省 `SanMing`；`JiuLi` 以百分之一日存，申月首段「戊己」以戊计。交节后日数由 `pai_pan` 以节气时刻精确算出（`BaziPan::days_since_jie`）。测试 `canggan::tests::{tables, si_ling_days}`。

## 七、大运与起运

### 1. 排法

《淵海》卷一《論起大運法》（书影 n3）：「陽男陰女順，以三日為一歲，數至未來交節成幾歲行運；陰男陽女逆，以三日為一歲，數至過去交節成幾歲行運……俱以月令上取，如男陽命甲子月出門行乙丑運……女陽命甲子月出門行癸亥運」。阳男阴女依年干阴阳与性别（阳年男、阴年女顺），自月柱顺排；阴男阳女逆排。每运十年。《三命通會》卷二《論大運》同（「陽男隂女大運以生日後未來節氣日時為數順而行之，隂男陽女……以生日前過去節氣日時為數逆而行之」）。「論節不論氣」：只数十二节，不数中气。

### 2. 起运岁数的折算

交运时刻：《三命》「必自十二月生日後實經歷過二十有一之日月運方移宫」，《淵海》「行運之法……甲子年正月初一日子時正一刻生，行運筭至乙丑年正月初一日子時正一刻乃作一歲，其年內小六個月即進六日……却為本年有閏月乃多一月矣，當退還」——两书都按历月实数。本项目以「起运岁数 × 回归年（365.2422 日）」加于生时，得 `QiYun::start_jd_tt` 与各运 `DaYun::start_jd_tt`；与按农历月逐月加之法相差在数日之内，**未按历月实现**。起运岁数为实岁（满岁）；虚岁加一由调用方自理。

### 命宫、身宫

《淵海》卷一《論安身命法》：「其法不論男女，每從子上起正月，逆數至本生月止，從生月上起生時，順數遇卯即安命也。假如四月寅時生，正月在子上，逆數二月在亥，三月在戌，四月在酉，却於酉上起本生寅時，順數至戌上卯，即戌宮坐命也。再數至酉即安身也。」《三命通會》卷二《論坐命宫》同，例「甲子年三月生人得戌時……逄卯便是即命坐卯宫……甲巳之年丙作首乃丁夘宫也」，干由年干五虎遁。

公式：命宫支 = 4 − 月 − 时 (mod 12)（月以正月为 1，时以子为 0）。身宫：「再數至酉」，所起之时数到酉处，恒在命宫对冲；《神峰通考》卷一「原取逢卯安命，逢酉安身」（录文）同此读。

生月依节（`MingGongMonth::Jie`，缺省，两书只言「本生月」）；以中气定月（过中气作下月）为今人一说，作选项。正月加子实即太阳在子宫（玄枵，大寒至雨水）之时，命宫法本出星命「太陽加時，卯上安命」，但两书都按「月」不按「中气」立说，故缺省依节。

## 十、格局与用神

各家体系（只述，不作机械判断）：
- **《淵海子平》**：卷三起逐格列正官、偏官（七杀）、印绶、正财、偏财、食神、伤官、倒食、杂气、日德、日贵、魁罡、金神、时墓等，外格甚多（目录书影 n0）。
- **《三命通會》**：卷五、卷六列正格与外格数百（飞天禄马、井栏叉、壬骑龙背、六阴朝阳……），多据神煞纳音；四库提要讥其偏取正官正印正财。
- **《神峰通考》**：倡「病药」——「有病方為貴，無傷不是奇」，以八字中所害之神为病、去之者为药，又有动静、盖头诸说。
- **《子平真詮》**：「八字用神，專求月令」（《論用神》）；以月令所藏、透干会支定格，论成败救应、相神；四吉神（财官印食）四凶神（杀伤枭刃）顺用逆用；「星辰無關格局」；外格（从化、一行得气）只在月令无用时取。
- **《滴天髓》**：论衰旺、中和、清浊、顺逆、从化，任铁樵阐微以「旺衰」定喜忌。
- **《窮通寶鑑》**：以十干分十二月论调候用神（如「三春甲木……」），不以格局为主。
- **《命理約言》**：卷一「看格局法」「看用神法」，以「扶抑」为主，驳专取神煞。

**可机械判定的一条**（`geju::yue_ling_ge`）：依《子平真詮·論用神》《論用神變化》《論雜氣如何取用》取月令之格——
1. 月令为日干之禄 → 建禄格；阳干月令为刃 → 阳刃格；阴干月令为同五行阳干之禄（乙日寅月之类）→ 月劫格（「是建祿月劫之格，非用而即用神也」，书页十九）。
2. 否则看月令所藏之干（表依 `CangGanTable`，缺省通行表）透于年、月、时干者：本气透 → 本气之格；本气不透而他干透 → 取所透者（「不透甲而透丙，則……得以作主」；「透戊則用偏財，透癸則用正印，透乙則用月劫」）；多透者取表中在前者，余列为兼透（「一透則一用，兼透則兼用」）。所透为比劫者作月劫格。
3. 皆不透 → 取本气之格。

**限制**：会支成局（「申與子會局則用水印」）、透干之清浊有情无情、用神成败救应、相神、外格皆不判断；多透时书中无先后明文，「表中在前」是本项目读法。测试 `geju::tests::zhen_quan_rules`（真詮「辛生寅月逢丙」「甲生三月」诸例）。

**卷十一运例**（「辛丑庚寅乙巳甲申……至乙酉運第五年丙申歲八月十九日死」）：辛丑年内合年月日三柱之日，1241、1421、1481 三年无，1301、1361、1541、1601 四年有。按阴男逆行、实历折除：
