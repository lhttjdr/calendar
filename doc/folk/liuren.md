## 一、月将

卷二总说：「以太陽纒度過宫而言則登眀為首逆布，逆布者謂之月将。」即太阳过宫、按中气换将。

**实现**：`JiangRule::ZhongQi`（缺省）取本项目历表算出的定气中气时刻，在中气时刻换将，精确到时刻（不是按日）。`JiangRule::Jie` 为按节换将（以月建定将：寅月亥将、卯月戌将……，交节即换），今人有此说，《六壬大全》未见，未核出处，只作选项。

**平气与定气**：《六壬大全》全书检「平氣」「定氣」「歲差」皆无，卷二只言「某中氣後」，未言平定，**无明文，不立选项**。古历以平气换将、清时宪历起用定气，本项目一律用定气。下文卷十一宫界日数与平气更合，只可说明书中所据历日用平气，不是换将之规定。

**恒星过宫**（`yue_jiang_xiu`、`GONG_JIE_DAQUAN`、`mansion_gu_huang_dao`；网页「换将：恒星过宫（卷十一宿度）」）：卷十一「太陽過宫」以宿度列太阳入各宫：

> 立春前九日有竒日躔子分女初度始三十日滿驚蟄前十日日躔亥分在危十二度三十二日滿清明前八日日躔戌分在奎初度三十三日滿　立夏前六日日躔酉分在胃三度……芒種前五日日躔申分在畢六度……小暑前五日日躔未分在井八度……立秋前六日日躔午分在栁三度……白露前五日日躔已分在張十四度……寒露前三日日躔辰分在軫九度……立冬前一日有竒日躔夘分在氐一度……大雪前三日日躔寅分在尾二度……小寒前六日日躔丑分在斗三度

卷二总说「以太陽纒度過宫而言則登眀為首逆布，逆布者謂之月将」，即月将是太阳所在之宫；卷十一以宿度定宫，二者相合即恒星过宫之说（宫界随星，不随中气）。此有明文，作选项；卷二各神注又以中气言之，二说并存，缺省仍中气。同卷歌「角亢氐一總在辰　氐二房心尾夘存　尾三箕斗在寅位斗四牛女丑宫真　女二虗危同在子……」所举各宫首度比上表多一度（歌言宫内第一整度，表言宫界），从表。

实现：太阳视黄经落入卷十一宿度宫界所在之宫为将；宿界用授时（元）距星（`yuan` 体系，明代行用），以古法黄道宿度——距星赤经圈与黄道交点之黄经（tan λ = tan α ／ cos ε）——为宿首，入宿古度折为度（365¼ 古度一周）。网页经星图 Worker（`SkyEngine::liuren_jiang_xiu`，要星表）求将，再传入 `liuren_json`。

## 二、起课

**天地盘**：月将加占时，地盘 d 上的天盘神 = 月将 + d − 时支（模 12）。

**四课**（卷一「十干寄宫」：「甲課寅兮乙課辰丙戊課巳……丁己課未庚申辛戌壬亥是其真癸課原来丑宮坐」）：一课下为日干（以干之五行论克），上为寄宫上神；二课为一课上神之上神；三课下为日支，上为支上神；四课为三课上神之上神。

**三传**：初传依下表诸法取得；除另有规定者外，中传为初传之上神，末传为中传之上神（卷一「初傳之上名中次中上加臨是末居」）。

| 法 | 卷一原文 | 实现 |
|---|---|---|
| 贼克 | 取課先從下賊呼，如無下賊上尅初 | 有下贼上者只论下贼上；一者重審，否则上克下一者元首。同一上神出现于两课作一 |
| 比用 | 下賊或三二四侵……陽日用陽隂用隂 | 多者取与日干阴阳相同之上神；只一个则知一 |
| 渉害 | 渉害行来本家止，路逢多尅為用取，孟深仲淺季當休，復等柔辰剛日宜 | 俱比俱不比（多个比者在比者中）以渉害深者；深浅相等取临孟者（見機），无孟取临仲者（察微），再等则刚日从干上、柔日从支上先见者（綴瑕） |
| 遥克 | 先取神遥尅其日，如無方取日来遥……擇與日干比者用 | 四课无克：二、三、四课上神克日干为蒿矢，否则日干克上神为弹射；多者取比者，俱比俱不比见下 `YaoTie` |
| 昴星 | 陽仰隂俯酉位中，剛日先辰而後日，柔日先日而後辰 | 刚日初传为地盘酉上神，中支上、末干上；柔日初传为天盘酉所临地盘，中干上、末支上 |
| 别责 | 四課不全三課備，無遥無尅别責例，剛日干合上頭神，柔日支前三合取……隂陽中末干中寄 | 三课：刚日初传取日干五合之干寄宫上神，柔日取支前三合（如酉日丑、未日亥）；中末俱干上 |
| 八专 | 兩課無尅號八專，陽日日陽順行三（連本位數），隂日辰隂逆三位，中末總向日上眠 | 两课无克：刚日干上神连本位顺数三，柔日四课上神（支阴神）连本位逆数三；中末俱干上 |
| 伏吟 | 伏吟有尅還為用，無尅剛干柔取辰，迤邐刑之作中末……若也自刑為發用，次傳顛倒日辰併，次傳更復自刑者冲取末傳 | 月将同时。有克取克（只一课可克，如乙日辰、癸日丑）；无克刚日干上、柔日支上；中末取刑；初自刑则中取另一（干上↔支上），中又自刑则末取冲 |
| 返吟 | 返吟有尅亦為用，無尅别有井欄名……丑日登明未太乙，辰上作申日上作未 | 月将冲时。有克照常；无克（丁丑丁未己丑己未辛丑辛未六日）为井栏：初传日支驿马（丑日亥、未日巳），中支上，末干上 |

## 四、天乙贵人与十二天将

### 十二天将

卷二「天將總論」：「十二天將天乙貴人為主居中，前有五位一蛇二雀三合四勾五龍……後有五位一后二隂三𤣥四常五虎……天空雖云後六位，有名而無物，緣貴人相對」。即自贵人起依次：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后（`TIAN_JIANG`）。各将加于天盘神，随贵人顺逆依次布之：「以課之天盤起貴神之例，地盤定順逆之序，順布者則背天門，逆布者則向地户」。

### 日墓（`MuRule`）

### 旺相休囚死（`wang_shuai`）

以月建定四时：寅卯木旺、巳午火旺、申酉金旺、亥子水旺，辰未戌丑四季月土旺；旺所生者相、生旺者休、克旺者囚、旺所克者死（卷五觀月經注「春木旺夏火旺秋金旺冬水旺四季土旺」「春火相夏土相秋水相冬木相季月金相」「春土死夏金死秋木死冬火死」）。月建取子平四柱月支（交节换月）。

**土旺四季各十八日**（`WangXiangRule::TuWang18`，`dang_ling`、`wang_shuai_ling`；网页「旺相」选项，缺省仍季月土旺）：卷八雜狀課「惟土守中宫分旺四季毎季前各旺十八日總七十二日合而成嵗故辰中有餘木未有餘火戌中有餘金丑中有餘水各十二日」；同卷又「土居中央分旺四季故春夏秋冬辰戌丑未月各寄旺十八日四季共七十二日……故辰中有餘木未中有餘火戌中有餘金丑中有餘水也」；卷二太常注「己未土旺四季各十八日」。即季月三十日中土旺十八日、余十二日仍属本季之行（辰木、未火、戌金、丑水）。十八日之起讫书中未明言「四立前」，依「辰中有餘木」（辰月前段属木、后段属土）读作季月之末十八日，即四立前十八日，与择日「土王用事」同（`zajie::tu_wang`，网页按东八区日与立春、立夏、立秋、立冬之日比）。此说书在雜狀課（取物类、数目），是否施于壬课旺相未明言，故只作选项。检验（`ke_ti::tests::tu_wang_18`）：辰月土王用事前当令为木、其间为土，丑月前段为水；缺省之说与 `wang_shuai` 逐月逐行全同。

**異说与读法**：
- 繁昌：觀月經旺孕例（妻金年上酉、夫水年上子）以本命纳音之行与年上神相合论「旺」，与心鏡、曾門以时令论旺相不同，未做；「夫妻年立德方發用」书例三传不在行年上，不以发用为必要。产期、受孕推法不做。
