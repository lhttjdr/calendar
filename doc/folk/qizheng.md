# 七政四余

星命之术：以日、月、五星（七政）与罗睺、计都、月孛、紫炁（四余）所在之宫度、宿度，配命宫、十二宫论命。本项目算「诸曜在何宫何宿几度、命宫与十二宫何在」，及星命书中可按规则推得之项（宫主、度主、命主、身主、廟旺、强弱、恩難、童限大限小限，见第四章），不作吉凶推断。

## 一、源流

- 唐代随西域、印度历术传入，以罗睺、计都为蚀神（印度 Rāhu、Ketu，白道交点）。月孛、紫炁为中国所增（未核出处）。
- 明：《七政推步》（贝琳，回回历）推罗计、月孛；万民英《星學大成》（嘉靖四十二年序）集星命诸家，卷一「孛曜九年一周天，羅計十八年一周天」。
- 崇祯改历（《崇祯历书》）：《明史》卷三十一徐光启等议「羅喉、計都即正交、中交行度，古今為平行……因設一加減，為交行均數」，「天行無紫氣，舊謂生於閏餘，又為木之餘氣……知為妄增」。
- 清初：汤若望新法行之，删紫炁、罗计与旧法相反。杨光先《不得已·摘謬十論》第七謬「刪除紫氣之新」、第八謬「顛倒羅計之新……不過以羅為計，以計為羅」。
- 清中期以后：逐年颁《七政經緯躔度時憲書》，四余俱全（道光十三年本有紫气），罗计复与回回旧法同。

宫界不在黄经 30° 整倍，而在某宿某度（`GongRule`）：

大成原文「氐一過卯尾三寅，斗三度兮丑中陳，女至一度方過子，危十二度亥中陳，奎一入戌胃三酉，畢六度兮移過申，井八過未柳三午，張十四巳軫九辰」，
后注「以上度數特其槩耳，其詳具於三辰通載」。两书差一度者四处，疑是「過某度」与「起某度」读法之别，原样并列。
本项目读作：宫首 = 该宿距星黄经 + 所云度数（古度，折 360/365.25）；宿用 `MansionFrame`（缺省清代距星），无距星时退回中气分宫。

#### 4.3.1 量天尺（命度）

### 4.6 恩難（五行生克）

以命主五行为主，各曜之关系（`XingMing::relation`）：恩（生命主）、難（克命主）、比（同行）、子（命主所生）、制（命主所克）。

- 《張果星宗》卷四《生殺星論》「生我者為恩星、為母曜，克我者為難星、為殺星」；同书「克我者為讎星」（仇、難同指）；「生我者，母星也；我生者，子星也」。
- 「用星」在星宗指身命、官福、田財、妻嗣诸主（卷一入门看法「用星者，即身命、官福、田財、妻嗣等主是也」），是职司，不是生克之名，故不按五行推。
  近世所谓「恩用仇難」四分（用、仇各为一类）未见原文（出处未核），不做。
- 检验（`en_nan`）：《星學大成》卷三月限「命坐巳未申三宫以月水為主，喜金水月木，畏火羅土計」——本项目：金恩、水月比、木子，火羅制、土計難，喜畏两组全合（书不举日、孛、炁）；
  「辰酉安命以金為主，流月喜逢胃栁女氐（土度）之日宿，忌尾室翼觜（火度）」——土恩、火難，合。

### 4.8 书中命例

《星學大成》《張果星宗》《星命溯源》所举命例多只记干支年、月、日、时，不记年号；集成本鄭氏、杜氏星案命盘皆为图，录文缺，未取。
检验法（`ming_li_cases`）：干支年在 960—1644 间（《星學大成》例止于成书之 1563）逐一推算，农历日由本项目定气定朔求（东八区民用日，时取时支正中），
各曜宫与命宫按缺省（计都升交、真交点、平远地点、卯上起命、量天尺自宫首），宫分「中」= 中气分宫、「宗」= 星宗宫界之宿度分宫，宿度用该时代距星（宋皇祐、元、明系统）；
「命@室」为命度所在宿（量天尺），「孛=命」为月孛在命宫。表中只列全合或最近之年；括注为不合项之推算值。年份由吻合推定，所用各项即参与推定，
故「全合」只说明本项目算法与书可同时成立，尚非独立检验；书例中凡天象自相矛盾者，记为书误或抄误之可能。
