# 七政四余

星命之术：以日、月、五星（七政）与罗睺、计都、月孛、紫炁（四余）所在之宫度、宿度，配命宫、十二宫论命。本项目只算到「诸曜在何宫何宿几度、命宫与十二宫何在」，不作推断。

## 一、源流

- 唐代随西域、印度历术传入，以罗睺、计都为蚀神（印度 Rāhu、Ketu，白道交点）。月孛、紫炁为中国所增（未核出处）。
- 明：《七政推步》（贝琳，回回历）推罗计、月孛；万民英《星學大成》（嘉靖四十二年序）集星命诸家，卷一「孛曜九年一周天，羅計十八年一周天」。
- 崇祯改历（《崇祯历书》）：《明史》卷三十一徐光启等议「羅喉、計都即正交、中交行度，古今為平行……因設一加減，為交行均數」，「天行無紫氣，舊謂生於閏餘，又為木之餘氣……知為妄增」。
- 清初：汤若望新法行之，删紫炁、罗计与旧法相反。杨光先《不得已·摘謬十論》第七謬「刪除紫氣之新」、第八謬「顛倒羅計之新……不過以羅為計，以計為羅」。
- 清中期以后：逐年颁《七政經緯躔度時憲書》，四余俱全（道光十三年本有紫气），罗计复与回回旧法同。

| 命宫 | 太阳所躔之宫加生时，卯上所临（命宫 = 太阳宫 + 3 − 时支，逆支计） | 《星學大成》卷一「天盤轉出地盤上，卯上分明是命宫」。卯时生命宫即太阳宫，午时生逆三宫，与天文上升点同向；另有天文上升点选项 |
| 十二宫 | 自命宫逆布：命宫、財帛、兄弟、田宅、男女、奴僕、妻妾、疾厄、遷移、官祿、福德、相貌 | 星命通例；次序原文未逐条核 |

### 罗计何者为升交点

| 时期 | 升交点 | 证据 |
|---|---|---|
| 明回回历 | 计都 | 《七政推步》卷一「求計都與月相離度……在初宮至五宮為黃道北」，又「置其日計都行度内加六宮即為逐日羅㬋行度」 |
| 崇祯新法、清初 | 罗睺 | 《明史》卷三十一「羅喉、計都即正交、中交」；康熙九年时宪历正月初一罗睺奎八度五十六分、计都角七度三十四分，按罗睺升交推算奎 8.43°、角 6.97°（差 30′、36′），按计都升交则二者互换 |
| 清中期以后 | 计都 | 道光十三年时宪书逐旬（下表） |

杨光先所斥「以羅為計」即第二行对第一行。何年复改，未核（疑在《历象考成》修成前后）。缺省取计都为升交（回回旧法与清中期以后同；`LuoJi::JiAscending`），罗睺升交为选项。

## 四、限制与待做

- 紫炁推法原文：查《大統曆法通軌》、《崇禎曆書》、《曆象考成》（维基文库未检到）或星命书中「紫炁」起算；目前只能用时宪书反推。
- 罗计复改为计都升交的年份：取雍正、乾隆年间七政时宪书核。
- 明以前以宿度分宫（《星學大成》卷二「戌宫三十二度」等）未做；所需「宫界宿度」表待转录。
- 十二宫次序、度主、限度（大限小限）、命主、身宫、各家「廟樂旺」等星命之法未做（《星學大成》卷一至卷三）。
- 康熙九年本四余逐旬数值起伏较大，行序读法未确，只取正月初一一行。
- 书影分辨率尚可，转录字小处未逐一复核；宣统二年、三年本（哈佛，维基共享资源）未取。
- 网页未接入（结构化输出 `QizhengChart` 可直接画星盘：十一曜黄经、宫、宿、命宫、十二宫）。
