十四主星一派的命盘：命宫、身宫、十二宫、五行局、紫微天府两系十四主星、辅佐煞曜、四化、长生十二神、博士十二神、大限小限、命主身主。

## 二、起例（全书卷二）

| 项 | 原文 | 实现 |
|---|---|---|
| 安命、安身 | 「人命俱從寅上起正月，順數至本生月止，又自人生月起子時逆至本生時安命，順至本生時安身。假如正月生子時就在寅宮安身命，丑時逆轉丑安命，順去卯安身，寅時逆轉子安命，順至辰安身」 | `ming_shen`：命 = 寅 + (月 − 1) − 时，身 = 寅 + (月 − 1) + 时 |
| 闰月 | 「閏月正月生者要在二月內起安身命，凡有閏月具要依此為例」 | 缺省 `LeapRule::NextMonth`（作下月） |
| 十二宫 | 「男女俱從逆轉，切忌莫順去」：命宮、兄弟、妻妾、子女、財帛、疾厄、遷移、奴僕、官祿、田宅、福德、父母 | `PALACES` 自命宫逆布 |
| 五行局 | 「甲己之歲起丙寅……」五虎遁定命宫干，取命宫干支纳音；「如甲生人安命在寅……丙寅丁卯爐中火，却去火局」 | `wu_xing_ju`：水二、木三、金四、土五、火六 |
| 紫微 | 五局安紫微图及诀（「坎水宮中二歲行，初一起丑初二寅，順行一宮安二日」等）；「正月初一生者是火局，酉宮起初一日」 | `zi_wei_pos`：以局数除生日，不尽借日使整除，自寅起数商宫，借数奇逆退、偶顺进 |
| 天府 | 「安天府圖」：「天府惟寅申二宮紫府同宮，餘宮俱各填協作對，如紫居丑則府居卯」 | `tian_fu_pos` = 16 − 紫微（模 12） |
| 十四主星 | 「紫微天機逆行旁，隔一陽武天同當，又隔二位廉貞地，空三復見紫微郎；天府太陰與貪狼，巨門天相及天梁，七殺空三破軍位，八星順數細推詳」 | `main_stars` |
| 文昌文曲 | 「子時戌上起文昌，逆到生時……文曲數從辰上起，順到生時」 | 按时 |

| 天魁天钺 | 「甲戊庚牛羊，乙己鼠猴鄉，六辛逢虎馬，壬癸兔蛇藏，丙丁猪狗位」 | 见「各派差异」 |
| 禄存、擎羊陀罗 | 「甲生祿存在寅宮，乙生在卯，丙戊巳，丁己禄存停午方，庚祿居申辛祿酉，壬祿在亥癸祿子」；「祿前擎羊後陀羅」，「假如癸祿在子，丑宮安擎羊，亥宮安陀羅」 | `lu_cun` |

## 三、各派差异（选项）

| 项 | 选项 | 缺省及理由 |
|---|---|---|
| 闰月 | 作下月（全书）／作本月／十五日以前本月、十六日以后下月 | 作下月：全书明文；后二说为近人所行，原典出处未核 |
| 丙丁年天钺 | 酉／戌 | 酉：全书录文「丙丁猪狗位」，但魁钺即天乙贵人，天乙贵人诀通行「丙丁豬雞位」（亥酉），且「猪狗」使魁钺相邻，与他干魁钺皆不相邻之例不合，疑录文之误；待刻本核 |
| 辛年魁钺 | 魁午钺寅／魁寅钺午 | 魁午钺寅（通行）：诀文「六辛逢虎馬」只列二支，未分魁钺；他干诀文「甲戊庚牛羊」等以前一支为魁，若照字序则辛为魁寅，列为选项 |
| 四化 | 全书／近人（庚：太陽武曲天府天同；壬：天梁紫微左輔武曲） | 全书：本书明文；近人表出处未核 |
| 长生十二神 | 男顺女逆（全书）／阳男阴女顺、阴男阳女逆 | 全书明文 |

四化中全书作「戊貪月弼機」（戊年右弼化科），与近人多数同；庚年「日武陰同」（太陽、武曲、太陰、天同）、壬年「梁紫府武」（天梁、紫微、天府、武曲），近人有异。

## 四、检验

| 检验 | 结果 |
|---|---|
| 卷二「安身命例」三例（正月子、丑、寅时） | 全合 |
| 卷二「甲生人安命在寅……丙寅爐中火……正月初一生者是火局，酉宮起初一日」 | 合（命宫丙寅、火六局、紫微在酉） |
| 卷二五局安紫微图：由录文逐格读出 150 日 | 147 日与算法相合；3 日录文讹脱，不计：木三局寅格「初初/三九」当作初三、初五（初九已见于辰格，致初九两见、初五缺），金四局亥格只「初一」、脱「三十」（算法三十在亥） |
| 卷二「安天府圖」：寅申同宫，紫居丑府居卯 | 合 |
| 卷二各主星条「某宫……与某星同度」41 条（紫微、天机、太阳、武曲、天同、廉贞、天府、贪狼、巨门、天相、天梁、七杀、破军各条），紫微十二位遍历 | 全部成立 |
| 卷二诸诀所举例：甲年四化；癸禄在子、羊丑陀亥；己年禄午（己丑流禄在午）；子、丑、午时劫空；文昌文曲子丑时；左右正月；天伤奴仆、天使疾厄；午宫安命命主破军 | 全合 |
| 闰月三说、大限顺逆、小限起宫 | 按选项各一例 |

**《紫微斗數方書》（韩国藏写本）旁证**（PDF 页码）：
- 第 5 页「安身命法」：「無論男女生月宮起子時逆數至生時安命」「順數至生時安身宮」——同全书。
- 第 6 页十二宫名作「一命宮二兄弟宮三妻宮四子息宮五財帛宮六疾厄宮七遷移宮八奴僕宮九官祿宮十田宅宮十一福德宮十二相貌宮」：次序同全书，名目「父母」作「相貌」，「子女」作「子息」。「定五行局法」以命宫干支纳音，同全书。安紫微表以「火六赤雞」「土五黄馬」「金四白猪」「木三青龍」「水二黑牛」起，列初一、初一加局数……之宫（火六局酉戌亥子……，木三局辰巳午……，水二局丑寅卯……），与 `zi_wei_pos` 相合。
- 第 7 页「安天府法」：「紫微既安之後，同宮於寅申，相對於巳亥，其餘皆斜對」——同全书安天府图。
- 第 8 页：「大限皆以局數定，陽順陰逆自命宮」——大限自命宫起，支持本模块对全书「從命前一宮起」的读法；禄存「甲祿寅、乙祿卯、丙戊祿巳、丁己祿午、庚祿申、辛祿酉、壬祿亥、癸祿子」同全书；「地空，亥上起子時逆至生時」即全书之天空（名目不同）；台辅、封诰作「文曲前□位」「文曲後□位」，字未确。

全书录文未见完整的出生年月日时命例（明刻七卷本卷末有命例，录文无），故未做整盘逐例检验。

## 五、限制与待做

1. **刻本核对**：明刻《紫微斗數全書》书影；《紫微斗數方書》（韩国藏写本）其余诸页中检四化诀、魁钺诀、火铃顺逆；《道藏》三家本第 36 冊核《續道藏》本录文。
2. **整盘命例**：以刻本或可靠古籍所载命例逐盘检验。
3. **十八飞星一派**（《續道藏》本）：起紫微、安身「一宮兩日半」、限法，另作模块。
4. **未实现之星**：截路空亡、旬中空亡、流年诸星（流禄流羊流陀、丧门白虎吊客官符、斗君）、天德月德解神、飞天三杀；庙旺利陷表。
5. 未接入网页。
