## 命宫、身宫、十二宫

- **命宫**：歌「杖星宮裏起生時，順數卯處安命之」；安命例（第 30 页）「凡從杖星順數本人生時……則從子上起申，順數至未逢卯，便是命宮」——天杖在子、申时生，子申、丑酉、寅戌、卯亥、辰子、巳丑、午寅、未卯，命在未。即命宫 = 天杖之宫 + (卯 − 生时) 顺数。
- **身宫**：安身例（第 30—31 页）「從杖上逆數，一宮兩日半，五日二宮，數至本人生日安身，不分男女皆逆。如遇初三、十三、二十三、初八、十八、二十八，此六日午時不過宮，未時過宮」。
- **十二宫**：卷一宫次「一命宮、二財帛、三兄弟、四田宅、五男女、六奴仆、七妻妾、八疾厄、九遷移、十官祿、十一福德、十二相貌」，与七政四余星命之十二宫同。排列之向原书无明文，缺省依星命家通例自命宫逆布（`PalaceDir::Ni`），顺布为选项。**未核**。

## 本命星（「自子生起順星逆」）

「術天機」图紫微旁注「自子生起，順星逆」，紫系十二星各注「某生」：子生紫微、丑生天祿、寅生天福、卯生文昌、辰生天貫、巳生天庫、午生紅鸞、未生天空、申生天壽、酉生天印、戌生天貴、亥生天虛——生年支顺行、星依紫系逆布之序逆取（`ben_ming_xing`）。此配与安星无涉（如子年生紫微在未，而子年所配为紫微），卷一至卷三正文检「本命」「主星」「生人」诸处均未言其用，故只列其配、不入推断；wasm `ziwei18_json` 字段 `benMing`，排盘页说明中列出（**用法未见**）。

## 与十四主星派之异

| 项 | 十四主星派（全书） | 十八飞星派（續道藏本） |
|---|---|---|
| 主星 | 紫微、天机……破军十四主星，按五行局与生日定紫微 | 紫系十二星按生年逆布，杖系按生月，刑姚按生月，哭合太岁 |
| 命宫 | 寅起正月顺至生月，再逆数生时 | 天杖之宫起生时顺数至卯 |
| 身宫 | 生月起子时顺数至生时 | 天杖起初一逆数，二日半一宫 |
| 宫名 | 命、兄弟、夫妻、子女……父母 | 命、財帛、兄弟、田宅、男女、奴仆、妻妾、疾厄、遷移、官祿、福德、相貌（七政四余之宫） |
| 十干阴阳 | 通例 | 甲丙戊庚壬为阴（原书） |
| 四化、五行局 | 有 | 无 |
