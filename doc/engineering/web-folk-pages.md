# 网页：择日页、排盘页与设备传感器

日历页只放历日与宜忌摘要；择日、排盘各为独立页面（顶栏「择日」「排盘」），与日历共用所选日期时刻（`App.tsx` 的 `shiftSelected` 调日、时辰），日柱、时柱取日历所示四柱（四柱预设、日界、当地太阳时皆随之）。

**宜忌两说**：「当日」卡片可切「宜忌依：协纪（缺省）／董公」；董公（《董公選擇日要覽》，`dong_gong_day_json`，月建按节）列宜忌、等第、条件、董公所举神煞与所据原句，无宜忌之文的日子只注「董公无宜忌之文」，不以协纪填补（数据与校订见 `doc/folk/tongshu_yiji.md` 第九节）。

**择日页另有**：二十四山图外缘色带标当月月厌、厌对（以节换月，正月厌戌逆行）与厌前（阳，浅红）、厌后（阴，浅蓝）两半，并给当日干支的阴阳将（类编「論隂陽不將日」）；「婚嫁择吉」面板按所示月份逐日判定（`jiaqu_days_json`，农历与朔弦望由页面传入，与日历同源），缺省列出全部日子及否决缘由；赤口可选不用（协纪）、类编、祛疑説、兀日起法（协纪卷三十六所述，即类编卷二六輪兀，逐日另标上兀、下兀；`opts` 位 2048），见 `doc/folk/jiaqu.md` 第三节。排盘页六壬外圈标十二天将（贵人两说、昼夜可选），奇门列演义卷二格局，紫微可切十四主星派与十八飞星派、主星旁注庙旺。

**神煞起例**（择日页当日卡片「神煞起例依：协纪（缺省）／类编／逐神选」）：`qili_shen_day_json` 以协纪起例与所选诸说（天德天德合四仲、天火、鳴吠、鳴吠對、復日、荒蕪、天賊、蠶命，`shensha::ShenshaOptions`、`nianshen::NianShenOptions`）各列当日之神，显示较协纪多、少之神与蠶命方位；只改所列之神，宜忌仍依协纪月表。出处见 `doc/folk/tongshu.md` 第五节。

**玄空飞星**：坐向可选二十四山（含替卦），或用罗盘测：站于门内、手机平放顶端朝门外（向首），取真北方位，坐即其背，自动定山、替卦与空亡；「锁定坐向」后人可走动，坐向不再随设备变。宅盘（洛书九宫）开罗盘时亦随设备转至实地方位，便于覆于房屋平面。

**七政四余**：日月五星视黄经要五大行星历表与清代二十八宿距星，排盘页不自带，复用星图页的 Worker（`web/src/skyWorker.ts` 的 `qizheng` 请求 → `SkyEngine::qizheng`，`rust/wasm-lib/src/lib_impl.rs`），切到「七政四余」页签才建 Worker、取历表（与星图同一批文件，浏览器缓存共用）。ΔT 由 Worker 估算，时刻取所选时刻（UT）；命宫上升点法用观测地经纬度。可选罗计（计都升交／罗睺升交）、交点（真／平）、命宫（太阳宫加时卯上起命／东方上升点）；紫炁依时宪书平行，月孛真远地点等其余选项取 `QizhengOptions` 缺省。圆盘十二宫依地支方位（同六壬地盘），内圈支与十二次，中圈人事十二宫，外圈本宫诸曜（简称、入宫度、逆行），罗盘开时随之转；旁列十一曜宫、入宫度、宿度、庙旺、对命主（恩難比子制）表，及命度、命主、身宫身主、童限，十二宫之宫主、强弱、大限岁表；星命诸说（分宫中气／星宗宿度／大成宿度／授时宿度（《元史》黄道十二次原数）、命主度主／宫主、身主、庙旺两说、强弱两说、大限年两说）以 `flags` 位传入 `SkyEngine::qizheng`。规则见 `doc/folk/qizheng.md`。检验：2026-11-09 盘面太阳卯宫 16.6°（黄经 226.6°）、朔前日月同宫、水金土逆行、木火同在午宫，与当日天象合。

**动态**：排盘页「实时」开关即日历的实时模式，盘随当前时刻，到时辰、节气交界自动换局；计算按分钟缓存（实时时钟每秒走，不必每秒重算）。罗盘开时，方位盘（奇门九宫、六壬天地盘、太乙十六神盘、七政四余十二宫盘）整盘转至实地方位，与择日二十四山图同（共用 `web/src/CompassBar.tsx`）；紫微命盘按地支排宫而不对应实地方位，不转。

**时空四维**（方位 × 时间）：方位由陀螺仪指南针转整盘（见「传感器」）；时间分三类处理（太阳时角之低精度公式在 `web/src/timeClock.ts`，精度约 0.01°，只供转盘显示）：
- **随天连续转**：七政四余「天盘随时转」、六壬「天盘连续转」（月将加时之连续形：月将中太阳之位对准真太阳时角，转角 = 太阳盘上方位 −（30°×月将支序 − 太阳在次中之偏）；时辰正中、太阳居次中时与按时辰之盘重合）。实时则每 250 ms 以当前时刻重算，一日一周（约 0.004°/s）。检验：14:48 未时，按时辰 120°、连续 134.36°（差不足半支）；8 s 转 0.034°。
- **循规则步进、可插值**：奇门转盘三组（九星、八门、八神）——选项「时辰内插值（示意，非原典）」按时辰已过比例向下一时辰之位取最短路径转去，到交界与下一局重合；局变（节气、三元）仍一跳。检验：14:25 未时（已过 0.71），八门下一时辰进 3 宫转 2.125 宫、九星八神进 2 宫转 1.416 宫。太乙不插值：太乙按洛书数移宫（坎一→坤二→震三跨盘），始击、主客将由算数得，皆非连续；文昌、计神逐局进退一位，可作插值（待做）。
- **飞宫**：玄空飞星之山星、向星、运星、流年按星数追踪所在宫，换运、换坐向、换年时各星沿洛书飞行路径（一二三……九，经五穿中心）飞至新宫（`Fly`/`FlyStars`，每段约 220 ms，整段至多 1.5 s）。玄空另有「九宫格（书式）」盘式（南上方格，诸星亦沿洛书路径飞行），与圆盘可切换，皆随罗盘转。

**图式**：一律南上北下、东左西右（古图惯例），字头朝外绕圆心统一旋转。方位盘皆作多层罗盘（`web/src/Wheels.tsx`）：多字名目逐字沿圆弧排、各依其位旋转（罗盘刻法），顺时针读；每类名目各占一环，不挤一层；外加二十四山（阳红阴黑）与周天度数两环（共用 `Shan24Ring`、`DegreeRing`）。
- 奇门：中五；宫卦与洛书数；地盘干；八门；九星；天盘干；八神（值符、值使之宫底色）；有方位格时，二十四山内另起一环按地盘十二支标天門、地戸、私門、天馬、亭亭、登天門（其山底色）。
- 大六壬：地盘十二支（占时底色）；天盘支（三传标红）；天盘神名（神后、大吉……）；十二天将；三传（初中末）。
- 太乙：中五；八宫（太乙所在底色）；主将；客将；十六神位（支 30°、维 45°，分格取相邻两位之中）；文昌、计神、始击各一环。
- 七政四余：十二宫（支、十二次；宫界依所选分宫法之实际黄经，`gongStart`）；人事十二宫；宫主（绿强灰弱）；二十八宿（距星视黄经为界，`xiuLon`）；黄道（十一曜按视黄经落点，相距 9° 内错层）；黄经刻度（命度 ▲）。黄经与方位：十二宫依地支方位，子宫玄枵居正北，方位角 = 315° − 黄经。
- 玄空：中宫；八宫飞星；后天八卦与洛书数；三元龙；二十四山（坐向底色）；周天度数；坐向线。
**天盘与地盘**：罗盘开时全盘同转（诸环同属地盘方位系，只随设备转）。另有随时间相对地盘而转之天盘：
- 六壬：天盘支、神名、天将、三传为一组，按月将加时相对地盘转 −30k°（k 为地盘子位所临天盘支序）；时辰交界以动画转过（最短路径），地盘十二支不动。
- 七政四余（选项「天盘随时转」，缺省宫居本位静盘）：太阳时角 H = 地方恒星时（GMST + 经度）− 太阳赤经，天盘整组转至太阳居方位 180° + H，即「太阳宫加时」之连续形；中心添地盘十二支，卯位底色，卯上所临之宫即卯上起命之命宫。检验：北京时 2026-11-09 11:27（午时）卯上为子宫，与命宫计算（子）合；时区与观测地不一致时（如浏览器 UTC 而观测地在中国），时柱按民用时、天盘按观测地真太阳，二者可差。
- 奇门转盘：九星（连天盘干）、八门、八神三组各绕八宫转（转过宫数取天蓬、休門、直符离坎之数，组内按本位画、整组转 45k°），时辰交界以动画转过；飞盘不转。检验：连续三时辰，粗体直使门、直符星所在宫与面板「直符加 N 宫、直使加 N 宫」皆合。
紫微命盘不对应实地方位，仍作方盘。

**字体**：罗盘图（排盘诸盘与择日二十四山图）用隶书：王漢宗中隸書繁（GPL v2，`vendor/fonts/wangfonts/wt021.ttf`），由 `scripts/dev/subset_lishu.sh` 按盘面用字（`Wheels.tsx`、`ZeRiPage.tsx` 全部汉字与排盘诸模块短字符串）子集化为 `web/public/fonts/lishu.woff2`（约 160 KB），首次用盘时以 FontFace 加载；字库缺字（炁、睺、卦符、简体）浏览器回退缺省字体。盘面新增文字后重跑脚本。

**传感器**（`web/src/sensors.ts`）：
- 定位：Geolocation API，取经纬度、海拔、精度；写回观测地（时柱当地时、更点、磁偏角共用），存于本机 localStorage。日历设置「观测地」与择日页均有按钮。
- 罗盘：DeviceOrientation。iOS 用 `webkitCompassHeading`（须在点击中 `requestPermission`），Android 用 `deviceorientationabsolute` 的 `alpha`（朝向 = 360 − alpha），加屏幕旋转角；角度圆周指数平滑。所得为磁北方位，加 WMM2025 磁偏角（`magnetic_declination_wasm`，见 `doc/astronomy/geomag.md`）为真北。二十四山图北在下，故整盘转 −真北方位 − 180°，手机平放时图上方位与实地相合。
- 转盘（`CompassBar.tsx` 的 `useSpinDriver`、`CompassSpin`）：读数存 ref，不经 React 状态；每帧（requestAnimationFrame）以时间常数约 90 ms 指数趋近目标角（−真北方位 − 180°），取最短路径、角度连续累加（跨 0°/360° 不倒转一周），直接写元素 transform（排盘诸盘写 CSS，择日二十四山图写 SVG 属性），不用 CSS transition；开罗盘时容器设 will-change 成独立合成层。文字读数与玄空测向所用之 React 状态节流：至多每 250 ms 一次且变 0.5° 以上（静止时每 1 s 补一次）；各盘面板以 React.memo 包住，读数更新时不重绘盘面。缘起：原先每个读数（约 60 Hz）都 setState 重绘整页并重启 120 ms 过渡，手机上盘面颤动、文字重影（截图为单帧，故清晰）。检验：无头 Chromium 2 s 内连发 126 个读数（跨 0°，±1.5° 噪声），盘角连续单调、长任务 1 次。
- 平放检测：取 beta、gamma 较大者为倾角，超过 15° 提示放平（立起时 alpha 不再是平面朝向）。
- 校准提示（`useCompassHeading` 的 `source`、`accuracy`）：iOS（读数来自 `webkitCompassHeading`）报 `webkitCompassAccuracy`：负值提示「未校准」，大于 15° 提示「精度低（±n°）」，均请远离金属、画「8」字校准，否则显示「罗盘精度 ±n°」。Android 等（读数来自 `deviceorientationabsolute`）W3C DeviceOrientation 规范无精度字段，浏览器不报磁力计校准状态，故常驻次要文字「此浏览器不报罗盘精度；读数不稳或与实地不符时，请远离金属并将手机画『8』字校准」。限制：读数抖动等启发式判据（静止时方位离散度）未做——用户转动手机时会误报，不可靠。
- 接口只在安全上下文（https 或 localhost）可用。

**检验**：无头 Chromium（授权 accelerometer、gyroscope、magnetometer）派发 `deviceorientationabsolute`（alpha 90，即顶端指西）：读数真北 262°（磁北 270°，北京磁偏角西 7.6°），盘上酉转至上方、北在右，合「面西而北在右」。实机（iOS、Android）未测。
