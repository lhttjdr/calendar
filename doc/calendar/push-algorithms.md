# 各朝代/政权历法推步算法总结

基于 [ytliu0/ChineseCalendar](https://github.com/ytliu0/ChineseCalendar) 源码整理。朔日来源分为三类：**预存实历表**（主表）、**平朔+无中气置闰推步**（历术参数 para）、**古六历/春秋历/秦与汉初历**（各自历元与规则）。下文先给**通用约定与核心算法**，再给**历术参数表**，最后按**时期/政权**对应到具体历术或数据。

---

## 一、通用约定与符号

- **jdc**：计日参考点，通常为「前一年 12 月 31 日 12:00 UT 的儒略日」的整数部分（如 `1429223 + accleap + 365*(y+799)`，`accleap = floor(0.25*(y+799) + 1e-5)`）。输出朔日、节气多为**相对 jdc 的日数**，换算为儒略历/格里高利历时加上 jdc 对应日期。
- **历术参数 para**：**lunar**（朔策）、**solar**（岁实）、**jd_epoch**（合朔历元 JD）、**JDw**（冬至历元 JD）。约定：年 y 的冬至 JD ≈ JDw + y×solar；合朔序列 JD ≈ jd_epoch + i×lunar（i 整数）。代码中对 jd_epoch、JDw 加小量舍入修正（dtc_round、dts_round）。

---

## 二、平气（24 节气）

**函数**：`compute_pingqi(y, para, jdc)`（split.js）

节气间隔 `dqi = solar/24`。从小寒起算的第 0 个节气（J12 小寒）的 JD：`J12 = JDw + y*solar + dqi`；第 i 个节气 JD：`J12 + i*dqi`。相对 jdc 的日数：`stermDate[i] = floor(J12 + i*dqi + 0.5) - jdc`。即**平气 = 冬至历元 + 线性岁实，等分 24 份**。

---

## 三、平朔 + 无中气置闰（统一算法）

**函数**：`cmonthDate_pingshou_noZhongqi(y, para, jdc)`（split.js）

1. **岁首界**：立春附近 Z1 的 JD：`Z1 = JDw + (y + 1/6)*solar`；下一岁 Z1 之后午夜 `Z1b = floor(Z1 + solar + 0.5) + 0.5`。
2. **正月朔（平朔）**：不晚于 Z1 日界的最近合朔。`i1 = floor((floor(Z1+0.5) + 0.5 - jd_epoch) / lunar)`，`m1 = jd_epoch + i1*lunar`。
3. **闰年**：若 `m1 + 13*lunar > Z1b` 则无闰（12 月），否则有闰（13 月）。
4. **岁长**：`cndays = floor(m1 + (12+leap)*lunar + 0.5) - floor(m1 + 0.5)`。
5. **各月朔**：无闰时第 j 月朔 = `floor(m1 + j*lunar + 0.5) - jdc`，j=0..11。有闰时用**无中气置闰**：中气间隔 `dmqi = solar/12`，从正月起找第一个「该月内无中气日」的月置闰（闰月朔写入 cmonthDate[12]，闰月号写入 cmonthDate[13]）；若 1..11 月均有中气则闰十二月。
6. **输出**：cmonthDate[0..11] 正月～十二月朔相对 jdc；cmonthDate[12] 闰月朔（无闰为 0）；cmonthDate[13] 闰月月份号；cmonthDate[14] 岁长 cndays。

### 3.2 以史书天象记录检验推步（2026-10-28）

复原表（主表、本项目推步、上游推步）都是复原结果；史书天象记录的日期是当时行用之历的一手证据。
`scripts/calendar_data/discriminating_records.py` 对已解析的全部天象记录（凌犯与日月食，汉书至清史稿），以主表与记录政权同系的
推步表逐条检验日干支是否在所记之月，列出判断不一者（`data/calendar/discriminating_records.csv`）；
`scripts/phenomena/discriminating_records_sky.py` 再以 DE441 求各历候选日当天天体与目标的地心最小角距
（`data/calendar/discriminating_records_sky.csv`）：日干支所指之日固定，两历只是月序不同，此日天象相符（角距 < 3°）即支持
把它排在所记之月的那一历；两历候选日不同者（相差约两月），月亮记录换一个日期角距差数十度，判定不依赖任何复原表。

- 北朝系（北魏、北周）共 14 条判断不一；本项目推步与上游推步（ytliu0）在这些记录上全同。
- 支持推步（景初历等北朝历）：太和元年十二月癸卯「月犯南斗」（主表日 60.7°、推步日 1.09°）、太和十八年四月庚申「月在斗蝕」
  （56.1°、1.45°）、正始四年十月癸未「月掩房」（59.9°、2.59°）三条月亮记录为强证据；太和七年五月辛卯「月犯南斗」及
  北周保定二年、太和十八年、延昌二年三条行星记录（同日 0.2°—2.1°，日干支只在推步之月）亦合推步。
- 支持主表：太和十五年七月乙未「月犯太微東蕃」（主表日 0.25°、推步日 61.8°）、七月癸卯「月犯牽牛」（1.62°、60.8°）两条强证据，
  七月辛丑「月掩建星」（8.9°、49.0°）为弱证据；北周天和二年七月庚戌「太白犯軒轅」（同日 0.41°，日干支只在主表之月）。
  太和十五年主表闰七月、推步（玄始历，与上游同）闰五月，推步的六、七月比主表晚一月。
  但《魏书·高祖纪》太和十五年六月丁未、七月乙丑、戊寅、己卯、乙酉五个记事日期只在推步之月（主表下全不在月），其余月份两表皆合；

  与本纪不同——或其材料来源按南朝历记日（推测，未证）。《魏书·律历志》：太武帝平凉（439）后以玄始历代景初，太和中张明豫
  修历未成，正光前未改历，与推步所用历术相合。
- 三处各家异说之月（吴 244 年十二月、吴 247 年九月、430 年二月）均无天象记录可证；改查本纪记事日期：《三国志·吴主传》赤乌七年、

  差一日的朔不能由月中日期判别。三处仍为异说。

## 五、古六历、春秋历、秦与汉初历

### 5.1 古六历（guliuli）

**朔策、岁实**：`solar = 365.25`，`lunar = 29 + 499/940`（与四分同）。

**算法**（guliuli_cmonth(y, jdc, yEpoch, jdEpoch, jdEpoch_lunar)）：(1) 年 y-1 冬至 `w0 = jdEpoch + (y - yEpoch - 1)*solar`，年 y 冬至 `w1 = w0 + solar`。(2) w0 前最近合朔 `m0 = jdEpoch_lunar + i*lunar`，其中 `i = floor((floor(w0+1.5)-0.5 - jdEpoch_lunar) / lunar)`。(3) 若 `floor(m0+13*lunar+0.5) < floor(w1+0.5)+0.1` 则 13 个月否则 12 个月。(4) 第 j 月朔 = `floor(m0 + j*lunar + 0.5) - jdc`；无中气判断同第三节（中气间隔 solar/12）。

**各历历元（guliuli_calendar_parameters）**：

| li | yEpoch | jdEpoch | jdEpoch_lunar | ziOffset（年首） |
|----|--------|---------|---------------|------------------|
| Zhou 周 | -104 | 1683430.5001 | 同 jdEpoch | 0（子） |
| Huangdi 黄帝 | 170 | 1783510.5001 | 同 jdEpoch | 0 |
| Yin 殷 | -47 | 1704250.5001 | 同 jdEpoch | 1（丑） |
| Lu 鲁 | -481 | 1545730.5001 | jdEpoch - lunar/19 | 0 |
| Zhuanxu 颛顼 | 14 | jdEpoch_lunar - solar/8 | 1726575.5001 | -1（亥，年终闰） |
| Xia1 夏(春秋用) | 444 | 1883590.5001 | 同 jdEpoch | 2（寅） |
| Xia2 夏(战国用) | 444 | jdEpoch_lunar - solar/6 | 1883650.5001 | 2（寅） |

ziOffset 将「子月起」的月序映射到各历正月：-1=正月亥（闰在年终），0=子，1=丑，2=寅。

### 5.2 春秋历（chunqiu_cmonth）

**常数**：`lunar = 30328/1027`，`yEpoch = -721`，`jdEpoch = 1457727.761054236`。**闰年表**：`leapYears[0..239]` 对应 -721～-482。步骤：`accMonths = 12*(y - yEpoch) + accLeaps[i]`，正月朔 `m0 = jdEpoch + accMonths*lunar`，月数 n = 12+leap，第 j 月朔 = `floor(m0 + j*lunar + 0.5) - jdc`。即**固定闰年表 + 朔策 30328/1027**，无中气规则。

### 5.3 秦与汉初历（HanZhuanXu）

**朔策**：`lunar = 29 + 499/940`（同四分）。**历元分三段**（出土历简复原）：y≥-162 用 Calendar C（jdEpoch=1646163.5001，accMonEpoch=321）；-201<y<-162 用 B（1633701.5001，174）；y≤-201 用 A（1589523.5001，1670）。**19 年章**：闰周 leapCycle、accMonCycle；`accMons = 235*floor((y-yEpochLeap)/19) + accMonCycle[yInCycle] + accMonEpoch`，闰 = leapCycle[yInCycle]。正月朔 `m0 = accMons*lunar + jdEpoch`。月序：十月、十一月、十二月、正月…九月、后九月（闰）。y=-201 时前三月用 B 的 m0，第 4 月起改用 `1633701.5001 + 470*lunar`。
