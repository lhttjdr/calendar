# 17. 古历复原模块

古历复原指**用程序完美复现中国古代历法的推步逻辑**，视为一套基于有理数运算的离线计算引擎。《三千五百年历日天象》等实历表**仅作验证用**，不作为计算依据。

## 四大模块（工程化逻辑）

1. **常量配置 (Configuration)**  
   历法配置类：历元（合朔历元 JD、冬至历元 JD）、岁实、朔策、气策（= 岁实/24）。不同朝代历法（如太初历、授时历）本质是更新这套配置；所有时间计算用**大整数与分数**，彻底摒弃浮点数，避免千年误差。

2. **线性时钟：平朔与平气 (Mean Motion)**  
   - 距算 = 目标年与历元的年差。  
   - 天正平朔：总月数 = 距算×岁实/朔策（取整），平朔时间戳 = 总月数×朔策；对 60 取模得干支。  
   - 平气：冬至时间戳 = 距算×岁实；以冬至为起点，每次累加气策，得 24 平节气。

3. **非线性扰动修正 (Anomaly Correction，可选)**  
   招差术：入历参数（入转、入历）→ 迟疾历/盈缩历查表 → 三次差内插得迟疾差、盈缩差。  
   定气 = 平气 + 盈缩差；定朔 = 平朔 + 盈缩差 - 迟疾差。  
   **第一版可跳过**，直接用平朔平气 + 历谱生成，得到「汉代平朔历法」级复原；后续将招差术作为策略注入即可升级到定朔历法。

4. **历谱生成与置闰 (Calendar Generation)**  
   - 大小月：定朔[i+1] − 定朔[i] 跨 30 日为太月，29 日为小月。  
   - 建子：冬至必在十一月。  
   - 无中气置闰：两冬至间若含 13 个阴历月，则找第一个无中气的月置闰（闰某月）。

5. **干支格式化**  
   时间戳（距历元日数）对 60 取模，映射到甲子…癸亥。

## 本仓库实现

- **位置**：`rust/core/src/calendar/ancient_restore.rs`
- **依赖**：`num-bigint`、`num-rational`、`num-integer`（有理数运算）。
- **当前实现**：配置（`AncientConfig`）、平朔（`first_month_new_moon`）、平气（`mean_solar_terms`）、历谱（`calendar_year`：大小月、无中气置闰）、干支序（`jd_to_gan_zhi_index_epoch`）。预设 `AncientConfig::sifen()`（东汉四分历）。
- **验证**：`month_new_moon_to_jd_day` 将月朔转为儒略日整数，可与 `实历朔日表.csv` 或《三千五百年历日天象》表逐条比对；平朔与实历可能差数日，定朔+招差术后可进一步逼近。

## 与主表、推步的关系

- **主表**（`实历朔日表.csv`）：各朝据历还原推步得到的连续表，用于**校验**古历复原输出。  
- **推步历**（`push_calendar.rs`）：当前为 f64 平朔+无中气置闰，与古历复原的分数版可对照；古历复原侧重「严格按古法分数推步」，便于与文献逐项核对。  
- 后续可在古历复原中接入招差术（立成表 + 内插），再与实历表比对定朔、定气。
