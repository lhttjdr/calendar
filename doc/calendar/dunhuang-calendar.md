# 敦煌历日换算（吐蕃、归义军时期）

> 本文的「推步」「实历」「复原」等术语与资料可靠性排序见 [历代历法总录](./calendar-compendium.md#资料可靠性排序)。
> 张表（实历朔日表）是复原，不是史实；出土具注历日是实物，属第 1 级证据。

吐蕃占领沙州（通说贞元二年 786 至大中二年 848）与归义军（848 至景祐三年 1036 前后）时期，敦煌与中原隔绝或往来稀少，
当地自造具注历日，朔日与中原历常差一二日、闰位也有不同。敦煌文书的纪日（「某年某月某日」）须按当地历换算，
不能直接套张表。本项把出土历日有据之月作「敦煌」政权历表，接入历史历日的换算路径。

## 数据：`data/calendar/敦煌朔日表.csv`

由 `scripts/calendar_data/build_dunhuang_shuori.py` 自比较表生成，254 月（原件 144、推算 110），吐蕃 808—835、归义军 858—994。
前 8 列与 `data/calendar/推步政权朔日表.csv` 同式（regime=敦煌、calendar=吐蕃时期敦煌历 / 归义军时期敦煌历、朔日民用历年月日、
敦煌自身的岁月闰），其后朔干支、朔依据、月日数、大小依据、文书、文书纪年（原书定名）、文书岁、书页。字段说明见
`data/calendar/README_shuori.md`「敦煌朔日表」。

- 敦煌朔只有干支，日期取同行中原曆朔（即张表）前后 3 日内同干支之日（唯一）。
- 月序、岁取敦煌历自身：比较表「敦煌月序」有字者用之（如 809 年中原閏三月敦煌作四月、中原四月敦煌作閏四月）；926 年「上年閏十二月」行
  是中原 925 年閏十二月、敦煌 926 年正月（敦煌 926 年閏正月）；「表列次年正月」行记于次年。
- 同一月见于两件者（893、924、982 年正月）合为一行、文书并列，朔与大小须一致（脚本断言）。
- 表内自校：月大小与紧接下一有据之月的朔差全合（`calendar::dunhuang::tests::embedded_table_is_consistent`）。

## 无据之月

出土历日只存 45 岁中的一部分月份，其余月份（786—1036 年拼合后 3104 月中 2850 月）无据。规则（`DunhuangFallback`）：

- **缺省 `Zhongyuan`：退回中原历**。理由（逐月见文末）：归义军原件 131 月，与张表同朔 73（56%）、差一日以内 122（93%）；
  与实际合朔（敦煌地方平时）所在日同日 64（49%）、一日以内 119（91%），且偏晚（敦煌朔在合朔次日 42 月、前一日 13 月），
  合朔次日者合朔地方时自 0.4 时至 23.9 时都有，不是进朔可解释的。张表与敦煌更近；月序、闰位上，有闰位可考之岁中只 809、858、
  893、926、993 五岁与张表不同，而现代定气定朔置闰与两者都无关系。敦煌历术不传，无从推步，故不退回定朔推算。
  吐蕃时期原件只 13 月（同张表 6、同合朔日 8），样本太少，同用此规则。
- **`EvidenceOnly`：只认有据之月**。无据之月、以及止日不知之月（原书「?」且下一月无据）的第 30 日，都不给结果。网页（wasm）不载张表，
  用此项：只在出土历日有据之日显示「敦煌」一行（`get_regimes_lunar_for_day`，「历日」图层的分政权一栏），其余日子主线即张表。
- 拼合（`lifa::dunhuang_months`）：
  1. 张表某月首与某有据之月首相距 3 日以内，视为同一月，取有据之月（月序、闰位从敦煌）。如 893 年张表閏五月在敦煌为六月，
     按敦煌月序查「893 年閏五月」得 None。
  2. 无据之月紧接有据之月之后者，月首取前月已知止日（月大小）；前月止日不知则限在前月朔后 29、30 日之间。
  3. 一段无据之月两端都由有据之月定时，与张表相差的一二日不压在相接之月（否则成 31 或 28 日之月），而沿张表月往段内推到能容纳为止
     （小月变大或大月变小）。786—1036 年因此挪动月首者 18 月，都在有据之岁前后：808 年七、八月（−1），809 年二、三月（+1），
     819 年八月（−1），891 年七月，895 年十二月，896 年十一、十二月，900 年三月，904 年十至十二月，905 年四月，923 年八、九月（+1），
     957、983 年二月（−1）。这些月的月首本无实据，挪动只为月长合 29、30 日；具体落在哪一月不可知。
  4. 无据之月限敦煌政权年限内（786—1036 农历年），月序、闰否照张表。年限是通说，只决定无据之月是否给出敦煌一行。
- 检验：退回中原历时 786—1036 年逐月首尾相接、月长都是 29 或 30 日（`calendar::lifa::tests::dunhuang_merged_months_are_contiguous`）。

## 纪年

`era_names::dunhuang_year_name(岁, 年号表, 敦煌表)` 返回时期、岁干支、通行纪年与该岁出土历日定名：

- **吐蕃时期（786—847）**：沙州文书不用唐年号，以地支纪年（「子年」「丑年」），间用干支；通行纪年给地支年，另给岁干支。
  比较表把吐蕃时期各件定名为「唐元和三年戊子歲」等，是邓文宽拟题（下编标题加〔〕，凡例二（一）「題名殘失者，所擬題目用〔〕表示」，
  808 年件书页 111 即如此），不是原件所书唐年号。地支纪年十二年一周，
  同名之年须据文书内容断代，本模块只给岁对应的地支，不反查。
- **归义军时期（848—1036）**：奉中原正朔，用中原年号；通行纪年取年号表主线的年末年号（`era_names_merged.csv` 主线）。
  但历日在岁前编成，当年改元不及载入，且改元消息传到沙州常迟，历日与文书多书旧号。比较表定名（归义军各件多照原件历首，如 926 年件历首「大唐同光四年具注曆日一卷」，书页 387；未逐件核是否拟题）与中原年号不同者：
  - 岁前已改元而仍书旧号（消息迟到）：「天復五年」（905；天祐元年四月已改，原书备注「天復祇四年，五年即天祐二年」）、
    「貞明八年」「貞明九年」（922、923；龙德元年五月已改）、「天福十年」（945；开运元年七月已改）；
  - 当年改元、历日岁前已编成：「光啟四年」（888，二月改文德）、「大順三年」（892，正月改景福）、「同光四年」（926，四月改天成）、
    「天福九年」（944，七月改开运）。

  这些是敦煌当时所书的第 1 级证据，`documents` 字段原样给出（改元月份据年号表与通行史书，未逐条核本纪）。换算文书纪年时以文书所书为准：
  所书年号若中原已改，按年数顺推到对应公元年，再查敦煌历。
- 年号表（`era_names_merged.csv`）不加「敦煌」政权行：该表由方诗铭、ytliu0 两源合并生成，敦煌纪年规则在此另立，不混入。

## 用法

```rust
use lunar_core::calendar::{dunhuang::DunhuangCalendar, lifa};
let dh = DunhuangCalendar::embedded();
// 敦煌文书「景福二年閏六月十五日」→ JDN（zhang 为张表 ShuoriTable，经中原一线来源次序）
let m = lifa::resolve_dunhuang_month(&dh, Some(&zhang), 893, 6, true, lifa::DunhuangFallback::Zhongyuan).unwrap();
let jdn = m.start_jdn + 15 - 1;
// JDN → 敦煌月日（含依据：原件 / 推算 / 张表）
let d = lifa::resolve_dunhuang_day(&dh, Some(&zhang), jdn, lifa::DunhuangFallback::Zhongyuan).unwrap();
```

逐条检验由 `cargo run --release -p lunar-core --example dunhuang_check`（写 `data/calendar/dunhuang_shuori_check.csv`、
`dunhuang_years.csv`）、`scripts/phenomena/dunhuang_fallback_check.py` 与 `scripts/calendar_data/dunhuang_checks_to_md.py` 生成下文。

## 限制与待补

- 敦煌历术不传，无据之月只能退回中原历，结果可差一二日，闰位亦可能不同（有据五岁之外未知）。
- 978 年斯0612 历序所列天祐十六年至太平兴国三年历年閏月，可作中原历闰位的第 1 级旁证，未与张表逐条核。
- 附录一以后刊布的敦煌历日（如《法藏敦煌西域文献》《英藏敦煌文献》图版所见他件）本地无录文，待取得原图版或录文后补入
  `敦煌历日_比较表.csv` 同式。
