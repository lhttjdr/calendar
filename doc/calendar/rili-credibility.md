# 主序列历日可信度

> 由 `scripts/calendar_data/rili_credibility.py` 生成，勿手改。逐十年数据 `data/calendar/rili_credibility_decades.csv`。

## 一、问题与方法

主序列（前 221—1911 年）每个月的历日，可信到什么程度？有证据之月看证据；无证据之月只有推步，可信程度取决于这部历的推步经得起多少检验。本页按资料可靠性排序（实物 > 当时文字 > 史书 > 推步），把各历推步拿到它所碰到的最高一级证据前检验，由检验样本估不合率，再外推到同一部历的无证之月。

- **检验等级**：A 实物（整年、单月实物历日）→ B 当时文书（汉简公文书，见 [hanjian-checks.md](hanjian-checks.md)）→ C 史书（本纪明书朔、纪日、后修，见 [benji-checks.md](benji-checks.md)），该级检验不足 20 月者往下取，三级合计仍不足者为「检验稀少」。汉初颛顼历的实物是拟合合朔改正 δ 所用（[qin-han-calendar-evaluation.md](qin-han-calendar-evaluation.md)），不是独立检验，记「实物定参」。
- **推步可能不合**：证据与推步不合之月，先按 [tongwu-causes.md](tongwu-causes.md) 逐条查成因。有「据」之史文讹误（校勘记、已考讹误、判语、同书相邻朔距不可能）、纪日抽取误、平朔时代食日书朔，都是证据之误，不计；余下之中，明书朔与推步差一二日者（进朔、退朔、以晦为朔之类），或主因为改历之年、代推之段、无从判断者，计为推步可能不合。差三日以上而无「据」者是系月、月名之事，推步不能差这么多，不计。汉简之条，判「合前后月」「待核」者计，差十日以上判抄误者不计。
- **不合率**：可能不合月数 / 检验月数，区间 Wilson 95%。所计之月仍可能是史书之误，故为**上界**。
- **外推**：无证之月的估计错月 = 该历不合率之和。外推的前提是有证之月与无证之月同质（有证之月多是本纪记了事的月份），此前提未经检验。

## 六、限制

- 不合率是上界；同时也只覆盖有证之月。无证之月是否与有证之月同质，未经检验。
- 汉简按「年 + 简文日期」归月，新莽建丑月名未逐条换算，个别月份可能归错；汉简证实之月未并入主序列逐月表。
- 检验稀少之历借总不合率，是权宜之计；补证据后应改用本历之数。
- 两家互异无据之月按一半取错计，没有用推步与张表各自的命中率加权。
