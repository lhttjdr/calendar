# 《中山世譜》《球陽》纪日与天象检验（自动生成）

> 由 `scripts/calendar_data/ryukyu_shipu_qiuyang_check.py` 生成，勿手改。录文 `data/calendar/ryukyu_shipu_qiuyang.csv`（纪日）、`data/phenomena/ryukyu_tianxiang.csv`（天象），逐条结果 `data/calendar/ryukyu_shipu_qiuyang_check.csv`、`data/phenomena/ryukyu_{solar,lunar}_eclipses_check.csv`；书目、证据等级与结论见 [ryukyu-sources.md](ryukyu-sources.md)。

## 方法

- 纪日：同 [ryukyu-jiri-checks.md](ryukyu-jiri-checks.md)（张表与当时行用之推步：明大统、清新法 / 考成 / 后编；康熙五至八年复用大统，月序闰位取大统本身推步）。1368 年以前无推步表，只列张表。同一史源（蔡鐸本、蔡温本同文）只算一条。
- 分类（每月一个）：两家**相同**之月——有证（实物合两家）、同误（实物与两家皆不合，判实物抄误或待核）、无证（两家相同而已，或只有推得、定年等不作证据之条）；两家**互异**之月——①实物证张表误（合推步）、②实物证推步误（合张表）、③无据待核（实物两家皆不合、证据冲突，或只一见而等级不足）。实物本身是证据，复原（今人诸表、外推）只作比对。 二书为琉球官修后修史书：相同之月与之合者按 C 级记「有证」；互异之月同月独立之条不足两条者不判，归 ③ 并注倾向。
- 天象：日食、月食以 `historical_eclipses` 计算记录日 ±1.5 日内有无食、首里可否见（ΔT 取 Morrison–Stephenson 2021，±σ、±2σ 各算）；记录日由张表换算。彗星、客星、星变只录不核。
