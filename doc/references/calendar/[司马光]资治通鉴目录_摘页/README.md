# 《资治通鉴目录》摘页（朔闰栏）

司马光《资治通鉴目录》三十卷，逐年列朔闰（据刘羲叟《长历》）。此处只存核对吴赤乌七年（244）十二月、赤乌十年（247）九月、
宋元嘉七年（430）二月朔所用的顶栏截图；全书扫描本见维基共享资源（2026-10-27 取）：

- 卷七至九：https://commons.wikimedia.org/wiki/File:SSID-12318599_資治通鑑目錄_卷7-9.pdf （PDF 第 31、34、35 页）
- 卷十三至十五：https://commons.wikimedia.org/wiki/File:SSID-12318601_資治通鑑目錄_卷13-15.pdf （PDF 第 31 页）

读法：每岁只列「前月为小月」之月的朔，未列之月 = 上月朔 + 30 日。核对结论见 doc/calendar/push-algorithms.md 3.1。
