# 古历复原

中国古代历法不是一张历表，而是一套算法：给出若干常数和几张表，按规定的步骤"推步"，就能排出任何一年的历日、节气、交食和五星。历代正史的律历志、历志记下了这些算法，称为"术文"或"历经"。按术文重新推算，就能复原当时的历书应有的样子，再拿史书的日期、出土的历日去检验。

本章讲推步的原理：平朔平气怎样由几个分数推出，上元积年是什么，定朔怎样用日躔、月离两张表修正，内插法怎样从刘焯发展到郭守敬，进朔规则怎样演变；最后讲复原的可靠程度怎样分档。各历的常数、表与逐历检验，见《历代历法总录》；先秦与三国至隋各政权历的推步，见《各朝推步》；辽、金之历见《行用历日》。

## 一、术文的结构

一部历法的术文通常分为几"步"：

| 步 | 内容 |
|---|---|
| 步气朔 | 求冬至、二十四气、平朔、弦望，置闰 |
| 步日躔 | 太阳运动的不均匀（盈缩），求定气、太阳所在宿度 |
| 步月离 | 月亮运动的不均匀（迟疾），求定朔 |
| 步晷漏 | 日影长短、昼夜漏刻、日出入时刻 |
| 步交会 | 日月食 |
| 步五星 | 五星的位置与见伏 |

排历日只需要前三步：气朔给出平朔平气，日躔、月离把它们修正为定朔定气。

术文中的数都是分数，以一个"日法"（或"通法""统法""总法"）为分母，一日分成若干分。例如三统历日法 81，一日分为 81 分；麟德历总法 1340。日法的选取，汉代附会于律吕，《漢書·律曆志上》："以其長自乘，故八十一為日法"；后世则为了让朔策、岁实都能写成同一分母的整数而取。

## 二、平朔平气

### 由章法推朔策

最早的历法认为日月都匀速运行，只需要两个数：**岁实**（一年的日数）和**朔策**（一个朔望月的日数）。先秦古六历和东汉四分历的岁实是 $365\tfrac14$ 日，所以称"四分历"；又取 19 年 235 个月为一"章"（十九年七闰）。两者合起来，朔策就定了：

$$\text{朔策} = \frac{19 \times 365\tfrac14}{235} = \frac{6939\tfrac34}{235} = 29\frac{499}{940}\ \text{日}$$

分母 940 = 4 × 235。三统历则先定日法 81，朔策 $29\tfrac{43}{81}$ 日，再由章法反推岁实：

$$\text{岁实} = \frac{235 \times 29\tfrac{43}{81}}{19} = \frac{562120}{1539} = 365\frac{385}{1539}\ \text{日}$$

1539 = 19 × 81，称"统法"。

### 推一年的朔与气

从历元到所求年的冬至，经过的年数称"积年"。冬至时刻 = 历元 + 积年 × 岁实。冬至前的平朔：先求积年中的总月数（积年 × 235/19，取整），再乘朔策。此后每加一个朔策得一个平朔，每加岁实的 1/24 得一个平气。每个时刻的整日部分对 60 取余，就是它的日干支，余下的分数（"小余"）是一日之中的时刻。置闰按无中气之月。

这些运算全是分数的加、乘与取整。所以推步一定要用精确的分数运算：几千年的累积下，哪怕最后一位的舍入，也足以把一个恰在夜半的朔推到另一天。

### 上元积年

历元最好是一个"万事同起"的时刻：甲子日夜半，恰好合朔，又恰是冬至，而且（后来的要求）日月在同一交点、五星同在一处。历家称之为"上元"，从上元到当年的年数称"上元积年"。元代《授时曆議》说："漢劉歆作三統曆，始立積年日法，以為推步之準。"

求上元，就是解一组同余式：要求积日同时满足"是 60 的倍数（甲子）""是朔策的整数倍（合朔）""是岁实的整数倍（冬至）"等条件。这类问题后来由南宋秦九韶在《数书九章》中总结为"大衍求一术"，即今天的中国剩余定理（未核原书）。条件越多、常数分母越大，上元就越远，积年动辄几十万、上千万年。唐《开元占经》卷一百五记有各历到开元二年（714）的积年，例如：

| 历 | 积年（至 714 年） |
|---|---|
| 东汉四分 | 9995 |
| 乾象 | 7885 |
| 景初 | 4523 |
| 元嘉 | 5974 |
| 大明（祖冲之） | 52190 |
| 正光 | 167942 |
| 兴和 | 294170 |
| 天和 | 875940 |
| 开皇 | 4129130 |
| 戊寅 | 164436 |
| 麟德 | 269930 |

这些数本项目都按各历常数重新推过，除东汉四分历差一年（"算上""算外"之别）外均相合；正史缺载或刻误的常数，有几处正是靠占经的积年订正的。

上元积年只是一个起算的约定，与天文无关，却迫使历家为了凑出整齐的上元而调整常数。郭守敬等造《授时曆》，索性不用：

> 今授時曆以至元辛巳為元，所用之數，一本諸天，秒而分，分而刻，刻而日，皆以百為率，比之他曆積年日法，推演附會，出於人為者，為得自然。（《元史·曆志二·授時曆議下》）

即以至元十八年（1281）冬至为历元，常数一律用百进小数。这与今天天文学"取一个近代历元，常数写成小数"的做法一致。

### 常数的精度

下表比较各历的朔策与当时的平均朔望月。朔望月几千年来几乎不变（每世纪约增 0.019 秒），所以这一比较是严格的：

|---|---|---|
| 三统（前 104） | 29.530864 | +24.2 秒 |
| 东汉四分（85） | 29.530851 | +23.0 秒 |
| 乾象（223） | 29.530542 | −3.7 秒 |
| 景初（237） | 29.530599 | +1.2 秒 |
| 元嘉（445） | 29.530585 | −0.0 秒 |
| 大明（祖冲之，510） | 29.530592 | +0.5 秒 |
| 戊寅（619） | 29.530601 | +1.3 秒 |

| 授时（1281） | 29.530593 | +0.5 秒 |

朔策每月多 23 秒，四百年就积累一日，这正是东汉要改用四分、三国以后各历不断改进朔策的原因。东汉末刘洪的乾象历首次把朔策从四分的数值上大幅修正，此后的误差都在几秒以内。

岁实的比较要复杂些：古历的岁实是从冬至到冬至的"冬至年"，它因地球近日点的移动而与平均回归年（今约 365.2422 日）略有不同，今约 365.2427 日。各历的岁实：四分 365.25、乾象 365.24618、景初 365.24688、元嘉 365.24671、大明 365.24281、戊寅 365.24461、麟德 365.24478、大衍 365.24441、授时 365.2425 日。祖冲之大明历首次在历法中引入岁差（东晋虞喜发现），并改十九年七闰为 391 年 144 闰，岁实因此大为改善；唐代诸历的岁实反而又偏大了。

## 三、定朔

### 日躔与月离

太阳在近日点附近走得快，月亮在近地点附近走得快。真实的合朔时刻在平朔前后摆动，最多相差十几个小时。古人用两张表描述这两种不均匀：

- **日躔表**：太阳在一年各段比平均快或慢多少，累积的位置差称"盈缩差"（即今天所说太阳的中心差）；
- **月离表**：月亮在一个近点月（古称"转终"）中逐日快慢，累积的位置差称"迟疾差"（即月亮的中心差）。

推定朔，先推出平朔，算出平朔时刻太阳在年中的位置（"入气"）和月亮在近点月中的位置（"入转"），查两表得盈缩差与迟疾差，再把位置差换算成时间：

$$\text{定朔} = \text{平朔} + \frac{\text{盈缩差} - \text{迟疾差}}{\text{月日行} - \text{日日行}}$$

分母是月亮比太阳每日多走的度数，约 12.2 度。太阳偏前（盈），月亮要多追一会儿，合朔推迟；月亮偏前（疾），合朔提前。

### 内插：从刘焯到郭守敬

表只给出每气（约 15 日）或每日的值，所求时刻往往落在两行之间，要内插。线性内插太粗，隋刘焯《皇極曆》（600 年撰成，未颁行）创用二次内插。设表值 $f$ 在等间距的节点 $0, h, 2h$ 处已知，一阶差 $\Delta_1 = f(h) - f(0)$、$\Delta_2 = f(2h) - f(h)$，二阶差 $\Delta^2 = \Delta_2 - \Delta_1$，则在 $sh$（$0\le s\le 1$）处：

$$f(sh) \approx f(0) + s\,\Delta_1 + \frac{s(s-1)}{2}\,\Delta^2$$

这与西方的牛顿—格里高利前向差分公式（17 世纪）相同，刘焯早了一千余年。唐一行《大衍曆》（729）因二十四定气间距不等，发展出不等间距的二次内插。

元郭守敬等《授时曆》更进一步，不再用表，而用三次多项式直接表达盈缩差，称"平、立、定三差"（"招差术"）。《元史·曆志三·授時曆經上》：

> 其盈初縮末者，置立差三十一，以初末限乘之，加平差二萬四千六百，又以初末限乘之，用減定差五百一十三萬三千二百，餘再以初末限乘之，滿億為度，不滿退除為分秒。

即以 $x$ 为距冬至（或夏至）的日数（"初末限"），盈缩差为

$$\Delta(x) = \frac{(5133200 - 24600\,x - 31\,x^2)\,x}{10^8}\ \text{度}$$

盈初缩末限为 88.9092 日，代入得最大盈缩差 2.4014 度；缩初盈末一式（定差 4870600、平差 22100、立差 27，限 93.7120 日）同样得 2.4013 度，两式在限上衔接。按现代理论，1281 年地球轨道偏心率约 0.01701，太阳中心差的最大值约 1.95°，合古度（周天 365.2575 度）约 1.98 度，授时历的盈缩差偏大约 0.4 度。中国古历的盈缩差普遍偏大，原因尚待考。

### 定朔的实行

定朔虽好，推行却不容易。南朝何承天的元嘉历曾主张定朔，被以"月有頻三大、頻二小"驳回；唐初傅仁均戊寅历（619）首次用定朔颁历，二十余年后又改回平朔；李淳风麟德历（665）起定朔才成定制。

### 进朔

定朔若在一日的傍晚以后，当天的新月还看不见，次日初一的傍晚才可能见到。为免"晦日月见"，唐宋金元各历规定：定朔时刻过了某一限，就把初一推到次日，称"进朔"。各历的限不同：

| 历 | 进朔限 |
|---|---|
| 麟德 | 志文不载；按本纪归纳，约在 18—20 时之间 |
| 大衍 | 戌初（约 19 时） |
| 宣明 | 秋分后为一日的 3/4（18 时），春分后随昏明时刻减，约 17.8—18 时 |
| 崇天 | 日入时刻，约 16.8—19.2 时 |
| 明天、观天、纪元、金重修大明及南宋诸历 | 秋分后 3/4 日，春分后减春分日出分差之三分之一 |
| 授时、大统 | 不进朔 |

宋以后有的历又附加"有交食之朔不进"之类的例外。进朔的存在说明历日不只是天文计算：同一个定朔，进与不进差一日，而当时的历书确实是进了的（见下节例子）。

## 四、复原与检验

有些历的术文已经失传，无法复原：唐观象历、后晋调元历、辽贾俊大明历等。后周钦天历的全术虽存，但关键的日躔、月离表没有流传下来。

### 几个例子

**太初历与东汉四分历**：按术文推出的平朔，与张表比较，太初历（三统历）2325 个月中 2321 个相同，东汉四分历 1682 个月中 1681 个相同。

**麟德历**（唐，665—728）：据《新唐書·曆志》复原日躔、月离两表，推得的定朔与张表比较，792 个月中 707 个同日；张表晚一日的 61 个月，麟德定朔都在当天 14.6 时以后——张表在这些月施行了进朔。再拿本纪明书的 57 个朔日检验，合张表 55 个。志文没有写进朔的规则，可历书确实这样排。

**金重修大明历**（1182—1234）：《金史·曆志》载有全术，日躔、月离表据中华书局点校本核对。按术文推步，《金史》本纪明书朔日 192 条全合；若不进朔，只合 143 条。进朔确是金历实行的规则。

**杨级大明历**（金，1137—1181）：术文失传，只存历元和日法，于是用重修历的常数代为推算。这不是复原，只是代推，结论要打折扣：本纪 144 条中合 143 条，个别临界月份仍属未定。

### 复原的分档

即便有术文，复原也有可靠程度之分：

- 术文载有全部算法，进朔有明文的（重修大明、纪元、观天、明天、崇天等）最可靠；
- 术文载有常数与表，但算法细节或进朔规则要从他历或本纪归纳的（麟德、大衍等），次之；
- 关键步骤要由复原者假定的（如崇玄历，志文没有求定朔的方法），再次之；
- 术文失传、借他历代推的（杨级大明历），只能作参考。

无论哪一档，复原都只是"按这部历法应该推出什么"。要成为"当时历书上写的是什么"，还得经过史书日期、出土历日的检验；按资料可靠性的次序，按术文推算排在实物历日、史书明载日期、史志所载术文之后，只能由前者检验它，不能反过来用它改史书。

## 五、本项目的取法

- **精确分数**：推步一律用大整数与有理数运算，不用浮点数，保证与术文逐位一致。
- **换算取哪一家**：中原一线换算历史日期时，依次取实物历日、按术推步、张表、现代定气定朔，并注明来源；推步与张表之间按本纪检验逐历取舍（见《行用历日》）。
- **术文据原书**：常数与表据正史点校本与《开元占经》核对，异文与订正逐条注明（见《历代历法总录》）。
- **还缺的**：观象、调元、钦天、贾俊大明历无法复原；淳祐、会天、本天诸历术文未见；平气的历史交节时刻（明代及以前历书上的节气日）尚未逐年复原。
