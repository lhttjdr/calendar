# 各朝推步

主表是一条主线，分裂时期的其它政权各用自己的历。三国的蜀、吴，十六国的后秦、北凉，北朝的北魏、东西魏、北齐、北周，以及隋初，所用的都是平朔平气之历，术文大多保存在正史的律历志里，可以按术推步，得出各政权的历日。本章讲这类推步的统一算法、各历的常数与行用年代，以及怎样用本纪的记事日期、"閏月"、天象记录和出土历日检验推步结果。先秦古六历、春秋历和秦与汉初历的推步，附在章末。

本章的"推步"指今人按术文所作的计算，结果不是史实记录；能检验它的，只有实物历日与史书原文。

## 一、平朔平气推步

平朔平气之历只需要四个数：**朔策** $L$、**岁实** $Y$、一个**合朔历元** $J_m$（某次平朔的儒略日）、一个**冬至历元** $J_w$（某个平冬至的儒略日）。由此：

- 第 $i$ 个平朔在 $J_m + iL$；
- 第 $y$ 年的平冬至在 $J_w + yY$，平气间隔 $Y/24$，中气间隔 $Y/12$。

排一年的历：

1. **定岁首**：正月是含雨水的月。求雨水时刻 $Z_1 = J_w + (y + \tfrac16)Y$，取不晚于 $Z_1$ 所在日的最后一个平朔为正月朔 $m_1$。
2. **定闰否**：若 $m_1 + 13L$ 已越过下一年雨水所在日，则本年 12 个月，否则 13 个月。
3. **定各月**：第 $j$ 月朔所在日为 $\lfloor m_1 + jL + 0.5 \rfloor$（儒略日数，夜半为日界）；有闰时，从正月起找第一个不含中气的月为闰月。
4. **日干支**：由儒略日数直接求出。

这就是汉魏南北朝历书的排法。各历之间只有四个数不同，以及岁首、行用起讫年份的差别。

几个换历的依据：

- **北魏改行玄始历**：《魏書·律曆志上》："世祖平涼土，得趙𣤆所修玄始曆，後謂為密，以代景初。"平凉在 439 年，但敦煌出土的北魏太平真君十一、十二年（450、451）历日仍是景初历（见下文），所以改历当在 451 年以后。
- **明克让历**：《隋書·律曆志中》记北周时"露門學士明克讓、麟趾學士庾季才及諸日者，采祖暅舊議，通簡南北之術"。其历术不传，廖育栋以正光历常数、冬至历元加 0.4 日代之，本项目从之，是一种假定。
- **北齐天保历**：《隋書·律曆志中》："後齊文宣受禪，命散騎侍郎宋景業葉圖讖，造《天保曆》。"文宣帝 550 年受禅，通常以为 551 年起行用；按本纪检验，应是 552 年起（见下文）。

## 三、检验

推步结果是"这部历应该推出什么"，要靠一手史料检验。北朝可用的史料有四类：本纪记事日期、本纪"閏月"的位置、天象记录、出土历日。

### 本纪记事日期

本纪记事的"某月某干支"，干支必须落在当时历书的那个月里。从《三国志》魏、蜀、吴诸纪传，《魏书》《北齐书》《周书》本纪和《隋书·高祖纪》中抽出全部带日干支的日期，比较它们在主表与在推步表下是否在月：

| 系 | 日期数 | 在主表之月 | 在推步之月 |
| --- | --- | --- | --- |
| 北魏、西魏、北周、隋 | 4279 | 92.2% | 94.6% |
| 东魏、北齐 | 818 | 93.3% | 94.7% |
| 吴 | 37 | 73.0% | 73.0% |

本纪常不书月份更替，所以不可能全在月；关键是两表判断不同的那些日期。北魏系推步比主表多合 103 日，判断不一的 144 条逐年统计，几乎每年都只支持推步。吴主传的日期在两表下判断全同，不能判别。

### 本纪"閏月"的位置

本纪在某月之后书"閏月"，即当年闰在该月之后，这是闰位的直接证据（本纪常略书月份，"閏月"之前所记之月可能早于真正的闰月前一月，推步闰位恰在所记之月加一者算作略书）：

| 政权 | 条数 | 与主表合 | 与推步合 |
| --- | --- | --- | --- |
| 北魏 | 28 | 9 | 23 |
| 东魏 | 3 | 3 | 3 |
| 北齐 | 5 | 2 | 5 |
| 北周 | 7 | 2 | 6 |
| 隋 | 4（推步有数据者 2） | 2 | 2 |

北朝的闰位推步远胜主表。《周书》可定闰位的七年中，武成元年闰五、保定二年闰正、保定四年闰九、建德二年闰正、建德四年闰十、宣政元年闰六都合推步，只有天和二年（567）不合（见下）。

### 天象记录

天象记录的日期也是当时之历的一手证据，而且可以用现代天文计算判断：记录说某日"月犯南斗"，按两种历这一干支分别落在相差约两个月的两天，那天月亮离南斗是 1° 还是 60°，一算便知，判定不依赖任何复原表。北朝两表判断不一的记录共 14 条：

- **支持推步**：太和元年十二月癸卯"月犯南斗"（主表之日月距南斗 60.7°，推步之日 1.09°）、太和十八年四月庚申"月在斗蝕"（56.1°、1.45°）、正始四年十月癸未"月掩房"（59.9°、2.59°），以及几条行星记录。
- **支持主表**：太和十五年七月乙未"月犯太微東蕃"（主表之日 0.25°，推步之日 61.8°）、七月癸卯"月犯牽牛"（1.62°、60.8°）。

太和十五年（491）是一个有趣的例子：主表闰七月，推步（玄始历）闰五月，六、七月相差一月。《魏书·高祖纪》这年六月丁未、七月乙丑、戊寅、己卯、乙酉五个记事日期只在推步的月里，支持推步；而《魏书·天象志》同年七月的三条月亮记录却按主表（南朝历）的月序。本纪是北魏朝廷按所行之历记日，天象志的材料或许来自按南朝历记日的来源——这只是推测，尚无证据。

### 出土历日：北魏太平真君历日

邓文宽《敦煌天文历法文献辑校》所收"北魏太平真君十一年（450）、十二年（451）曆日"，是现知最早的敦煌历日，逐月录有月大小、朔干支、建除与节气。这是北朝唯一的实物历日：

| | 朔日（25 个月） | 450 年闰月 | 节气之日 |
| --- | --- | --- | --- |
| 推步（北魏系，景初历） | 25/25 | 闰七 | 48/48 |
| 主表（南朝元嘉历） | 21/25 | 闰十 | — |
| 玄始历重推 | 21/25 | 闰九 | 0/47 |

历日中七月之后的闰月"十五日白露八月節"而无中气，与无中气置闰全合。450—451 年北魏所行的是景初历，推步的朔、闰和平气常数逐日得证；同时证明《魏书·律历志》所说以玄始"代景初"，在 451 年以后才实行。

### 北齐行用天保历之年

兴和、天保两历在 545—577 年间月份有异者 16 年。逐年看《北齐书》本纪的记事日期在两历下各有几个在月：

| 551 | 22 | 21 | 17 | 四月后 | 闰四 | 闰二 |
| 553 | 19 | 17 | 19 | 十一月后 | 闰十二 | 闰十一 |
| 559 | 16 | 13 | 16 | | | |
| 561 | 12 | 9 | 11 | | | |
| 562 | 16 | 8 | 15 | | | |
| 564 | 24 | 23 | 23 | 九月后 | 闰十 | 闰九 |
| 567 | 16 | 13 | 15 | | | |

551 年本纪有三月丙午、己未、庚申，四月壬辰，閏月乙丑，五月丙戌、丁亥。以朔日序列试闰二、闰三、闰四，合者分别为 6/10、8/10、10/10，唯闰四全合，即兴和历。553 年起纪日与闰位都合天保历。所以天保历实行自 552 年（552 年两历无异，不能更细），551 年仍用兴和历。按此划分，东魏、北齐推步的在月率为 94.7%，本纪"閏月"5/5 全合。

### 未解之处

- **北周天和二年（567）**：主表（陈历）闰六月，推步（天和历）闰八月。《周书》"六月辛亥……甲子，月入畢。閏月庚午，地震……秋七月辛丑"，以及七月四个记事日期和《隋书·天文志》七月庚戌"太白犯軒轅"，都要求闰在六月或以前。天和历的闰余法（章岁 391、章闰 144）得闰九月，改用此前的明克让历或正光历得闰七月，都不合；只有陈历的闰六月相合。原因未明。
- **北周朔日差一日**：天和六年（571）"正月己酉朔"、大象二年（580）正月丁亥、七月甲申三处，所记之朔都是真实合朔之日，而平朔推步晚一日；开皇三年（583）"二月己巳朔，日有蝕之"则早于真实合朔一日。按《隋书·律历志》由上元积年重推，天和历（甄鸾甲寅元历）、大象历（马显丙寅元历）的天正冬至与天正朔都与推步常数一致，所以差异不出于常数。《隋書·律曆志中》说甄鸾造历"遂參用推步焉"，大象历也载有月行迟疾，所行或许不是纯粹的平朔。四例尚不足以定其法。
- **三处异说之月**：吴赤乌七年（244）十二月、十年（247）九月，以及北魏、北凉神䴥三年（430）二月，各家历表不一，既无天象记录，本纪记事日期也不能判别，仍作异说。

推步表保持按术推步的结果，不据这些个例手改。

## 四、先秦与秦汉之际

### 古六历

战国至汉初流传六种四分历：黄帝、颛顼、夏、殷、周、鲁，合称"古六历"。它们的岁实、朔策都与东汉四分历相同（$365\tfrac14$、$29\tfrac{499}{940}$），只有历元与岁首不同：

| 历 | 历元年（天文纪年） | 岁首（建） |
|---|---|---|
| 周 | −104 | 子 |
| 黄帝 | 170 | 子 |
| 殷 | −47 | 丑 |
| 鲁 | −481 | 子（合朔比冬至早朔策的 1/19） |
| 颛顼 | 14 | 亥（以立春合朔为元，闰在年终） |
| 夏（冬至起算，战国） | 444 | 寅 |
| 夏（雨水起算，春秋） | 444 | 寅 |

表中历元年是推步所取的基准年（从廖育栋的推步），不是这些历的制作年代。古六历是否真为各代所用、出于何时，学界意见不一；本项目只按其术推步，作为检验春秋战国历日的参照。

### 春秋历

春秋时期各国用历不一，鲁历也非一贯。张培瑜《中国古代历法》表 3-7 由《春秋》经传的日食与朔日干支归纳出前 721—前 482 年逐年是否有闰，并取朔策 $30328/1027$ 日（约 29.53067 日）。按此表与朔策推步，就得到春秋历谱。它对《春秋》经文的检验见《历代历法总录》。

### 秦与汉初历

秦与汉初（前 221—前 104）以十月为岁首，闰月置于年终，称"后九月"。朔策与四分历相同，历元依出土的历谱简牍分为三段（前 201 年以前、前 201—前 162 年、前 162 年以后）。复原方案与《汉书》的检验，见《秦与汉初历法》。

## 五、本项目的取法

- 蜀、吴、后秦、北凉、北魏系、东魏北齐系按上表推步，用精确分数运算，与廖育栋的推步逐月比对。不同之处只有两类：三处异说之月，廖育栋作了人工修正，本项目保持纯推步；北齐天保历的行用年，本项目据本纪改为 552 年起。
- 网页对同一天列出各政权历下的农历日期。
- 推步表保持纯推步，异说与未解之处在文中注明，不据个例手改。
- 还缺的：北周天和、大象历是否参用迟疾，尚待更多史料；明克让历术不传，只能代推。
