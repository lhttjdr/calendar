# 干支历四柱

把年、月、日、时都用干支表示，就是干支历；某一时刻的年、月、日、时四个干支合称"四柱"。日柱是六十日的纯循环（见《历日与纪日》），年、月、时三柱则要定"从什么时候换"，各家规则不同。本章只说明四柱怎样排、各家怎样取，不涉及命理解读。

## 年柱

年干支六十年一周，公元 4 年为甲子年：

$$\text{年干支序} = (\text{年} + 56) \bmod 60$$

问题在于一年从哪天算起：

| 换年规则 | 说明 | 用者 |
|---|---|---|
| 立春交节时刻 | 太阳视黄经 315° 的时刻起为新年 | 子平八字、《协纪辨方书》择日、风水 |
| 正月初一 0 时 | 农历新年 | 民俗黄历、紫微斗数 |
| 冬至交节时刻 | 太阳视黄经 270° 的时刻 | 奇门遁甲等（本项目预留，未用于预设） |

立春与正月初一可差半个月以上，这段时间里两种规则的年柱不同。

## 月柱

月支固定：正月建寅，二月建卯，……十二月建丑。月干由年干推出（"五虎遁"）：

| 年干 | 正月（寅月）的月干 |
|---|---|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

以后逐月顺推。换月有两种规则：

| 换月规则 | 说明 |
|---|---|
| 十二节交节时刻 | 立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒，各为一月之始 |
| 农历初一 0 时 | 以朔日为月首 |

按节换月时没有闰月问题。按初一换月时，闰月用哪个月的干支，各家不同：

| 闰月处理 | 说明 | 用者 |
|---|---|---|
| 随前月 | 闰几月就用几月的干支 | 民俗黄历 |
| 月中切分 | 闰月前十五日用本月干支，后十五日用下月 | 紫微斗数（古派） |
| 整月作下月 | 整个闰月用下月干支 | 紫微斗数（部分现代派） |

## 日柱与时柱

日柱按儒略日数推算。换日有两种规则：

- **子正换日**：0 时换日（现代通行）；
- **子初换日**：23 时即入次日（古法，子时跨两日，以子时开始为一日之始）。

一日分十二时辰，子时为 23 时至次日 1 时，丑时 1 至 3 时，依此类推。时干由日干推出（"五鼠遁"）：

| 日干 | 子时的时干 |
|---|---|
| 甲、己 | 甲子 |
| 乙、庚 | 丙子 |
| 丙、辛 | 戊子 |
| 丁、壬 | 庚子 |
| 戊、癸 | 壬子 |

23 时起的子时，时干一律按次日的日干推。时辰按北京时间的钟点划分，没有换算到当地的真太阳时；按真太阳时排时柱是另一派做法，本项目暂未提供。

## 四套预设

几种规则搭配起来，对应几家常见的用法：

| 预设 | 换年 | 换月 | 闰月 | 换日 |
|---|---|---|---|---|
| 子平八字 | 立春 | 节 | （不涉及） | 子初 |
| 紫微斗数（中州派） | 正月初一 | 初一 | 月中切分 | 子正 |
| 民俗黄历 | 正月初一 | 初一 | 随前月 | 子初 |
| 协纪辨方书 | 立春 | 节 | （不涉及） | 子初 |

四柱中凡用到立春、十二节的地方，都用本项目算出的节气时刻（见《二十四节气》），精确到秒；用到初一的地方，用农历的朔日（见《农历编排》《实历与主表》）。网页上的"干支历四柱"可以按这四套预设切换。
