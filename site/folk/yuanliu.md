# 民俗源流

本篇所讲的纪时、择日、式占、命理诸术，古人统称"术数"或"数术"。它们名目繁多，来历各异，但大都依附于历法：以干支、节气、朔望乃至日月五星的位置为输入，按一定的起例推出结果。本章先看古代目录学怎样给术数分类，再按时代梳理各支的源流，然后说明各术依附历法的程度，以及本篇取哪些、不取哪些。

## 一、古人怎样分类

### 《汉书·艺文志》的六种

东汉班固据刘向、刘歆父子的《七略》编《汉书·艺文志》，把"数术"列为六略之一，下分六种。各种的小序说明了其所以然：

| 种 | 家数、卷数 | 小序要语 |
|---|---|---|
| 天文 | 二十一家，四百四十五卷 | "序二十八宿，步五星日月，以紀吉凶之象" |
| 历谱 | 十八家，六百六卷 | "序四時之位，正分至之節，會日月五星之辰" |
| 五行 | 三十一家，六百五十二卷 | "小數家因此以為吉凶"；所录有《堪輿金匱》《轉位十二神》《羨門式法》《風后孤虛》《風鼓六甲》 |
| 蓍龟 | 十五家，四百一卷 | "定天下之吉凶……莫善於蓍龜"；所录有《龜書》《夏龜》等 |
| 杂占 | 十八家，三百一十三卷 | "紀百事之象，候善惡之徵"，以占梦为大 |
| 形法 | 六家，百二十二卷 | "大舉九州之勢以立城郭室舍形，人及六畜骨法之度數"；所录有《宮宅地形》《相人》 |

总序说："數術者，皆明堂羲和史卜之職也。"天文、历谱与后四种同列一略，可见在汉人看来，步算日月与占验吉凶本是一家之学。后世择日、式占所用的堪舆、式法，当时都归在"五行"之下。

### 《史记·日者列传》的七家

《史记·日者列传》记汉武帝召集占家，问某日可否娶妇，"有五行家、堪輿家、建除家、叢辰家、曆家、天文家、太乙家凡七家"（据《四库全书总目》卷一百九所引）。建除、丛辰、堪舆是择日的源头，太乙是式占的一支，此时已各成一家。

### 《四库全书总目》的七小类

清代《四库全书总目》子部术数类，开篇的序说："術數之興，多在秦、漢以後。要其旨，不出乎陰陽五行，生克制化，實皆《易》之支派，傅以雜說耳。"其下分七小类（卷一百八至一百十一）：

| 小类 | 按语要语 | 本篇所据之书在此类者 |
|---|---|---|
| 数学 | "物生有象，象生有數，乘除推闡" | — |
| 占候 | "占天本以授時，而流為測驗災祥" | — |
| 相宅相墓 | "相宅、相墓，自稱堪輿家" | 《宅經》《葬書》《撼龍經》《青囊奧語》 |
| 占卜 | "凡依託易義，因數以觀吉凶者，統謂之占卜" | 《京氏易傳》《易林》《六壬大全》《卜法詳考》 |
| 命书相书 | "命言前知，主於一定不可移。他術則皆言可趨避" | 《李虛中命書》《星命總括》《星學大成》《三命通會》 |
| 阴阳五行 | "《漢志》並為陰陽、五行二家……今總題曰陰陽五行，以存舊目" | 《太乙金鏡式經》《遁甲演義》《御定星曆考原》《欽定協紀辨方書》 |
| 杂技术 | 占梦之类 | — |

值得注意的是，四库把"三式"拆在两处：太乙、遁甲入阴阳五行，六壬入占卜。择日书也归阴阳五行。命书与相书合为一类，是因为两者都"言前知"。

## 二、源流

### 龟与筮

商代以龟甲兽骨占卜：先在甲骨背面钻凿，再灼烧，看正面裂出的兆纹判断吉凶，并把卜辞刻在旁边。周代卜筮并用，《周礼·春官·大卜》说："掌三兆之法，一曰玉兆，二曰瓦兆，三曰原兆……掌三易之法，一曰連山，二曰歸藏，三曰周易。"《尚书·洪范》讲稽疑："曰雨，曰霽，曰蒙，曰驛，曰克，曰貞，曰悔，凡七。卜五，占用二"，前五种是龟兆，后二种是筮卦的贞、悔。

龟卜后来衰落。据四库《卜法詳考》提要的考述："《漢書·藝文志》載《龜書》五十二卷……則漢時其書猶多"，褚少孙补《史记·龟策列传》述其占法；《隋书·经籍志》只剩史苏《龟经》一卷，《新唐书·艺文志》有孙思邈《龟经》，到《宋史·艺文志》又"頓增史蘇以下十九部，其為輾轉依託，可以概見"；元代有陆森《玉灵聚义》，清代胡煦辑成《卜法詳考》。

筮法另有两支。一支是《周易》本筮：以五十策演大衍之数，得出本卦，再看变爻得出之卦，依卦辞爻辞断事。《左传》《国语》所载筮例，都是"遇某卦之某卦"的形式；南宋朱熹《易学启蒙》"考变占"一篇，依变爻多少规定取本卦还是之卦的哪一句卦爻辞。另一支是西汉京房的纳甲：把天干地支配到卦爻上，以五行生克断事，不再看卦爻辞。后世的"六爻"就出于这一支，宋有《火珠林》，清有《卜筮正宗》《增删卜易》。托名北宋邵雍的《梅花易数》也属占卜一类。

### 观星

仰观天象、占验人事，是最古老的一支。《汉书·艺文志》把天文、历谱与五行、蓍龟同列于数术略，总序称"六國時楚有甘公，魏有石申夫"：战国甘德、石申的星经已经散佚，只在后世占书中留有片段。司马迁作《史记·天官书》，此后历代正史都有天文志、五行志，记录日月食、彗孛、五星凌犯，并附占辞。天文篇"史书天象检验"一章逐条核对的那些记录，就是星占的原始材料。

唐代李淳风作《乙巳占》，瞿昙悉达编成《开元占经》一百二十卷；四库说后者保存了许多唐以前的古籍，"古籍之不存者多賴其徵引以傳"。宋代有《灵台秘苑》；明代刘基作《清类天文分野之书》，以天上星区分配地上州郡，即所谓"分野"。风角、云气等"占候"之书，四库存目中有题李淳风的《观象玩占》等。

另有外来的一支。唐代随佛经和西域天文传入的星命书，有不空所译《宿曜经》、金俱吒《七曜攘灾决》，以及只见书目的《都利聿斯经》《聿斯四门经》。明洪武十六年（1383），朝廷又组织海达儿等人翻译了回回《天文书》。这一支的末流就是七政四余（见下"命"一节）。

本篇只算天象的位置与时刻，不论占验。

### 日书与日者

睡虎地、放马滩两地出土的秦简《日书》，有建除、丛辰等篇，按日的干支和月建定宜忌，这是今日所见最早的择日书。到汉武帝时，日者已分为建除、丛辰、堪舆等七家；《汉书·艺文志》所录《堪輿金匱》《鍾律叢辰日苑》都在五行家。

此后经唐五代具注历日、元末《类编历法通书大全》、明清各家通书，清乾隆四年（1739）官修《钦定协纪辨方书》加以考订，择日一系的规则从此以钦天监颁行的时宪书为准。神煞宜忌、年神方位等内容，就出自这一系。

### 式

"式"是一种占具：上为圆盘象天，下为方盘象地，天盘可以转动。汉墓中已出土过六壬式盘和太乙九宫占盘，《汉书·艺文志》五行家也著录了《羨門式法》《轉位十二神》。太乙、遁甲、六壬合称"三式"，都由式盘演化而来。

- **太乙**：唐王希明《太乙金镜式经》是今存最早的完整太乙书。太乙按积年推算局数，用于推国运、兵事、水旱。
- **遁甲**：唐李筌《太白阴经》卷九已有遁甲。宋仁宗景祐年间官修遁甲书，据陈振孙《书录解题》，为"《遁甲玉函符應經》，為司天春官正楊惟德撰，而仁宗御製序文"。明程道生《遁甲演义》集其大成，清代有《御定奇门宝鉴》。时家飞盘出于明代陶仲文，与古法转盘并行。
- **六壬**：明《六壬大全》汇集诸家，四库提要说它"所取天乙尚沿俗例"。

遁甲有"托始黄帝风后"之说。《遁甲演义》卷一所引的歌诀说："因命風后演成文，遁甲竒門從此始；一千八十當時制，太公刪成七十二……張子房一十八局"。四库提要对此辨正道："神其說者以為出自黄帝風后及九天元女，其依托固不待辨……考漢志所列，惟風鼓六甲、風后孤虚而已，於竒遁尚無明文；至梁簡文帝樂府始有三門應遁甲語，陳書武帝紀遁甲之名遂見於史。"

另有一部旧题风后撰的《握奇经》（又作《握机经》），讲的是八阵。四库将它列入兵家，提要认为是唐以来好事者根据诸葛亮八阵推演、再托名风后而成，"《宋史·藝文志》始著於錄，其晚出之顯證矣"，旧附的西晋马隆述赞也是依托。诸葛亮"推演兵法，作八陣圖"见于《三国志》本传，属于兵家阵法，与遁甲的排局是两回事。明清坊间刻印的奇门书，常题"诸葛武侯"或"刘伯温"所撰。四库在《将苑》提要中一语道破："宋以來兵家之書，多托於亮；明以來術數之書，多托於劉基。"今人还有以"风后奇门"为名的流派，所据何书尚未查到。

### 命

以人出生的时刻推断命运，四库按语追溯到王充《论衡》"人生時值星"的说法。今存命学有两大系统：

- **星命（七政四余）**：唐代随西域天文传入，用日月五星（七政）和罗睺、计都、紫炁、月孛（四余）在黄道上的真实位置推命。罗睺、计都即月亮轨道与黄道的两个交点，名称来自印度。今存有宋代的《星命溯源》《星命总括》，明代万民英的《星学大成》。
- **干支命理**：唐代李虚中以生年月日的干支推命（据韩愈为他写的墓志），宋代徐子平以日干为主、加上时柱，于是有"子平"之名。明代万民英的《三命通会》集其大成。
- **紫微斗数**：今存最早的是明万历三十五年（1607）《续道藏》本，属十八飞星一派；通行的十四主星派以明代《紫微斗数全书》为代表。两派都按出生的农历月日时辰排星。

### 宅与墓

《汉书·艺文志》形法类录有《宮宅地形》。后世相地之学托名黄帝《宅经》、晋郭璞《葬书》、唐杨筠松《撼龙经》《青囊奥语》，四库归入"相宅相墓"类。后来分为两派：一派是形法（峦头），看山川形势；一派是理气，配合卦位、方位与时运。清初蒋大鸿一系的玄空，以三元九运和罗盘坐向推算飞星，属于理气一派。

### 近代新说

二十世纪以后流行的五格剖象法（姓名学），起源于日本，与古代术数并无渊源；数字能量等更是当代产物。它们都不依附历法。

## 三、依附历法的程度

各术需要的输入差别很大，这决定了哪些能"按规则推出"：

| 输入 | 术 |
|---|---|
| 只要干支 | 纳音、值日、建除、黄道黑道、百忌，年神方位，紫微斗数（年干支加农历月日时辰） |
| 要节气时刻 | 月建与交节、土王用事、三伏社日、奇门定局（节气配局）、六壬月将（中气） |
| 要朔望 | 农历月日、反支、晦日、朔弦望 |
| 要日月五星真位置 | 七政四余 |
| 要方位 | 年神方位、奇门八宫、六壬天地盘、太乙宫位、玄空坐向 |
| 要天象位置但只论占验 | 星占（位置可算，占辞不作推算） |
| 不依历法 | 龟卜（兆纹出于灼烧）、相术、占梦、姓名学 |

前五类只要有可靠的天文历法计算，再按原典起例逐条推算，结果就是确定的；各家起例不同，就把各家并列。最后一类没有可以推算的输入，只能讲源流。

## 四、本篇的取法

- **取**：依附天文历法、能按原典规则推算的，包括纪时、节令、择日、式占（太乙、遁甲、六壬）、命理（七政四余、紫微斗数）、风水理气（三元九运、玄空），以及筮法（大衍筮法与考变占、京房纳甲）。
- **只讲源流**：龟卜；星占的占验部分（天象位置由天文篇计算）。
- **不取**：相术、占梦、姓名学、数字能量等。
- **出处与诸家**：起例一律以原典为准，注明卷次；各家不同的并列，不作取舍。托名之书与今人流派，原书可见的照录并注明，不可见的只记其名。

## 附：书目

下面两份书目逐条抽自原书：一是《四库全书总目》子部术数类的全部著录与存目，二是《汉书·艺文志》数术略的书名。"本篇"一栏注明该书所属之门在本篇是否推算。

### 《四库全书总目》子部术数类全目（卷一百八至一百十一）

据维基文库录文逐条抽取，著录五十部、存目一百四十六部（另附录二部），与各小类末「右某屬若干部」相符。「撰者」取提要首句（「舊本題」即托名）。「本篇」：该书所属之门在本篇的状态（本篇做、进行中、未做、只入源流、不做）；★为本篇所据之书。按书名与小类判，原书未读者以提要为准。
