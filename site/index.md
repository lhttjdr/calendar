# 农历的天文计算与历史复原

这里说明一件事是怎样做成的：从太阳、月亮在天上的真实运行出发，算出每一个合朔、每一个节气，排出农历；再往前，按历代历法的术文复原古人实际用过的历日，并用史书里的日期和天象记录检验它。

全文分四篇，按依赖的先后排列：数学是工具，天文算出日月的位置与时刻，历法据此排出历日，民俗又依附在历日之上。建议按顺序读。

## 数学篇

全书通用的计算工具。

- **基础**：
  1. **向量与空间**——点与向量、点积叉积、坐标与尺度因子、量纲、位置与速度的六维状态。
  2. **转动**——转动矩阵、欧拉转动定理、四元数与对偶四元数。
  3. **数值精度**——双精度与双双精度，误差有多大，速度与精度怎样取舍。
- **数值方法**：
  4. **级数求值**——历表、岁差、章动的级数形式与项数，怎样快而准地求值。
  5. **求根与极值**——合朔、节气、大距、食甚等时刻的求法与收敛判据。
  6. **最小二乘拟合**——线性与非线性拟合、形式误差、按独立样本选型，以历表的拟合为例。

## 天文篇

讲怎样算出任意时刻太阳、月亮、行星的位置，以及由此得到的天象。

- **基础**：
  1. **天球坐标**——赤道、黄道、春分点，黄经为什么是历法的核心。
  2. **时间与时标**——儒略日、各种时标、$\Delta T$。
  3. **参考架**——历元、分点，同一颗星为什么有不同的坐标。
  4. **岁差**——地轴两万六千年一周的进动。
  5. **章动**——18.6 年周期的小幅摆动。
  6. **历表**——太阳、月亮的位置从哪里来，对齐 JPL 数值历表能准到什么程度。
  7. **模型配套**——历表、$\Delta T$、参考架各以什么为准，混用会差多少。
- **位置**：
  8. **视位置**——光行时与光行差，从几何位置到看见的位置。
- **天象**：
  9. **合朔与月相**、10. **二十四节气**——农历所需的两组时刻。
  11. **日月食**、12. **行星**、13. **恒星与二十八宿**、14. **当地星空**——天象的计算与检验。
  15. **史书天象检验**——二十四史日月食、凌犯逐朝代核验。

## 历法篇

讲怎样从这些时刻排出农历，以及历史上的历日与今天的有何不同。

- **基础**：
  1. **历日与纪日**——儒略日数，儒略历、格里历与民用历，两种纪年，干支纪日，日界。
- **农历**：
  2. **农历编排**——现行规则，闰月从何而来。
  3. **实历与主表**——历史上实际行用的历日，多政权并存，月序改制，以本纪核验主表。
- **古历**：
  4. **古历复原**——平朔平气、定朔的推步方法。
  5. **各朝推步**——三国、南北朝、辽金等政权历的推步参数与检验。
  6. **秦与汉初历法**——太初以前的复原方案与《汉书》检验。
  7. **历代历法总录**——资料可靠性分级，各历常数、表、算法与检验，进朔法沿革。
- **纪年**：
  8. **年号纪年**——政权、帝号、年号，并存政权与改元。

## 民俗篇

依附在历法上的纪时与择日规则。只算到规则给出的结果，各派分歧并列，不做吉凶与命运解读。

- **总论**：
  1. **民俗源流**——术数的分类（汉志数术略、四库术数类）与源流，从龟卜、日书、式盘到明清诸家，附书目长表。
- **纪时**：
  2. **干支历四柱**——年、月、日、时四柱的排法，各家换年、换月、换日的规则。
  3. **纳音与值日**——六十甲子纳音，二十八宿值日与七曜，年月紫白九星。
  4. **更点时刻**——百刻制与夜漏更点，元授时法与清台官法。
- **节令**：
  5. **杂节气**——三伏、社日、寒食、腊日、入梅出梅、土王用事、数九、七十二候。
- **择日**：
  6. **建除与黄道**——建除十二值、黄道黑道十二神、百忌日。
  7. **神煞宜忌**——神煞起例、宜忌等第与月表、逐年铺注、年神方位，以乾隆三十年时宪书逐日核对。

## 关于本站

本站的计算都来自同一个开源项目，网页上的日历、星图、日月食图用的也是这套计算。动画均按真实几何绘制；个别量级太小、无法直接画出的效应（如章动、参考架偏差）在图中放大，并在字幕里注明放大了多少。

项目仓库中另有面向开发者的文档，记录代码结构与实现细节。
