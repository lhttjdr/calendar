# 史书天象检验

二十四史的本纪、天文志、五行志记有数千条日月食与"凌犯"——月亮、五星与恒星、彼此之间的接近。它们是古代天象的一手记录，也是检验历日换算、地球自转（$\Delta T$）的独立材料。本章先讲这些记录的术语与来历，再讲检验的方法，然后按朝代给出结论：哪些朝代的记录可靠，哪些不宜当作天象依据。

## 一、记录的术语

史书描述天体接近，用一套术语：

| 术语 | 一般含义 |
|---|---|
| 犯 | 两者接近。《清史稿·天文志》卷首定义"相距一度内"为犯 |
| 掩 | 月或行星遮住恒星、行星（月掩星） |
| 入 | 进入某星官（多为大星官，如"入太微"） |
| 守 | 行星在某处停留，多指留前后的缓慢移动，如"荧惑守心" |
| 合、聚 | 两星或数星同在一宿；清代"同躔某宿某度"指经度同度，不是角距近 |
| 乘、食、在 | 乘为接近（多指在其上方），食为掩，在为位于 |

除清代外，各代没有统一的数值定义，所以检验时按 1°、2° 两档统计，并与随机日期的基线相比。

## 二、源流

中国自汉代起，太史令逐日观测、记录天象，以备占验；正史设天文志、五行志收录。记录的动机是占验：天象被看作人事的征兆，史家常把天象与事应并书。这带来两个问题：一是记录有时出于推算或预报（如钦天监预推的日食、凌犯），不是实见；二是为附会事应，可能有天象被编造。黄一农以"荧惑守心"为例，指出若干记录与实际天象不合，当是伪造（篇目、刊期待核）。

今人系统利用这些记录，大致有两条路：

| 方向 | 代表 | 内容 |
|---|---|---|
| 汇编 | 北京天文台主编《中国古代天象记录总集》（1988）；庄威凤主编《中国古代天象记录的研究与应用》 | 把散在各书的记录分类汇集、考订 |
| 用于地球自转 | Stephenson、Morrison 等 | 以日食在某城可见与否约束 $\Delta T$，中国记录是主要材料之一 |
| 检验可靠性 | 刘次沅、马莉萍、邢钢与石云里、Pankenier 等 | 逐朝核对日食、凌犯与计算是否相合 |

## 三、方法

- **日期只按历法换算，不用天象。** 太初（前 104）以前用秦与汉初复原历（十月岁首），以后用主表；新莽、魏景初建丑，武周、唐肃宗末建子的时期按当时月序换算；北朝用各自的推步历。这样日期与天象互不依赖，检验才有意义。
- **日月食**：方法见《日月食》一章。所记之日 ±1.5 日内确有食算"有食"，再看当时都城是否可见；月食按"夜日"（日界取正午）记日。
- **月、五星凌犯与相合**：站心位置；只在天黑（太阳低于 −6°）且天体在地平上的时段内求最小角距；一夜自当地正午起计（实测显示史书把整夜的天象记在入夜那一天）。主角距依次取具体星、天体之间、星官成员中最近者。
- **随机基线**：把同一批记录的日期错开 ±60—240 日重算，行星 ≤1° 的比例只有 1%—2%。记录的命中率远高于此，说明日期换算与认星基本正确。
- **日期偏移**：对行星记录，找出记载日 ±4 年内与目标角距小于 1° 的全部时段，用来区分"年、月记错，换个日期就合"与"换日期也不合"；日干支不在所记之月者，列出同一干支可落之月。

几点总的观察：

- **可靠的时期**：东汉、三国、南朝、元，行星记录 ±4 年内都找不到 1° 内时段的只占 2%—7%，记录的日期总体可靠。元代命中率在各代中最高。
- **不可靠的时期**：西晋。两部独立成文的史书（《晋书》《宋书》）结论一致，三分之一的行星记录在前后四年内都不可能发生，"荧惑守心"一类尤甚。这类记录不宜用作天象依据。
- **记录口径**：《旧唐书》多记距离（"去東井一尺"），与推算对照，一尺约合 1°；清代"同躔"是经度同度、凌犯书钦天监预推的地心相距，都要按其口径检验。

## 六、本项目的取法

- **记录是检验对象，不是真值**：天象计算（日月食、合朔、行星位置）在问"当时天象如何"时可靠性最高，用它来检验记录；但它不能证明历日，日期一律由历法换算。
- **按原文口径**：凌犯按 1°、2° 两档；清代按时宪历黄道宿度与"同躔"之义；日食区分实见与预推。
- **不据推算改原文**：日干支不在所记之月、年号误认等，只在逐条结果中注明可能的校法，不改数据。
- **还缺的**：《汉书》新莽记录未单独解析；《清史稿》天文志卷三十至三十五无录文；金代天文志尚按宋历换算；彗孛、流星、云气等不涉及位置计算的记录不在检验之列。
