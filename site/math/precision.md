# 数值精度

计算总要用有限位的数。古代历家用分数，以"日法"为分母，把一切时间化为整数的"分"；元代《授時曆》改用百进的小数；今天的计算机用二进制浮点数。本章讲浮点数的原理与误差从哪里来，怎样用两个浮点数拼出更高的精度，历代计数制度的演变，以及本项目用什么精度、误差多大、速度与精度怎样取舍。

## 一、浮点数

### 表示

浮点数把一个实数写成 $\pm m \times 2^e$，$m$ 是有限位的二进制小数（尾数），$e$ 是整数（指数）。IEEE 754 标准规定的双精度数用 64 位：1 位符号、11 位指数、52 位尾数，加上隐含的最高位共 53 位有效二进制数字，约合 16 位十进制。

任何实数存进浮点数，都要舍入到最近的可表示数。相对误差不超过单位舍入 $u = 2^{-53} \approx 1.1\times10^{-16}$。加减乘除与开方，IEEE 754 规定结果必须是"精确结果的正确舍入"，即每一次运算只引入一次至多 $u$ 的相对误差：

$$\mathrm{fl}(a \circ b) = (a \circ b)(1 + \delta),\qquad |\delta| \le u$$

这一条使浮点运算的误差可以分析。

### 有效位在哪里丢失

单次运算的误差极小，丢失有效位的是以下几种情形：

- **大数加小数。** $10^6 + 10^{-12}$ 在双精度下等于 $10^6$：小数的全部位数都落在大数的最低位以下。
- **相近的数相减。** $1.000000001 - 1.000000000$，两数各有 16 位有效数字，差只剩 7 位。这叫"相消"，本身没有引入新误差，却把先前已有的舍入误差放大成主要部分。
- **误差的传递与放大。** 问题本身若"病态"（输入的微小变化引起输出的大变化），任何算法都无法补救。条件数衡量这种放大（见《最小二乘拟合》中法方程的例子）。

天文计算中最典型的两处：

- **儒略日。** 现代的儒略日约 $2.46\times10^6$，双精度下最低一位约为 $2.46\times10^6 \times 2^{-52} \approx 5\times10^{-10}$ 日，即约 40 微秒。前 3000 年附近相同。月亮 40 微秒走约 $2\times10^{-5}$″。把儒略日与一个小时间差相加，小数部分低于 40 微秒的部分就丢了。
- **大相位的约化。** 月亮平黄经在公元前 3000 年时约 $4\times10^5$ 弧度，约化到一周以内后，只剩约 $10^{-10}$ 弧度的精度（见《级数求值》）。

天文学的标准库 SOFA 为此把儒略日拆成两个双精度数之和传递（如整日数与日内小数），两部分各自保有完整的 16 位，时间分辨率可达皮秒级。JPL 历表的读取也常这样做。

### 误差分析

威尔金森（J. H. Wilkinson）在 1960 年代建立了舍入误差的"向后分析"：不问算出的结果离真值多远，而问它是哪一个稍有扰动的问题的精确解。若扰动与舍入同量级，算法就是"向后稳定"的；结果的误差则等于扰动乘以问题的条件数。这把算法的好坏（稳定性）和问题的难易（条件数）分开了。

## 二、更高的精度

### 无误差变换

两个浮点数相加，舍入丢掉的那部分本身也是一个浮点数，而且能用浮点运算精确求出（Møller 1965；Knuth 1969）：

$$s = \mathrm{fl}(a + b),\quad b' = \mathrm{fl}(s - a),\quad e = \mathrm{fl}\big((a - (s - b')) + (b - b')\big)$$

则严格有 $a + b = s + e$。乘法也有同样的分解（Dekker 1971，或用"乘加融合"指令一步求出）。这类运算叫"无误差变换"：一对浮点数 $(s, e)$ 精确地表示了 $a + b$。

### 双双精度

Dekker 在 1971 年据此提出：用两个双精度数之和 $x = x_\text{hi} + x_\text{lo}$（$|x_\text{lo}| \le u|x_\text{hi}|$）表示一个数，约 106 位二进制、32 位十进制有效数字，四则运算都用无误差变换实现。这就是双双精度（double-double），后来有 Bailey 等的 QD 库（Hida、Li、Bailey 2001）。再往上有任意精度库，如 MPFR（Fousse 等 2007）。

| 精度 | 有效数字（十进制） | 实现 | 相对速度 |
|---|---|---|---|
| 双精度 | 约 16 | 硬件 | 1 |
| 双双精度 | 约 32 | 软件，无误差变换 | 加减乘约慢十倍，三角函数约慢数十倍 |
| 四倍精度（IEEE binary128） | 约 34 | 多为软件 | 慢数十倍 |
| 任意精度（MPFR） | 任意 | 软件 | 更慢，随位数增加 |
| 有理数精确运算 | 无舍入 | 大整数分子分母 | 视分母大小 |

### 两种精度互检

高精度最有用的地方不在于直接算，而在于检验：同一套算法用两种精度各算一遍，差就是低精度的舍入误差（只要高精度的误差小得多）。这比理论上的误差上界更实际：误差上界往往过于悲观，而实测的差直接回答"双精度够不够"。

## 三、历代的计数制度

### 分数制：日法

中国古历不用小数，而是选一个分母，称"日法"，把日的零头记作"分"。西汉《太初曆》及刘歆据以改编的《三統曆》日法 81，东汉《四分曆》日法 4。一个朔望月记作若干日又若干分，岁实、朔策都化为日法的整数倍，于是推步全用整数运算，没有舍入误差。代价是：为使朔望月、回归年、甚至五星周期都能被同一个日法整除，又要求上古某时"日月合璧、五星联珠"作为历元（"上元积年"），积年动辄数万、数十万乃至上亿年，推算时要处理很大的整数。《元史》列出汉以来各历的积年日法，第一条即《三統曆》（原注"西漢太初元年丁丑鄧平造"）：积年 144511，日法 81；次为《四分曆》：积年 10561，日法 4。

### 百进制：授时历

元郭守敬、王恂等的《授時曆》（1281）废除上元积年与日法，以当时的至元十八年为历元，日以下一律百进：

> 今授時曆以至元辛巳為元，所用之數，一本諸天，秒而分，分而刻，刻而日，皆以百為率，比之他曆積年日法，推演附會，出於人為者，為得自然。（《元史》卷五十三《曆志二·授時曆議下·不用積年日法》）

历经开头便是"日周，一萬"（《元史》卷五十四《授時曆經上·步氣朔第一》）：一日为一万分，岁实三百六十五万二千四百二十五分，即 365.2425 日。这是有限位的十进制小数，与今天的定点数同理：不再追求整除，而是取足够的位数，接受舍入。

同一卷还记下了反对者的意见："昔人謂建曆之本，必先立元，元正然後定日法……今一切削去，無乃昧於本原"；作者引晋杜预"治曆者，當順天以求合，非為合以驗天"作答。从分数制到小数制，不只是记数方法的改变，也是从追求数的整齐，转向追求与天象相合。

### 二进制浮点

计算机的浮点数始于楚泽（Konrad Zuse）1941 年的 Z3。早期各家机器的浮点格式、舍入规则互不相同，同一程序在不同机器上结果不一。1985 年 IEEE 754 标准统一了格式与舍入，主持者卡亨（William Kahan）因此获 1989 年图灵奖。2008 年的修订加入了乘加融合运算与十进制浮点。

| 年代 | 制度或人物 | 要点 |
|---|---|---|
| 前 104 | 邓平等《太初曆》（刘歆改编为《三統曆》） | 日法 81，上元积年 |
| 1281 | 郭守敬、王恂《授時曆》 | 废积年日法，日周一万，百进 |
| 1941 | 楚泽 Z3 | 二进制浮点 |
| 1963 | 威尔金森 | 舍入误差的向后分析 |
| 1965—1971 | Møller；Knuth；Dekker | 无误差变换；双双精度 |
| 1985、2008 | IEEE 754（卡亨） | 浮点格式与正确舍入的标准 |
| 2001、2007 | QD；MPFR | 多倍精度库 |

## 四、本项目的取法

### 双精度够不够

全部计算可以在双精度与双双精度之间整体切换，同一套代码、同一组检验都能用两种精度各跑一遍。实测两者之差：

| 量 | 双精度与双双精度之差 |
|---|---|
| 月亮完整位置（ELP/MPP02 全部项） | ≤ 2 厘米（≤ $10^{-5}$″） |
| 合朔时刻（前 3000—公元 3000 年，每 500 年取一年，54 个朔） | ≤ 0.1 毫秒 |
| 节气时刻（同上，104 个节气） | ≤ 0.3 毫秒 |
| 上面这些朔、节气落在东八区哪一天 | 无一不同 |
| 行星大距、近距的极值时刻 | ≤ 0.2 秒 |
| 日月食典对照（时刻印到 0.1 秒，γ、食分印到 $10^{-4}$）、史书凌犯（角距印到 0.01°） | 逐格相同 |

极值时刻的差最大，因为极值附近函数变化平缓，数值噪声被放大（求法见《求根与极值》）。朔、节气的抽样中没有一条落日不同，但这只是抽样：时刻恰在午夜前后 0.3 毫秒以内的朔气，日期仍可能随精度翻转，只是这种情形极少，而且 $\Delta T$ 等模型误差远大于此。

### 与其他误差比

| 误差来源（月亮） | 量级 |
|---|---|
| 双精度与双双精度之差 | ≤ $10^{-5}$″ |
| 双精度儒略日的时间分辨率（40 微秒） | 约 $2\times10^{-5}$″ |
| 历表与 JPL 数值历表之差（前 3000—公元 3000 年） | 约 1″ |
| $\Delta T$ 的不确定度（前 200 年约 110 秒） | 约 1′ |

双精度的误差比历表本身小 4—5 个量级，比古代 $\Delta T$ 的不确定度小约 7 个量级。

### 速度

| 操作 | 双双精度 | 双精度 | 倍数 |
|---|---|---|---|
| 月亮级数求值（3.6 万项） | 9.7 毫秒 | 0.42 毫秒 | 约 23 |
| 月亮视位置（含光行时迭代） | 184 毫秒 | 8.3 毫秒 | 约 22 |
| 格林尼治视恒星时（含完整章动） | 700 微秒 | 40 微秒 | 约 18 |
| 全部天象逐条校验 | 约 1.5 小时 | 约 5 分钟 | — |

也试过折中做法：相位约化与三角函数用双精度，只把求和留在双双精度。结果只快约 3 倍，因为三角函数便宜之后，相位多项式与乘加的双双精度运算成了大头；而精度并不比全双精度更有意义，故不采用。

### 取舍

- **缺省用双精度。** 网页、排历、天象检验、批量搜索都用它。
- **双双精度只作参照。** 用来检验双精度的误差：发现数值上的可疑之处时，用两种精度各算一遍，看差异是否来自精度本身。
- **两种精度的逐格比对作为常规检验。** 每张校验表都注明所用精度；全部校验另有一项两种精度逐格比对，不一致即报错。
- **古历复原用有理数精确运算。** 按术文复原古历时，日法、朔余等照原文的分数精确计算，不引入舍入，与历家的整数推步逐位一致。
