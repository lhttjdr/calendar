# 数值精度

计算机里的实数是有限位的浮点数。本章说明本项目用什么精度做计算、这种精度带来的误差有多大，以及速度与精度怎样取舍。

## 两种精度

- **双精度**（IEEE 754 double）：53 位二进制有效位，约 16 位十进制。硬件直接支持，最快。
- **双双精度**（double-double）：用两个双精度数之和表示一个数，约 106 位二进制、32 位十进制有效位。由软件实现，一次三角函数约慢 40 倍。

全部计算可以在两种精度之间整体切换，同一套代码、同一组检验都能用两种精度各跑一遍。

## 双精度够不够

双精度的相对精度约 $10^{-16}$，但有两处会损失有效位：

- **儒略日。** 现代的儒略日约 $2.46\times10^6$，双精度下时间分辨率约 40 微秒；前 3000 年附近相同。月亮 40 微秒走约 $2\times10^{-5}$″。
- **大相位的约化。** 月亮相位可达 $4\times10^5$ 弧度，约化到一周以内后剩下约 $10^{-10}$ 弧度的精度。

把两种精度的结果逐项比较，就能直接量出双精度的误差：

| 量 | 双精度与双双精度之差 |
|---|---|
| 月亮完整位置（ELP/MPP02 全部项） | ≤ 2 厘米（≤ $10^{-5}$″） |
| 合朔时刻（前 3000—公元 3000 年，每 500 年取一年，54 个朔） | ≤ 0.1 毫秒 |
| 节气时刻（同上，104 个节气） | ≤ 0.3 毫秒 |
| 上面这些朔、节气落在东八区哪一天 | 无一不同 |
| 行星大距、近距的极值时刻 | ≤ 0.2 秒 |
| 日月食典对照（时刻印到 0.1 秒，γ、食分印到 $10^{-4}$）、史书凌犯（角距印到 0.01°） | 逐格相同 |

极值时刻的差最大，因为极值附近函数变化平缓，数值噪声被放大（求法见《求根与极值》）。

## 与其他误差比

| 误差来源（月亮） | 量级 |
|---|---|
| 双精度与双双精度之差 | ≤ $10^{-5}$″ |
| 双精度儒略日的时间分辨率（40 微秒） | 约 $2\times10^{-5}$″ |
| 历表与 JPL 数值历表之差（前 3000—公元 3000 年） | 约 1″ |
| $\Delta T$ 的不确定度（前 200 年约 110 秒） | 约 1′ |

双精度的误差比历表本身小 4—5 个量级，比古代 $\Delta T$ 的不确定度小约 7 个量级。

## 速度

| 操作 | 双双精度 | 双精度 | 倍数 |
|---|---|---|---|
| 月亮级数求值（3.6 万项） | 9.7 毫秒 | 0.42 毫秒 | 约 23 |
| 月亮视位置（含光行时迭代） | 184 毫秒 | 8.3 毫秒 | 约 22 |
| 格林尼治视恒星时（含完整章动） | 700 微秒 | 40 微秒 | 约 18 |
| 全部天象逐条校验 | 约 1.5 小时 | 约 5 分钟 | — |

也试过折中做法：相位约化与三角函数用双精度，只把求和留在双双精度。结果只快约 3 倍——三角函数便宜之后，相位多项式与乘加的双双精度运算成了大头——而精度并不比全双精度更有意义，故不采用。

## 取舍

- **缺省用双精度。** 网页、排历、天象检验、批量搜索都用它。
- **双双精度只作参照。** 用来检验双精度的误差：发现数值上的可疑之处时，用两种精度各算一遍，看差异是否来自精度本身。
- **两种精度的逐格比对作为常规检验。** 每张校验表都注明所用精度；全部校验另有一项两种精度逐格比对，不一致即报错。
